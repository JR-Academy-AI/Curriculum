**术语说明**（第一次出现就解释，后面不再重复）：
- **GT（ground truth）** = 真实来源的用户数据（客服记录、用户访谈、公开评论区里的真实发言），跟 AI 凭大纲和常识"推测出来"的内容是两回事。这份文档里凡是标了具体来源（文件路径 / URL）的都是 GT，标"AI 推断"的就是没有真实数据支撑、纯靠常识拍出来的。
- **cohort** = 每一期招生开课的班级，本课叫"期"，比如"第 30 期"。
- **ROI** = 投入产出比，这里特指某个营销渠道花的精力换来的实际转化效果好不好，不是指流量大不大。

## 跟 ai-engineer-bootcamp 的定位区分（必读，否则 persona 会画串）

这两门课**名字都带 AI Engineer，但卖的是两拨人，买的是两样东西**，做 marketing 千万别混：

| | **本课 · 全栈项目班** | ai-engineer-bootcamp |
|---|---|---|

| 主线技能 | React + Redux + (.NET / Node.js / Spring Boot) + AWS + Agile 团队协作 + Git/CI/CD，AI（RAG/OpenAI/Azure）是其中 1 个模块 | 全程围绕 LLM 工程，全栈基础是地基不是主菜 |
| 买家的痛 | "我没有澳洲本地经验 / 没有能拿出手的项目作品集，投简历石沉大海" | "公司招 AI 工程师我对不上 JD 的 RAG/Agent" |

## 2. Persona 详情

### Persona A · 缺本地经验的新移民开发者（核心买家，~35%，占比仍是推测）

**画像**：26-38 岁，国内有 1-5 年开发 / IT 相关工作经验的新移民（PR / 工签 / 配偶签），落地澳洲后发现投简历全被"no local experience"卡住。年龄区间和签证状态是 AI 按常识推的，没有真实数据。但课程方自己定义的目标人群里明确写了"国内有 IT 工作经验、无本地工作经验的新移民"，这条不是 AI 编的。（来源：`outline.json` suitable 字段）

这次调研找到一条比较硬的交叉验证：一条 2020 年发布的真实学员采访视频标题是"国内工作 10 年移民澳洲，缺乏本地学习工作经历如何斩获 Offer？——全栈班学员 Leo"。这跟 Persona A 的画像几乎是逐字对上的——国内工作年限长、移民后缺本地经验，正是这个 persona 的核心特征。但要打个折扣：这条视频对应的是"第 8-10 期"左右的老 Web 全栈班，那时候还没有现在的 AI Engineer 定位和 RAG 模块，只能算方向性证据，不能当成当前 26-30 期学员的同期数据。（来源：销售页打包数据里的真实 YouTube 视频标题，2026-07-03 curl 拿到）

**痛点 Top 3**：这三条目前仍然是 AI 按常识拟写的，不是真实用户原话，还没有客服记录或访谈能直接印证具体措辞。

1. AI 推断："我国内写了好几年代码，但澳洲 HR 一看简历没有本地经验直接划掉，连面试都进不去"
2. AI 推断："我有技术，缺的是一段'用澳洲这套流程（Agile / Git flow / AWS 部署）做出来的、能给雇主看的项目'"
3. AI 推断："我没在本地团队里跟 BA、DevOps、UI 协作过，面试一问团队经验我就露怯"

**决策周期**：AI 推断 3-6 周（客单价高、要对比 bootcamp、要看校友是不是真上岸、要协调上班/家庭时间）——这个字段完全没有真实数据，需要靠销售访谈（"这类客户从第一次咨询到付款一般隔多久"）或第一期学员问卷才能填对。

### Persona D · 完全零基础的纯小白

## 8. Ground truth 覆盖率诚实评估

**结论：从上一版的 0.15 大概能提到 0.22-0.25，仍然远没到 0.5 的及格线。**

算法上，本文档 3 个买家 persona × 10 个字段 = 30 个标注位。这轮之前，只有"课程方定义的目标人群"和"33 期历史 cohort"两条算半个 GT（覆盖不到 5 个标注位），其余 25 个左右都是纯 AI 推测。这轮新增的证据分成三类，按贡献大小排：

1. **完整核实的硬事实**（价格、班型规模）——不属于用户行为字段，但让 Meta 部分更扎实了，间接提高了整份文档的可信度基线。
2. **弱交叉验证**（9 条学员采访标题）——覆盖了 3 个 persona 各自"画像"字段的一部分，但因为时间跨度大（2020-2021 年，对应改名前的老课程），只能算方向性佐证，不能当作当前 26-30 期学员的直接证据。
3. **中等强度的第三方证据**（新足迹论坛帖）——第一次给"不信什么"和"异议"这两个此前完全空白的字段填了真东西，样本是 1 个帖子里的几条回帖，量不大，但内容具体、可复核（帖子链接可以直接打开验证），比纯 AI 推测强不少。

这三类加起来大概能让 3 个 persona 里各自 2-3 个字段从"纯推测"升级到"有真实依据但需要打折扣使用"，覆盖率往上挪了一截，但离及格线还差得远——因为权重最大的那一块**完全没动**：决策周期、日常活跃平台的具体时段、信任谁、购买触发器、渠道 ROI 排序，这五个字段本质上需要主动的用户访谈或后台成交数据才能填对，公开网络搜索天生够不到。换句话说，这次调研已经把"公开网络能查到的部分"基本查穷了（销售页、论坛、V2EX、Reddit、知乎、一亩三分地都试过或验证过为什么用不上），但覆盖率卡住的根本原因从来不是"公开信息不够多"，而是"没有人翻过真实学员名单、没有人访谈过销售顾问、没有人导出过客服记录"——这三件事都是内部数据，只有公司内部的人能做，AI 在公开网络上再怎么搜也补不上。

下一步要把覆盖率真正推过 0.5，唯一路径是走 §7 task 1（翻学员名单）+ task 2（访谈销售）+ task 5（客服记录），这三件事做完大概半天到一天就能看到明显提升，比继续在公开网络上找证据划算得多。
