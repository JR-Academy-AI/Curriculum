## 2. Persona 详情

### Persona A · 在职资深架构师 / AI·ML 工程师 / 技术负责人

- **画像**：30–45 岁，解决方案架构师 / AI·ML 工程师 / 技术负责人 / 资深软件工程师，**3+ 年系统架构经验**，做端到端交付、对接干系人、负责安全合规与治理。`[来源: 官方 CCAR-P Exam Guide 受众段 ⭐⭐⭐⭐⭐]`
- **痛点 Top 3**：
  1. **中文备考材料在这门上几乎是空白，尤其两块**：RAG 流水线设计、架构决策沟通（写 ADR / 五分钟讲清取舍与 SLA）。后者是纯软技能，`DESIGN.md` 判断"华人技术考生最容易丢分、也最缺练习材料"。⚠️ 该判断是**产品侧假设，无数据支撑**，但"中文材料空白"这一半可由本次核查佐证（中文搜索结果几乎全是复读官网的水文，且含事实错误）。`[来源: DESIGN 支柱 3 ⭐⭐⭐ + 本次公开渠道核查 ⭐⭐⭐]`
  2. **按 CCAR-F 的方法复习 P 会漏掉 40% 考点** —— 逐词比对官方两份考纲的结果是硬事实：**RAG / 检索**在 F 考纲**出现 0 次**（且 "vector database implementation details" 被明确列进 out-of-scope），在 P 是 Domain 3 核心 **19%**（权重最高）；**GDPR / HIPAA / FedRAMP** 在 F **出现 0 次**，在 P 是 Domain 5；**stakeholder** 在 F **出现 0 次**，在 P 是整个 Domain 6，占 **14%**。`[来源: 官方两份 Exam Guide 逐词对照 ⭐⭐⭐⭐⭐]`
  3. **报名卡在门口**：官方规定**必须用已登记公司域名邮箱，个人邮箱注册不了**；域名未登记时官方处理需 **7–10 天**。⚠️ 对这个 persona 相对最轻——他多半有公司邮箱，但**公司域名是否已挂在某 CPN 组织的 partner record 上，仍需逐个确认**。`[来源: 官方 Partner FAQ 2026-07-26 ⭐⭐⭐⭐⭐，详见 CLAUDE_CERT_FAMILY §3.1]`
- **决策周期**：⚠️ 待补。**⚠️ 最大空白**：`DESIGN.md` 判断这批人"往往由公司报销"——若成立，决策链含**报销审批**，周期与话术都跟个人自费完全不同（要给得出发票/报销说明/对上级的价值陈述）。**这条假设没有任何数据，必须优先验证。** `[来源: DESIGN 定价口径 ⭐⭐⭐ 产品侧假设，⚠️ 待验证]`
- **日常活跃平台 Top 5 + 时段**：⚠️ 待补（推断：LinkedIn / 公众号技术长文 / 私域架构师圈层 / 极客时间类付费内容）`[来源: AI 推断 ⭐]`
- **信任谁**：⚠️ 待补（推断：把两份官方考纲逐词比对给他看的人、同级别架构师的实考复盘）`[来源: AI 推断 ⭐]`
- **不信什么（黑名单）**：⚠️ 待补（推断：「保过」、自称官方 Partner、没有依据的"精讲"。⚠️ 后两条同时是我方红线——匠人在 CPN 是 **Registered** 级，**禁止**自称官方 Partner）`[来源: AI 推断 ⭐ + CLAUDE_CERT_FAMILY §4 ⭐⭐⭐⭐⭐]`
- **购买触发器**：看到 **F vs P 逐词对照表**那一刻——「RAG、stakeholder、GDPR 这些词在 Foundations 考纲里出现 0 次」。这是本产品最锋利的一句，且是可核查的事实。`[来源: DESIGN 支柱 2 ⭐⭐⭐ + 官方考纲 ⭐⭐⭐⭐⭐]`
