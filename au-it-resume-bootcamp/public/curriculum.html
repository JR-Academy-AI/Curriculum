Action Verb + Metric + Impact 公式。"参与了项目开发" vs "用 React + Node.js 重构了用户中心，页面加载速度提升 40%"——哪个版本更好？

如何撰写 IT 专业简历
针对 IT 岗位的简历特殊要求：技术栈怎么列（不要"熟练掌握 Java"，要"Java 8+, Spring Boot, Hibernate"）、GitHub/Portfolio 链接放哪里。
