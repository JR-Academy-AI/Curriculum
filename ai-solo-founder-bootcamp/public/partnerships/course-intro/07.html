PHASE 1 · AI Enable Business
W1-W7 · 28 节 · 7 现场课 · 5 Lab

W0 · Pre-work（开班前自学）
  • 装机 + LLM Key + AI 订阅档位
  • ABN 前置材料 + 创业身份 A/B/C 采集表
W1 · ⭐ 搭起你的 CEO AI OS
  • 5 个 AI 秘书方案对比 + 现场选型
  • 喂 Gmail / Calendar / Drive / Notion 进超级记忆
  • 锁方向写死一页生意 SoT + 现场组队
  • 现场派 7 个秘书任务，至少跑通 2 个
W2 · ⭐ 你的 AI 员工上岗
  • Hermes / 龙虾 OpenClaw / Codex / Claude Code 四选一装上
  • 接权限 + 给 agent 写工作说明书
  • Agent Schedule：竞品监控 / GSC 周报 / 财务月报
  • 周中 agent 跑调研 + 你约 5 个真实用户访谈
W3 · 这是不是一门好生意 ⭐嘉宾
  • Stan（麦肯锡）现场拆 3-4 个学员 idea
  • 四把尺子：市场规模 / 竞争 / 单位经济 / 护城河
  • 形态决策 + 5 大定价模型选型
W4 · 做出能卖的东西
  • 不写代码的：专长 + AI 做生产化服务 / 信息产品
  • 会写代码的：MVP 范围砍到一周能 ship
  • 周中 MVP coding 全自学 + 3 个 Vibe Coding Lab
W5 · 立起你的品牌门面
  • 官网 + design system + 品牌一稿出全套
  • Source of Truth 一处改，官网 / Deck / 一页纸 / 公众号同步
W6 · 别让项目烂尾 ⭐嘉宾
  • Ray（微软）大厂 PM 那套删到一个人还能用
  • AI OS 当 PM 维护 backlog + 追进度
W7 · 收到第一笔钱
  • 人脉盘点 → 30-50 人排序名单 → 一对一 pitch
  • Stripe / Lemonsqueezy 澳洲版接入
  • $1 真实付费（毕业硬指标）+ 法律文件 AI 生成 AI 律师审

PHASE 2 · Go To Market
W8-W11 · 13 节 · 4 现场课 · 2 Lab

W8 · AI 内容工厂
  • 小红书爆款 + 私信转化

  • Sora 2 / Veo 3 视频 · Heygen 数字人 · AI 海报 / 漫剧

W9 · 主动敲开客户的门
  • LinkedIn 个性化 outreach 三段式公式
  • ProductHunt 冷启动 + launch 日期定死
  • 中英文圈 6 大线下渠道
W10 · 让人和 AI 都搜到你
  • Google long-tail SEO
  • AEO / GEO：写成 AI 愿意整段引用的内容
  • E-E-A-T / Schema.org + GSC 提交验证
W11 · ⭐ 用户增长 + Marketing OS
  • 5 层管道：数据 → 选题 → 多平台 → 发布 → 学习
  • AARRR 五环表找最大漏水环
  • 推荐机制与病毒循环 + 一个 launch 跑通 10 渠道
  • 匠人 dogfood：1 人 30min/天 = 4 平台 × 12 篇
