## 2. Persona 详情

### Persona A · 在职华人开发者，想跟上 AI Coding 浪潮

**画像**：2–6 年 backend / full-stack / DevOps 经验，有 Python / JS 基础，会用 ChatGPT / Copilot 写代码片段，但停在"问一句答一句"，没有系统的 AI 开发工作流。
[来源：`outline.json` 的 `targetAudience`（"有编程基础的开发者、全栈工程师、DevOps、想用 AI 提升开发效率的技术人员"）和 `suitable`（"全栈开发者想用 AI 10x 开发效率"）字段——这两个字段是公司自己写的官方定位声明，不是独立做过的用户调研，标清楚不要当成"我们访谈过这类人得出的结论"。]

**痛点 Top 3**：

1. "怕被会指挥 AI 的人卷掉"——这是上一版文件写的核心痛点假设，这次调研没找到任何一条真实 JD 或招聘讨论帖能证明企业真的在要求"AI coding 能力"、或者有员工在讨论区抱怨"同事用 AI 效率碾压自己"。[来源：⚠️ 待补，AI 推测未核实——需要 HR 或员工去 Boss 直聘搜相关 JD、脉脉搜相关讨论帖，截图给我们才能验证]
2. AI 写的代码谁来兜底、工具选来选去还是不确定选哪个——这条不是直接针对本课程的证据，是抓取 V2EX 热帖快照看到的真实讨论热度：「公司 vibe coding 的项目，团队已经无法掌控了」145 条回复，「讨论：AI 写的代码要不要看，不看代码的程序员会被淘汰吗？」98 条回复，「真的没人觉得 codex 比 claude 笨很多吗？」54 条回复。[来源：V2EX 官方公开 API `api/topics/hot.json` 抓取快照，间接证据——只能说明"这类话题在目标人群社区确实有热度"，不能当成"用户在评价这门课"来用]
3. 市面上的 AI 课大多是 prompt 速成，学完还是零散技巧，不成体系。[来源：⚠️ 待补，AI 推测未核实]

## 7. Ground truth 覆盖率评估（诚实版，不因为写得详细就往上调）

**结论：约 0.28**，还是不到 0.5 的及格线。

这个分数在算什么：4 个 persona × 10 个字段 = 40 个标注位，统计里面有多少个字段能指出真实出处（生产数据、真实用户原话、公开可查的社区讨论），而不是"团队觉得应该是这样"。这次重写实打实往前推进的是两块——Persona A/B 的"购买触发器"里定价那部分（之前是 0，现在有三处真实数据源互相印证），以及 Persona A/B 共享的"不信什么/异议"里新增的一条真实负面证据（V2EX 网友原话）。这两块之前完全是空的，现在有实证支撑，这是真实的进步，不是文档写得更长造成的错觉。

覆盖率上不去的原因也很直接：Persona A/B 的决策周期、平台时段的具体数字、异议里剩下的 2-3 条、触达 ROI 排序，这些字段唯一可能的真实来源是小红书评论区、01 期学员反馈、内部咨询记录——这三处全部被红线挡在外面（小红书是反爬红线只能人工截图，内部记录是这次工具够不到的系统）。Persona C 和 D 两条副线基本是 0——这次调研的公开网络搜索完全没有触达到这两批人的真实声音，写着"待补"的字段比写着有来源的字段多得多。
