核心能力

LLM 与 Context

解释 token/API behaviour、prompt/context boundary、structured output 与 reasoning pattern 的适用范围。

RAG

解释 chunking、embedding、retrieval、grounding、citation、RAGAS、LLM-as-a-Judge 与 GraphRAG 何时值得。

Agents

解释 ReAct、tool calling、bounded loop、Multi-Agent trade-off、termination、human approval 与 failure recovery。

Production Runtime

解释 Memory lifecycle、Harness、trace、budgets、checkpoint/replay、Model Routing、fallback 与 escalation。

Governance

解释 risk register、privacy、permission、eval threshold、vendor risk、release gate、rollback 与 incident response。

Fine-Tuning 决策

先证明 prompt、context、RAG、tools 或 routing 不足，再根据数据、质量、隐私、成本和维护能力决定是否训练。

最终面试证据

一套可运行的 CareKind Agent repository；一份 system architecture；一组 production eval cases；一份 routing decision log；一套 release / rollback / incident evidence；以及能说明“为什么这样设计”的现场 defense。
