## 1. 这节课要解决什么

学员在 W1 锁了方向（Business SoT v0.1），W2 让 agent 跑了调研、做了 5 场用户访谈，W4（本期提前上了）把东西做了出来。
**W3 是唯一一次有人逼着他们冷静算账的机会。**

一句话目的：**把 idea 从「我觉得有戏」变成「我算过，它这样才赚钱，风险在这两处」。**

三件套（逐字取自 `outline.json` L09 description，不改写）：

| | 内容 |
|---|---|
| **本周真实动作** | 把 idea 过一遍麦肯锡式判断——市场规模、竞争、单位经济、护城河、产品形态、定价，全部定死 |
| **本周产出** | 一页商业验证报告（赚钱算式 + 形态结论 + 定价模型 + 价格 anchor + Top 2 风险） |
| **卧槽点** | 麦肯锡顾问当场把你的 idea 拆到只剩骨头，你第一次看清它到底赚不赚钱 |

**现场过关**（outline 原文）：每人带走三样——一条能算的赚钱算式、一个明确的交付形态结论、一个定好的定价模型与价格 anchor。

## 2. 教学定位（讲师定调）

- **今天不是让你放弃**。三种结论都合格：继续 / 调整 / 换。**「换」是最便宜的一种，越早越便宜。**
- **今天不产出内容，只产出判断**。没有 LIVE demo、没有 Codex 断点——这一节的产能全部押在「学员自己算」和「被追问」上。
- **全场只认可数的东西**。「他们说很痛」不算证据，「他上个月为这事花了 $X」才算。写 0 就写 0。
- **语言口径沿用 W4**：大白话为主，`TAM / unit economics / churn / anchor` 这类行话第一次出现时用括号给中文注释。班上有律师 / 会计 / 医生 / 咨询背景、不写代码的学员。

## 6. 数据纪律（本 deck 没有 `research/`，原因写在这）

这一节课**没有需要外部引用的市场数据**——它教的是一套算账方法，数字由学员自己现场填。
因此本 deck **不建 `data/*.ts`、不建 `research/`**，而是执行更严格的一条：

> **deck 上不出现任何具体的金额、转化率、市场规模、案例收入。**

具体做法：

| 位置 | 处理 |
|---|---|
| S08 七条变现路径 | outline 原文有「逐条给客单价区间」，但**没给数字**。deck 不编——客单价一栏做成留白，现场按学员自己的市场填 |
| S10 反推表 | 纯算术（$1k ÷ 客单价 = 客户数），标「这是算术，不是承诺」 |
| S23 Freemium | outline 写「转化率 1-5%」，deck 引用时标注**来源为课程大纲的经验区间，不是保证** |
| S25 早鸟折扣 | outline 写「30-50% off」，同上处理 |
| 任何案例 | **不放**。`W1_CASE_STUDIES.md` 不在本仓库，无从核对来源 → 一个案例都不写，改由讲师现场口述自己经手的 |

红线遵守情况：不承诺金钱结果 ✓ · 不给法律税务意见 ✓（W7/W13 才碰）· 不提任何人的族裔 ✓ · 无编造人名公司名 ✓ · 无 AI 味模板腔 ✓
