# MARKETING PLAN · Claude 官方架构师认证 · 考试直通包

> 本文是 `cca-f-cert-pack` 的对外宣传策划 SoT。Landing、小红书、公众号、朋友圈、社群、销售私聊都从这里取方向和话术。

## 1. 命名原则

对外先说人能秒懂的名字，不要一上来用简称。

| 场景 | 推荐写法 | 说明 |
|---|---|---|
| 主名称 | Claude 官方架构师认证 | 首屏、封面、标题优先用这个 |
| 完整名称首次出现 | Claude 认证架构师 – Foundations（Claude Certified Architect – Foundations，考试代码 CCAR-F） | 先中文解释，再补官方英文名和考试代码 |
| 后文简称 | Claude 架构师认证 | 大多数渠道正文用这个 |
| 专业补充 | CCAR-F | 只放在括号、FAQ、专业说明里（这是官方考试代码，不是 CCA-F） |

避免写法：

- CCA-F / CCAR-F 考试直通包（考试代码只在专业说明里出现，不做封面钩子；且代码是 CCAR-F，别再写成 CCA-F）
- 成为全球华人首批 CCAR-F 持证人
- 用报名限制当封面标题或主钩子

推荐改写：

- Claude 官方架构师认证 · 考试直通包
- 成为全球华人首批 Claude 官方认证架构师
- 匠人 CPN 合规通道 · 打通 Partner Academy 报名准入 · 系统备考路线

## 2. 产品定位

产品名：Claude 官方架构师认证 · 考试直通包

产品形态：

- 报名准入：为你开通 Anthropic Partner Academy 账号（个人无法自行注册）
- 系统化备考资料
- 从注册到约考的全程陪跑
- 场景题拆解
- 全真模拟冲刺
- 备考答疑社群

一句话定位：

> 成为全球华人首批 Claude 官方认证架构师。Anthropic Partner Academy 个人无法自行注册——必须由 Claude Partner Network 伙伴在后台开通账号才进得去。匠人已注册加入 CPN，通过合规通道为你开通账号、打通报名准入，再配上最短备考路线、场景题拆解和全真模拟，陪你走完注册 → 约考 → 考场。

核心不是卖资料，而是三件事：

1. 打通报名准入：匠人通过 CPN 合规通道为你开通 Partner Academy 账号、打通报名资格。账号开通后，你本人在 Partner Academy 上自行注册考试、自行结账支付官方考试费，再自己建 Pearson VUE 账号约考——每一步匠人都陪你走。
2. 备考路线：把 Anthropic Academy 散课整理成 5-domain 最短路径。
3. 冲刺确定性：原创考点精析、场景题框架、全真模拟、注册与约考陪跑。

> 费用说明：官方考试费不含在包价里，按官方标准在 Partner Academy 结账时由你本人直接支付。这笔钱确实存在、需要另付，别默认已含在包价里——具体金额销售私聊时讲。

## 4. 目标用户

优先人群：

- 已经在用 Claude / Claude Code / MCP 做项目的开发者。
- AI Engineer / Solution Architect / 技术顾问。
- 想给简历、LinkedIn、客户提案增加 Anthropic 官方认证背书的人。
- 做 AI 外包、Agent 项目、企业 AI 转型咨询的人。
- 已学过 Claude Code 实战班，但缺一张官方认证的人。

不适合人群：

- 完全没用过 Claude / Claude Code 的新手。
- 想从零学 AI 编程的人。
- 期待直播课、长期辅导、项目实战的人。

分流话术：

> 你只是差一张证，选考试直通包。你还没真正上手 Claude Code，建议选 Claude Code 实战冲刺班。

### 卖点 1：打通 Partner Academy 报名准入（CPN 合规通道）

这是最硬的价值点，也是可信度支柱，但不要放成封面主口号。封面先讲“成为全球华人首批 Claude 官方认证架构师”。

推荐话术：

> Claude 官方架构师认证是 Anthropic 首个 Claude 官方技术认证。关键是：Anthropic Partner Academy 个人无法自行注册，必须由 Claude Partner Network 伙伴在后台开通账号，你才进得去、才报得了名。匠人已注册加入 CPN，通过合规通道为你开通 Partner Academy 账号、打通报名资格。账号开通后你本人在 Partner Academy 上自行注册考试、自行结账支付官方考试费，再建 Pearson VUE 账号约考——注册、约考、OnVUE 环境自检每一步匠人都陪你走完。

### 卖点 2：省下几十小时摸索

推荐话术：

> Anthropic Academy 的官方课是免费的，我们不藏这件事。但官方课是散的，没人告诉你哪门课对应哪个考点、哪些必须看、哪些可以跳过。我们把它整理成 5-domain 备考路线，按考试权重和题型直接冲刺。

### 卖点 3：官方没有的原创冲刺件

推荐话术：

> 官方给你考纲，我们给你考点精析、场景题答题框架、全真模拟、逐题解析和考前清单。

交付物：

- 为你开通 Anthropic Partner Academy 账号（个人无法自行注册），打通报名准入。
  - 官方考试费不含在包价里，在 Partner Academy 结账时由你本人直接支付，按官方标准。
- 5 大 domain 考点精析（按官方考纲权重）。
- 场景题拆解（官方 6 个场景抽 4 个的题型框架）。
- 全真模拟题。
- 逐题详解。
- 注册、约考、OnVUE 环境自检、重考与续证规则答疑。
- 备考社群。

官方考纲五大 domain 权重（按此排序备考）：

| Domain | 权重 |
|---|---|
| Agentic Architecture & Orchestration | 27% |
| Claude Code Configuration & Workflows | 20% |
| Prompt Engineering & Structured Output | 20% |
| Tool Design & MCP Integration | 18% |
| Context Management & Reliability | 15% |

> 权重最高的是 Agentic Architecture & Orchestration（27%），备考重心先压这里，再是 Claude Code 与 Prompt Engineering。

证书有效期与续证（可做留存钩子）：

> 证书有效期 12 个月。到期前可在 Partner Academy 完成一次免费、非监考的续证评估续期；一旦过期须全价重考。备考社群会在到期前提醒你续证，别让证书白白过期。

## 8. 合规红线

对外禁止：

- 官方 Claude Partner（匠人在 CPN 是 Registered 级，禁止自称官方 Partner、禁止用 Partner badge）
- Anthropic 官方合作伙伴
- 保过 / 稳过 / 必过 / 包通过
- 官方考试名额 / 含考试名额 / 帮你拿到考试名额 / 名额已激活（匠人不代发、不代购名额，只开通账号打通准入）
- 对外公开官方考试费的具体金额（这笔钱要让读者知道存在、需另付，金额留给销售私聊）
- 对外公开包价格

允许：

- 匠人已注册加入 Claude Partner Network。
- 通过 CPN 合规通道为学员开通 Partner Academy 账号、打通考试报名资格。
- 官方考试费按官方标准，在 Partner Academy 结账时由学员本人直接支付（不含在包价里）。
- 冲刺过考、以一次过考为备考目标（不承诺保过）。
- 官方考纲确认：60 题 / 120 分钟 / 720 分（100–1000 量表分）/ 6 个场景抽 4 个（可直接写“官方考纲”，不用再标“社区口径”）。
- 证书有效期 12 个月，到期前可做一次免费、非监考续证评估；过期须全价重考。
- 考试信息以 Anthropic 官方考纲和 Pearson 官方说明为准。
