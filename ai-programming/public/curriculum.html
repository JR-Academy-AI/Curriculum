📝 开营第一节：现场定下你自己的项目

第一节课现场填《我的项目单》六个问题，讲师逐个过 —— 把太大的砍小、把太虚的问实。 后面 5 周所有作品都做你自己的题目，不做房地产楼盘演示案例（那只是讲师 demo）。
  1. 你想做出个什么东西？（一句话，具体到能被看见）
  2. 这东西给谁看 / 给谁用？（老板 / 客户 / 同事 / 招聘方 / 家人 / 自己）
  3. 你现在做这件事要花多久？← 效果基线，结营对照这一条
  4. 你最想要的效果是？（提升上班效率 / 有个能拿出去看的作品 / 让想法落地 / 搞清楚 AI 能干什么）
  5. 你手上有什么真实材料能拿来练？（工作 PPT / 报价单 / 客户资料 / 简历 / 产品图）
  6. 学完你打算用在哪个具体场合？（下个月的哪次汇报 / 哪个客户 / 哪次求职）
结营答辩（S10）你会拿着这份单子上台，逐条对照第 3 题的基线 —— 这不是考试，是让你看见这 5 周换到了什么。
