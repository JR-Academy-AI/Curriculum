Vibe Coding 大师课 · 第六节课 — Agent：会遇到的问题 · 怎么定位 · 怎么改

90 分钟诊断课（讲解 + 投屏演示 + 一段 10 分钟诊断练习，不做长任务实操，学员不需要环境）。立意是「懂原理不解决问题，会诊断才解决问题」，所以全课是一条诊断链：① 会遇到的问题 → ② 怎么定位 → ③ 怎么改。地基段只讲到够用：Agent = 模型 + 工具 + 循环、循环四拍与「它每一轮都重新读一遍 context 再决定、不是带着记忆往前走」、停止条件里的「它认为」，以及核心立论「它没有记忆，只有 context」——于是「它怎么又忘了 / 瞎编 / 不守规范」三句抱怨全都先当 context 问题查，前五节所有 SoT 的物理作用被重新解释成一件事：让它每轮重读 context 时读到的是对的东西（系列收束页）。① 问题（全课最长一段）讲五条跑偏机制，每条配一个学员认得出的症状：context 稀释（越到后面越不守规矩）/ 压缩丢细节（风格断层、重踩已解决的坑）/ 错误累积（每步都有道理但整体错）/ 目标漂移（diff 大三倍）/ 进度幻觉（总结全绿、自己跑全红——前四条骗的是它自己，这条骗的是你的验收环节）。② 定位给出可带走的两件工具：定位三问（这件事在它 context 里吗 · 它是在查还是在猜 · 这句「完成了」我自己验过吗）和症状 → 机制反查表（每行右边都是 30 秒内能做完的动作），并点破「『它今天不行』不是诊断，是放弃诊断」；随后老师投屏走一遍真实反查 + A/B 预录对照（裸交 vs 带任务交付单），揭穿「顺便该修的都修一修」就是目标漂移的许可证、而且是你自己发的。10 分钟现场诊断练习：学员对着预录的跑偏记录填诊断单前两栏，讲评只问「你依据哪条症状」、不判对错——练的是推理链。③ 怎么改把五条机制一一对应到五个具体处方：落盘（治稀释/压缩）· 计划先行 + 你审计划（治累积）· 交付单的「边界」格（治漂移）· 可执行验证 + 铁律「它说完成了不算完成，判据必须来自它之外」（治幻觉）· 打断三信号（事中兜底）；最后学员回填诊断单第三栏，带走一条完整的「症状 → 机制 → 处方」链。28 页，含反查表 / 定位三问 / 交付单模板三张可打印讲义 + 作业（含课后补做完整 A/B、交付单按 L5 判断线做成 Skill）。

Vibe Coding 大师课 · 第七节课 — Subagent：给 context 分家

120 分钟动手工作坊（两次实验：一次正收益，一次红灯；全程只读、不改真实代码）。承接 L6：上节课诊断出「探索噪音挤满一个 context」，L7 给出那个病的结构性解法——别把所有事塞进一个 context 里。全节立论只有一句：子 Agent 不是多一个人手，是多一个独立的 context；立住之后收益（脏活不污染主 context）、代价（冷启动 / 报告开销 / 它看不见你的对话）、铁律（不假设继承 / 不重叠所有权 / 不拿自述验收）全是它的推论。判断线是两层门：三项强收益（隔离噪音 / 并行分支 / 独立视角）至少命中一项，四条就绪条件必须全过——而且「独立视角」是唯一一个 1 个子 Agent 就能拿满的，这直接推出最小配置：1 个 verifier。课堂做两次实验且顺序不可调：动手 A 派三路只读调查、收口是一张证据可追溯、缺口已标记的汇总矩阵（不许把三份报告拼起来）；动手 B 是红灯——故意派一个两三步就能做完的小活并真的计时，让学员亲手测到冷启动 + 重新摸索 + 写回执 + 你再读回执比自己顺手做完慢得多。判断线放在两次实验之后，从学员自己的数据里长出来——延续 L4 CI 红灯 / L5 description 翻车 / L6 裸交跑偏一贯的「先撞墙，再给尺子」。操作层同样落地：六格 brief + 坏 brief 现场改写、三档调用的强制力差别（「我说了」不等于「它照做了」）、好指令逐句拆解（边界用否定句显式收窄、证据格式前置、以及最容易漏的「给『不知道』一个出口，不给出口它就编」）、按判断密度而非重要性选模型档（verifier 判断密集不能省，调查员执行密集便宜档够用；先调思考力度再动档）。收尾是三条底线：context 隔离 ≠ workspace 隔离、完成回执、以及「再找一个 Agent 看看不是 verifier」。全课收口：分派改变的是信息怎样流动，不会转移最终验收责任。

Vibe Coding 大师课 · 第八节课 — Agent Team：从分派到协作

120 分钟「做一步讲一步」工作坊 · 12 拍做/讲交替（全程只读，不改课堂仓库任何代码）。课堂仓库已锁定：star-mansions，与 L7 同一个——学员已经熟了，省掉重新摸项目的时间。

🔑 v0.2 三处结构性改版（v0.1 是「讲 64 分钟 + 一次大实验」）：
① 课型改成 12 拍做/讲交替，第 6 分钟就动手，立论页挪到第 30 分钟——学员刚亲眼看完结论翻转的那一刻。v0.1 把立论和 charter 全排在唯一一次实验之前，重复了 L7 v0.3 已经付过学费的错误：尺子先于撞墙。
② 主教具从自动 Agent Team 改成「手动 Team」（三个会话 + 学员自己当消息总线 + 一个 md 当任务板），自动 Team 降为第 9 拍的 8 分钟投屏对照。理由：自动 Team 一开跑就是黑盒、喊停停不住，结构上不支持「做一步讲一步」；而且 Team 的价值全在消息里，消息自动飞过去就看不见了——手动粘贴看到的不是「结果不一样了」，而是「这一句话改变了什么」。连带效果：本节不再有开课门槛，不要求工具支持 Agent Team，国内学员从「走降级方案」变成和全班做同一件事。
③ 实验题换成两道预埋题，因为 v0.1「课堂脚本必须制造一次通信有价值的时刻」靠嘱咐保不住，一定退化成分工。现在把对抗时刻做成题目本身的结构性事实。

🐛 浅题（拍 2–4，零制作成本——它真实存在于仓库 main 分支上）：前端 authAdapter.login 只做 trim 不做大小写归一（前端不擅自改用户输入，对的）；后端 emailToId() 用邮箱原文派生 user.id（也是对的）——交界处 Rick@x.com 和 rick@x.com 派生出两个账号，历史记录「消失」。由此把立论从「锚定」升级为「交界处的 bug」：锚定是概率问题（派得够多有可能碰上），交界 bug 是结构问题——「A 没问题」+「B 没问题」+「C 没问题」=「都没问题」≠ 真相，不管派多少路、brief 写多好，这个和永远算不出真相。全课最重要的一句：交界处的 bug，互不通信的调查者在结构上不可能发现——不是漏了，是算不出来。

🐛 深题（拍 6–8，只需一页现象报告，不改任何代码）：线上记录丢失，时间线显示每次消失前 30 秒都有一次部署，三路会一致得出「部署导致丢失」——错误、自洽、且按它去修三个方向全错。真因是生产 Supabase 配置没生效、走了 handlers/history.ts 里那条「仅本地/单测用」的内存回落；部署只是触发器，是共因不是因果。拆穿它只有一条路：有人专职去找反例（「有没有没部署但也丢了的时候」）。两道题教两件事：浅题教「不通信就发现不了」，深题教「不通信会一起错、而且错得很自信」。

🧱 从搭一个 agent 开始：拍 1 花 8 分钟让学员从零写一个角色文件，今天的三个队友就是这三份自己搭的文件，一路走到拍 9「同一份文件当 teammate 再跑一次」——那句「一个字没改」的对照才有主语。暗线是 tools 字段：你砌的那道墙挡住噪音（L7 的收益），也挡住证据（今天的代价）。

其余判断线原样保留：第二问、Team 门槛必须比 Subagent 高、对抗 ≠ 分工、没有廉价判据时辩论才值、三类关键消息（DISCOVERY/CONFLICT/DECISION）、任务板全绿 ≠ 外部验收完成、异构只能进 Subagent。新增一条操作纪律：传证据不传结论——原文转贴不做二次总结，否则对方翻转的是「同意你」而不是「发现矛盾」。

🖥 deck 已实现（21 页 · React 19 + Vite + framer-motion · 1600×900 SlideEngine）：deck 的性质是白板不是讲义——① 不放空白填写表，模板一律留在讲义里，投屏上只给填好的样例（一格空白等于 60 个人盯着一片空，填好的样例反而讲得动）；② 每一拍的「现在做什么 / 什么时候停 / 贴什么到群里」放 Runsheet 不上 deck（那是老师的操作手册，不该投给学员看）；③ 只有 P07 / P08 两页是大字页——拍 3 的口令和立论，那 9 分钟不许被任何多余信息稀释。（曾做过 4 页课堂填空 + 每页底部三行节拍页脚，Rick 判定太多太抢，已全部删除。）

🏗 新增课后进阶：如何和 Agent 对话生成专家 Agent（讲义 §12 / 蓝图 §20 / Runsheet 附录 D）。别直接说「帮我创建一个安全专家 Agent」——那只会拿到一段人设提示词，等于一个没有 tools 字段的角色文件。正确做法是让 Agent 先当 Agent 架构师，五阶段访谈问出规格，最后才写 Prompt：定义任务（关键句是「请先不要生成最终提示词」+「每次只问一个最重要的问题」）→ 给三个真实案例 → 反推能力并指出缺口（「不要自行假设关键业务规则」）→ 生成 12 项 Agent Specification（暂不写 Prompt）→ 最后才生成 System Prompt → 六类测试场景 + 找另一个 Agent 当审计员。教学决策：这一段绝不能提前到拍 1——你不会审规格，就不该让 AI 替你写规格；而且拍 9 那句「一个字没改」需要「这是你写的」这个主语。所以课堂只用 3 分钟预告，完整方法进讲义、作业里选做。它和本节四条判断一一对应：规格先于 Prompt = charter 先于开跑；风险检查那 10 条全是交界问题；审计员就是拍 7 的唱反调成员（同样不能说「审计一下」，要给具体检索目标）；「别只问抽象的风格或角色定位」= L7 的 tools——人设不是边界，权限才是。另补一条判断线（原材料没有）：只读 / 一次性 / 自己用 → 手写四格；能改东西 / 给别人用 → 才走五阶段——别因为方法更高级就都用它。
