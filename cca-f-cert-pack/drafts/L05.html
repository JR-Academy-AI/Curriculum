官方唯一备考资源：Anthropic Academy

CCAR-F（Claude Certified Architect – Foundations）没有官方教材、没有 study guide、没有官方模拟题。Anthropic 给的备考入口只有一个：Anthropic Academy，托管在 anthropic.skilljar.com，注册免费、全部课程免费看。考试本身考的是"你能不能用 Claude 搭生产级应用"——原文是 "a technical exam for solution architects building production applications with Claude"（2026-03-12 公告），Academy 就是覆盖这套能力的唯一一手内容源。

先把丑话说前面：这些课全部免费，你自己去 anthropic.skilljar.com 注册就能看，匠人不卖课程访问权。我们这个直通包卖的是"把 20 门散课排成一条对考试有效的路线"——哪几门是命根、哪几门是背景、哪 6 门跟架构师考试完全无关可以直接跳、按什么顺序刷、两周怎么排进日历。这一课就干这件事。

抓这条主线前记住两个约束：其一，Academy 课程是 Anthropic 按"产品线 + 人群"组织的，不是按考试五域组织的，所以你不能顺着目录从上往下刷，得重新编排；其二，目录会增减（这份清单以 2026-07 实际抓取为准，共 20 门），你自己进站时对一眼数量。

顺带把"为什么值得考"说清楚，免得你在两周里泄气：这张证发给个人、不发给公司（原文 "Certifications belong to individual people, not firms"），是你个人履历上的技术背书；据 Anthropic 官方 Services Partner Hub 公布，已有一万多名顾问拿到 Claude 认证（原文 "more than 10,000 consultants have earned a Claude certification"，出处见文末引用）。注意一个常见误解——Anthropic 的 Services Partner Directory 收录的是"有 Claude 落地经验的公司"，不是"个人持证就自动进目录被企业买家搜到"。个人持证的真实价值是两条：给自己简历加硬背书，以及帮你所在公司凑够合作伙伴层级要求的 certified 人数。想清楚这个，就不会考完发现"跟预期不一样"。

还有一件容易被忽略的事：免费课最大的陷阱是"看过≠会"。这些课做得顺滑、看着轻松，很多人一路点"下一节"点到完课，考试一做题全塌。刷 Academy 要当成刷考点，不是当播客听——每看完一门，立刻用自己的话回答三个问题："这门课解决什么问题？考试会拿它的哪个概念挖坑？我现在能不看笔记复述出来吗？"答不上来就是没学会，回看那一节，别急着点下一门。下面 L06 起每门直通包课都配了 5 道自测题，就是逼你把"看过"变成"答得对"。

20 课 → 5 Domain 映射表

考试分五个域，官方 Exam Guide v1.0 给了明确的编号和权重：Domain 1 Agentic Architecture & Orchestration 27%、Domain 2 Tool Design & MCP Integration 18%、Domain 3 Claude Code Configuration & Workflows 20%、Domain 4 Prompt Engineering & Structured Output 20%、Domain 5 Context Management & Reliability 15%。用它判断"该在哪个域多花时间"，直接看权重就行。抓两个反直觉点：一是权重最高的是 Domain 1（27%），不是 Claude Code；二是域的编号不等于你该刷课的顺序——Domain 2 是 Tool Design、Domain 3 才是 Claude Code，别被序号带着从上往下刷。下面把 20 门课按官方域编号重排，跨域的课在主域列一次、在次域标"（跨域）"。

先看懂这张表的两个信号：一是跨域课就是高性价比课——一门 Building with the Claude API 同时喂 Domain 1 和 Domain 2，一门 subagents 同时喂 Domain 1 和 Domain 5，刷一门抵两个域，这类课要优先且刷透；二是没有专属课的域要靠别人"顺带"覆盖——Domain 5（Context Management & Reliability）在 Academy 里没有一门以它命名的课，全靠 subagents 的 context 隔离和 MCP Advanced 的上下文传递带出来，所以你看那两门时要有意识地把"这在讲上下文管理"的部分单独记下来。

Domain 1 · Agentic Architecture & Orchestration（官方权重 27%，五域最高，主战场）

  • Introduction to subagents — 多智能体编排、coordinator/subagent 职责边界、context 隔离，这个域的命根，必刷。
  • Introduction to agent skills — agent 能力封装与 skill 设计，配合 subagents 一起看。
  • Building with the Claude API — agentic loop、stop_reason、工具循环的底层机制（同时喂 Domain 2 工具设计，跨域）。
  • Claude Code in Action — 真实 agentic workflow 怎么跑起来（同时喂 Domain 3 / 5，跨域）。

Domain 2 · Tool Design & MCP Integration（官方权重 18%）

  • Introduction to Model Context Protocol — MCP 是什么、server/client 怎么接，必刷。
  • Model Context Protocol: Advanced Topics — MCP 进阶，也涉及上下文传递（同时喂 Domain 5，跨域）。
  • Building with the Claude API（跨域） — tool use、tool 定义、tool_choice 的坑，工具设计的地基。

Domain 3 · Claude Code Configuration & Workflows（官方权重 20%）

  • Claude Code 101 — Claude Code 入门与基础配置，必刷。
  • Claude Code in Action（跨域） — 配置进阶、hooks、permission 在真实项目里怎么落。
  • Introduction to Claude Cowork — Claude 协作 / 团队工作流场景，跟 Claude Code 生态一起理解。

Domain 4 · Prompt Engineering & Structured Output（官方权重 20%）

  • Claude 101 — prompting 基本功，也是所有课的起点，第一门就该看。
  • AI Capabilities and Limitations — 知道模型边界（会什么、不会什么）才写得出靠谱 prompt，考点里的"识别超范围任务、该升级人工"跟这门直接相关。
  • AI Fluency: Framework & Foundations — 与 AI 协作的思维框架，偏概念，快过一遍即可。

Domain 5 · Context Management & Reliability（官方权重 15%，五域最低但别裸考）

  • Introduction to subagents（跨域） — subagent context 隔离 = 省 token 的核心手段，这门课在这里再消化一遍。
  • Model Context Protocol: Advanced Topics（跨域） — 上下文注入与管理。
  • Claude Code in Action（跨域） — 长任务里的 context / memory 怎么撑住。

补充背景课（生产部署，考试产出低，有余力再看）

下面三门讲"把 Claude 放到哪跑"，对"生产级应用"这个考试定位有背景价值，但直接命中考点少，时间紧可放最后或跳过：

  • Claude Platform 101 — 平台能力概览，10 分钟扫盲用。
  • Claude with Amazon Bedrock — 在 AWS Bedrock 上跑 Claude。
  • Claude with Google Cloud's Vertex AI — 在 GCP Vertex 上跑 Claude。

下面这批是"AI Fluency"人群普及系列，面向非架构师人群，讲的是各行业怎么日常用 AI，不碰 agent 架构 / MCP / Claude Code 配置，考试一分不占，别浪费两周里的一分钟：

  • AI Fluency for educators（面向教师）
  • AI Fluency for students（面向学生）
  • AI Fluency for nonprofits（面向非营利组织）
  • AI Fluency for Small Businesses（面向小微企业主）
  • Teaching AI Fluency（教别人怎么用 AI，师训向）
  • AI Fluency for Builders — 这门比上面几门离我们近（面向 builder），但仍是 persona 普及课、技术深度浅，优先级最低，时间紧就跳，有闲再当轻松读物。

一句话记账：20 门里，5 门 AI Fluency 人群课直接删，1 门 for Builders 可删，3 门云平台课押后，真正围绕考试要精刷的是剩下那 8 门左右。把无关的先划掉，本身就是省一半时间。

推荐学习顺序（按权重 + 前置依赖排）

不要顺着 Academy 目录刷，也不要只按权重从高到低刷——先看的课得给后看的课打地基。有人看到 Domain 1 权重最高就想第一天直接冲 subagents，结果连 agentic loop、stop_reason、tool use 是什么都没搞清，subagents 那些"context 隔离""只有 final message 回流"的机制根本听不懂，白看一遍还得回头补。权重决定你在一个域上花多少时间，不决定先看哪门课。下面这条顺序是"前置依赖优先，其次按官方域权重压时间"。再强调一次：官方权重（Domain 1 的 27% 到 Domain 5 的 15%）只用来分配精力，不决定刷课先后；后面 L06–L10 的考点地图会按域拆开这五组官方权重，帮你把时间压到该压的地方。

  1. Claude 101 — 起点，把 prompting 和基本心智模型立起来（喂 Domain 4 Prompt Engineering）。
  2. Building with the Claude API — 立刻建立 agentic loop / stop_reason / tool use 的底层认知，Domain 1 和 Domain 2 都靠它（跨域地基）。
  3. Claude Code 101 — Domain 3 入门，把 Claude Code 跑起来。
  4. Introduction to subagents — 权重最高的 Domain 1 主攻，顺带把 Domain 5 的 context 隔离一起吃掉。
  5. Introduction to agent skills — 补齐 Domain 1 的 agent 设计视角。
  6. Introduction to Model Context Protocol — Domain 2 主线开刷。
  7. Model Context Protocol: Advanced Topics — Domain 2 进阶 + Domain 5 上下文管理。
  8. Claude Code in Action — 把 Domain 3 / 5 在真实 workflow 里收口，前面的概念到这里落地。
  9. AI Capabilities and Limitations — 收 Domain 4 的"模型边界 / 何时升级人工"考点。
  10. AI Fluency: Framework & Foundations + Introduction to Claude Cowork — 概念补全，快过。
  11. （有余力）三门云平台课当背景扫读；六门 AI Fluency 人群课整批跳过。

为什么把 Domain 5（相对权重最低）夹在中间而不是最后？因为它没有独立课，全靠 subagents 和 MCP Advanced "顺带"覆盖——你按上面顺序刷，Domain 5 自然就跟着消化了，不用单独排时间。这也是"按域重排"比"按目录刷"值钱的地方。

PROJECT：制定你的两周备考计划

现在把上面的顺序落进一张你自己能填的两周日历。规则：每天锁 60–90 分钟；先看课、当天就做对应域的自测题（本直通包 L06 起每课带 5 题）；看完一门立刻在这门后面记一句"最容易考错的点"，这句话比看第二遍更值钱。下面是模板，把方括号换成你的真实日期和实际花的时间。

Week 1 · 打地基 + 啃最高权重域

  1. Day 1 ［日期＿＿］：Claude 101 → 记要点＿＿｜自测得分＿＿
  2. Day 2 ［日期＿＿］：Building with the Claude API（agentic loop / stop_reason）→ 要点＿＿
  3. Day 3 ［日期＿＿］：Claude Code 101 → 要点＿＿
  4. Day 4 ［日期＿＿］：Introduction to subagents（Domain 1 主攻，多留 30 分钟）→ 要点＿＿
  5. Day 5 ［日期＿＿］：Introduction to agent skills → 要点＿＿
  6. Day 6 ［日期＿＿］：复盘 Domain 1 全部自测错题，错哪补哪
  7. Day 7 ［日期＿＿］：休息 / 弹性 buffer（追前 6 天没赶完的）

Week 2 · 工具 MCP + 上下文 + 收尾

  1. Day 8 ［日期＿＿］：Introduction to Model Context Protocol → 要点＿＿
  2. Day 9 ［日期＿＿］：MCP: Advanced Topics（顺带 Domain 5）→ 要点＿＿
  3. Day 10 ［日期＿＿］：Claude Code in Action（Domain 3/5 落地）→ 要点＿＿
  4. Day 11 ［日期＿＿］：AI Capabilities and Limitations（Domain 4 边界与升级人工）→ 要点＿＿
  5. Day 12 ［日期＿＿］：AI Fluency: Framework & Foundations + Claude Cowork，快过概念
  6. Day 13 ［日期＿＿］：五域自测题重刷一遍，统计各域正确率，最低那个域回看课
  7. Day 14 ［日期＿＿］：模拟考节奏（限时做题）+ 检查 OnVUE 考试环境，约考

两个自查红线：其一，六门 AI Fluency 人群课一门都没排进去——排进去就说明你没把这一课的判断听进去；其二，如果某天你在某门课上花了远超 90 分钟还没懂，别硬磕，先记下卡点问题、往后排，这类"讲不清的点"正好丢进 L06 起的自测题去反查。计划是给你压节奏的，不是给你增焦虑的。

两种常见情况怎么改这张表：只有一周——把 Week 1 的 Day 1–5 压成前三天（Claude 101 + Building with the Claude API 合一天、Claude Code 101 + subagents 合一天、agent skills + MCP 入门合一天），Week 2 的 MCP Advanced / Claude Code in Action / Capabilities 挤进第四五天，第六天刷题、第七天约考；概念补全课（AI Fluency Foundations / Cowork）和三门云平台课这一周全砍。已经天天用 Claude Code、只想查漏——跳过 Claude 101 和 Code 101，直接从 subagents + MCP 两条主线切入，把省下的时间全砸在五域自测题上，错题率最高的域回看对应课，别从头顺刷。

关于考试硬约束，排计划时顺手记住：Pearson VUE 承办、OnVUE 线上远程监考或线下考场、闭卷有监考、不允许 AI 辅助、12 个月滚动周期内最多重考 4 次（间隔 14 / 30 / 90 天）。这条约束反过来定义了你该怎么学：考场上没有 Claude 帮你查 stop_reason 有哪几个取值、没有文档告诉你 PreToolUse 和 PostToolUse 谁能拦住转账，全靠脑子里的判断力。所以 Day 14 一定要真限时做题，把"开着文档能做对"练成"闭卷也能做对"——这也是为什么光看免费课不够、得配一整套逼你闭卷答题的自测。
