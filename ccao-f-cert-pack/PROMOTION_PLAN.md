## 1. 课程定位摘要

**一句话**（DESIGN.md）：你已经天天在用 Claude 干活了，这门证把「我会用 AI」变成「我能证明我判断得了 AI 靠不靠谱」—— **而且不需要写一行代码**。

**目标人群**（官方明写"不需要开发或 API 经验"，技术水平有限到中等）：
- P1 — 运营 / 市场 / 项目管理，天天用 Claude 但没证明的知识工作者（核心，TAM 最大）
- P2 — 教育 / 传播 / 通用知识工作者，想给简历加一张官方 AI 证
- P3 — 想入门 AI 认证、但被"要不要写代码"劝退的非技术人
- ❌ 不适合：想考技术证的开发者（分流去 CCDV-F / CCAR-F）

**主推内容角度**（Type 8 首发窗口变体 · 权重排序）：
1. ⭐⭐⭐⭐⭐ **"不用写一行代码就能拿的 Anthropic 官方 AI 证"** —— 直击非技术人最大顾虑，这是四门里唯一能这么说的
2. ⭐⭐⭐⭐⭐ **最锋利的一句（数字来自官方 blueprint，可放心引用）**："市面上所有中文 AI 通识课都在教你写 prompt，可这门官方认证里 prompt 只占 14%，而『怎么判断 Claude 在胡说』占 21% —— 评估+治理合计 36%，是 prompt 的两倍半，方向搞反了刷再多题也没用"
3. ⭐⭐⭐⭐ **CPN 报名准入 + 首批窗口**（可信度支柱，不做封面主钩子）

**售价档**：对外不露价。考试费另付、学员本人在 Partner Academy 结账，金额私聊讲。

**承诺红线**（全部见 `CLAUDE_CERT_FAMILY.md §2-4`）：
- ❌ 官方 Partner → ✅ 已注册加入 CPN / CPN 合规通道
- ❌ 保过/稳过/必过 → ✅ 冲刺过考
- ❌ 含考试名额/名额已激活 → ✅ 为你开通 Partner Academy 账号
- ❌ 对外写考试费金额 + 露包价 → ✅ 让学员知道另付、金额私聊

## 2. 目标与漏斗反推

> 非技术受众决策更轻、更依赖内容种草。路径「内容触达 → 咨询私信 → 销售私聊 → 报名」。比例 `⚠️ 假设/待补`。

```
首期报名目标：N 人  ⚠️ 待补
  ↓ 咨询私聊 → 报名转化：假设 20%（非技术受众决策周期短但客单敏感）
咨询私信目标：5N 人
  ↓ 内容触达 → 私信转化：假设 2.5%（小红书泛受众私信率高于技术受众）
内容总触达目标：约 200N
  ↓ 各渠道分摊（非技术受众版，小红书权重最高）
  - 小红书种草：45%（主战场 —— 泛知识工作者最活跃）
  - 公众号长文：25%
  - 朋友圈/社群真名发声：20%
  - 线上说明会：10%
```

⚠️ 待补 ground truth：首期席位数、报名目标、非技术受众实际私信率（无历史数据，全行业基线）。
