## 1. 课程定位摘要

## 2. 目标与漏斗反推

> 🚨 这一节和 skill 模板给的标准三档漏斗模型对不上，因为**这门课现在没有三档也没有引流课，只有一个价位在直接卖**。下面先写"现状怎么算"，再写"FUNNEL_PLAN 提议的三档一旦落地会变成什么样"，两套模型分开写，不要混在一起假装现在已经是三档在跑。

```

  ↑ 内容触达 → 咨询/加微信转化率：⚠️ 未知
  ↑ 各渠道 UV：⚠️ 未知（01/02 期招生时用过哪些渠道、效果如何，这次调研完全没找到记录）
```

这条链路现在**每一环都是问号**，不是这份文档偷懒不填，是真的没有任何历史数据可以拿来填。这本身就是一个值得点名的问题：**这门课已经卖了两期、真金白银招到了学员，但没有人系统记录过这些学员是从哪个渠道来的**。如果不先把这个数据缺口补上，03 期就算定了开课日期，也没法知道该把资源往哪个渠道倾斜，只能重新从行业基线猜起。

**FUNNEL_PLAN 提议的三档模型（仅供参考，等三档真正上线才能用这套算）**：

```
报名目标 N 人（自学 + 教学 + 陪跑三档合计，N 未定）
  ↓ 假设主课转化率 5%（行业基线，非本课实测）
加微信目标 20N 人
  ↓ 假设引流课 → 主课转化率 15%（同上）
引流课报名目标 3N 人
  ↓ 假设引流课页面 CTR 30%
引流课页面 UV 目标 10N 人
```

这套模型现在完全是占位——FUNNEL_PLAN.md 自己也标注了这些比例是"行业基线，不是该课程实测"。放在这里的唯一作用是提醒：等引流课真的上线，第一批数据跑出来之后，要回头把这套模型里的假设数字换成真实数字，而不是永远用行业基线糊弄下去。
