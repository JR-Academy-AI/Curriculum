System Design 面试问题分析
System Design 面试的标准流程：需求澄清（5min）→ 高层设计（10min）→ 深入设计（15min）→ Trade-off 讨论（10min）。面试官打分的 4 个维度。
30m
L14
📹 录播
什么是 Monolith
单体架构的特点：一个代码库、一个部署单元、一个数据库。优点：简单、容易调试。缺点：规模大了改不动、部署慢、团队协作冲突多。
30m
L15
📹 录播
什么是 Microservices
微服务架构：每个服务独立部署、独立数据库、通过 API 通信。什么时候该拆微服务、什么时候不该拆。面试中怎么回答"Monolith vs Microservices"。
30m
L16
📹 录播
什么是 Docker
Docker 解决什么问题（"在我机器上能跑"）、Image vs Container、Dockerfile 怎么写、docker-compose 管理多服务。面试常见 Docker 问题。
30m
