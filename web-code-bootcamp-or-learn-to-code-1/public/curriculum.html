W02线下带练

W2 线下带练：搭前端 — 看懂 AI 生成的 React 代码

180m

线下小班带练（Claude Code）· 2.5–3 小时 课前先看（录播自学库）： React 基础、组件、state、props 相关录播。 线下这堂课一起做： 用 Claude Code 搭出产品的前端页面，重点带你 逐行看懂 AI 生成的 React 代码 ——组件怎么拆、state 怎么流。 走出教室你会： 能读懂并改动 AI 写的 React 前端，不再是黑箱。

W03线下带练

W3 线下带练：搭后端 API — 请求、路由、响应

180m

线下小班带练（Claude Code）· 2.5–3 小时 课前先看（录播自学库）： Node / Express、REST API、HTTP 请求-响应相关录播。 线下这堂课一起做： 带练用 Claude Code 搭后端 API，讲清一次请求从前端到后端再回来的全过程、路由怎么设计。 走出教室你会： 能看懂并新增后端接口，理解前后端是怎么对话的。

W04线下带练

W4 线下带练：全栈打通第一个 CRUD

180m

线下小班带练（Claude Code）· 2.5–3 小时 课前先看（录播自学库）： 数据库（MongoDB / PostgreSQL）、CRUD 增删改查相关录播。 线下这堂课一起做： 把前端 + 后端 + 数据库三层用 Claude Code 打通，做出第一个能存能读的全栈 CRUD 功能。 走出教室你会： 亲手跑通一个完整全栈闭环，为本期项目立项做好准备。

180m
