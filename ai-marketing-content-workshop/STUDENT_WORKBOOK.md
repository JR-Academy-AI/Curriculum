```text

1. 最优先目标人群（只选一个）
2. 他们最常见的具体场景
3. 他们想解决的前三个问题
4. 他们真正想获得的结果
5. 他们购买前最大的三个顾虑
6. 一句话核心卖点
7. 三条支持卖点的证据
8. 品牌语气：三个关键词
9. 本轮内容唯一行动目标

规则：
- 只使用我提供的信息；资料不足时标注“待补充”，不要编造。
- 避免“赋能、引领、极致、颠覆”等空泛词。
- 每一点都要具体到可以直接指导文案。
```

## 3. 公众号 / 长文

先生成大纲：

```text
基于营销作战卡和主主题，为目标人群写一篇 1000–1500 字的公众号文章大纲。

结构：
1. 标题备选 5 个
2. 具体场景开头
3. 点出常见误区或问题
4. 提供 3 个有用的方法或判断标准
5. 用真实证据建立信任；资料不足则保留 [待补充证据]
6. 自然过渡到产品 / 活动
7. 以唯一 CTA 结尾

先只输出大纲，不写全文。避免新闻稿腔、空泛排比和虚假故事。
```

确认大纲后：

```text
按确认的大纲写出全文。保持段落简短、语言自然，每个方法都配一个场景或例子。不要新增任何未经提供的数字、评价或承诺。
```

编辑初稿：

```text
现在作为严格编辑审稿：
1. 删除套话、重复和过度形容
2. 标出所有缺少证据的主张
3. 把抽象表达改成具体场景
4. 检查标题是否兑现正文价值
5. 检查全文是否只有一个 CTA
输出“问题清单 + 修改后的成稿”。
```

## 4. 小红书笔记

```text
把已确认的长文改写为一篇小红书原生笔记。不是摘要，也不要照搬长文语气。

输出：
- 10 个标题：具体、有对象、有价值，但不夸大
- 1 个最推荐标题及理由
- 正文 500–800 字：前两行给出强场景或冲突；短段落；包含 3 个可收藏要点
- 结尾用一个自然问题促进评论，再接统一 CTA
- 5–8 个相关话题标签
- 3 页配图 / 卡片建议

限制：不编造亲身经历、客户评价、数据或“亲测有效”。少用 emoji，避免营销机器人语气。
```

## 5. 朋友圈文案

```text
基于同一营销作战卡，分别写 3 条朋友圈：

1. 预热型：用一个真实场景引发共鸣，不急着销售
2. 价值型：分享一个马上能用的小方法，建立专业信任
3. 转化型：说明适合谁、能得到什么、关键信息和 CTA

每条 80–150 字，像真人说话；不要连续感叹号、夸张承诺、虚假稀缺或整齐得像广告的排比。每条提供一个配图建议。
```

## 6. 短视频脚本与口播稿

```text
基于营销作战卡和主主题，写一条 45–60 秒竖屏短视频脚本。

请用表格输出：时间、画面 / 动作、口播、屏幕文字。
结构：
- 0–3 秒：目标人群一听就懂的钩子
- 3–12 秒：具体问题或常见误区
- 12–42 秒：三个有用信息点
- 42–52 秒：自然带出产品 / 活动
- 52–60 秒：唯一 CTA

随后单独输出“可直接念的口播稿”。
要求：短句、口语化、读速约每分钟 220–260 个中文字；不编造证据；不以“大家好，今天给大家分享”开头。
```

朗读后继续修改：

```text
这段口播读起来太像文章。请改成自然说话：缩短长句，加入合理停顿，删除书面连接词；保留事实、核心卖点和 CTA。总时长控制在 45–60 秒。
```

## 7. 一周发布计划

```text
把已经完成的内容安排成 7 天发布计划，目标是让同一批受众依次经历“认识 → 兴趣 → 信任 → 行动”。

用表格输出：
- 日期 / 星期
- 用户阶段
- 平台
- 发布内容
- 使用的内容角度
- CTA
- 需要准备的素材
- 发布后观察指标

约束：
- 不要连续两天硬性促销
- 长内容先建立母题，短内容负责拆解和提醒
- 对现有内容可拆成片段复用，但不要原文复制到所有平台
- 第 7 天安排复盘：记录浏览、收藏、评论、私信、咨询或成交
```
