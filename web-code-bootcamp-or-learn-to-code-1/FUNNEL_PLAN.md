## 1. 漏斗定位

- **主课方向**：16 周全栈**项目**班（React + Redux + .NET/Node/Spring Boot 多方向可选 + AWS + Agile + RAG/AI 模块）
- **主课时长**：16 周，明显长于市面上 4-12 周的短训营。周期越长，意味着决策周期大概率也更长——这是常识判断，PERSONAS 里"决策周期 3-8 周"这个字段目前还是 AI 推断，没有真实数据支撑，但周期长这件事本身是从课程时长直接推出来的，不算瞎猜。
- **目标用户**（详见 PERSONAS.md）：A 缺本地经验的新移民开发者（约 35%）、B 无项目作品集的应届/在校生（约 35%）、C 想转码的 Job Changer（约 20%）——这三个占比数字本身也还是 AI 推断，真实占比要等有人翻过 26-30 期学员名单才能确认（PERSONAS §7 task 1）。
- **业务模式现状**：单档主课，所有人不管背景不同都付同一个价格（$5360 早鸟 / $5900 标价），拿到的是同一套服务。本文档要评估的是要不要往"引流课 + 分档主课"这个更细的漏斗结构演化。
- **核心承诺**："16 周亲手做出 3 个能上线的全栈项目（含 1 个带 BA/DevOps/UI 协作的 Agile 团队商业项目），补齐简历上最缺的'本地项目经验 + 团队协作经历'那一块。"这句话直接对应新足迹论坛帖子里质疑的"这些成功案例是不是本来就有底子"——承诺的是"做出真实项目"这个可验证的过程结果，不是"保证找到工作"这个没法验证的结果承诺。

## 3. 主课要不要拆三档

**结论先说：不建议现在拆，建议先加引流课、跑通"单档 + 引流课"这个更简单的结构，看数据再决定要不要拆。**

**为什么不建议现在拆**：三档定价的核心逻辑应该是"不同的人愿意为不同深度的服务付不同的钱"，但目前没有任何真实数据能回答"这三类人（新移民 A / 应届生 B / 转行者 C）里，真的有一部分人愿意花更少的钱只要基础版吗"这个问题。如果贸然把现在的 $5360 拆成"$1980 自学版 + $3680 教学版 + $5360 陪跑版"，最大的风险是把现在愿意直接付 $5360 全套的人，用一个更便宜的选项分流走了——这在电商里叫"自相蚕食"（cannibalization），拆错了会让整体收入下降，而不是上升。现在唯一站得住脚的判断依据是：应届生 B 这个 persona 预算比较紧（学生预算，$5360 是笔大钱，PERSONAS 里 B 的决策周期和分期方案高度相关），如果真要拆，第一刀应该先照顾 B，而不是把三档一次性全铺开。

**如果未来真要拆，参考框架是什么**：不按"内容多少 / 周数"分档（16 周内容三档理论上是共用的），而是按**"最终做出并上线到什么程度的项目、拿到什么级别的求职服务"**分级——这个逻辑跟这门课"卖作品集不是卖知识"的定位是一致的。

| 档位 | 参考定价（AUD，占位提案，未验证）| 一句话承诺 | 差在哪 | 大概对应谁 |
|------|------|------|------|------|
| 自学版 | 约 $1980 | 跟着录播 + 社群答疑，独立做出 2 个个人全栈项目并部署上线 | 没有 Agile 团队项目、没有 1v1 简历内推 | B 里预算最紧、想先低成本试水的学生 |
| 教学版 | 约 $3680 | 16 周跟直播做，作业有人批改，完成全部 3 个项目（含 Agile 团队商业项目）| 比自学版多了直播互动 + 团队协作项目，但没有求职服务 | A / C 里更看重"团队协作经验"本身、暂时不着急求职服务的人 |
| 陪跑版 | $5360-5900（=现价）| 教学版全部内容 + 12 个月简历内推 + 1v1 求职辅导 | 现在卖的就是这一档 | A / C 里明确要"全套就业服务"的人 |

这一档定价的每个数字都是"参照同类型 bootcamp 分档惯例拍出来的占位数"，不是从这门课的真实成本或真实用户意愿倒推出来的，套用之前**一定要**先看 PERSONAS 决策周期字段有没有真实数据。另外提醒一句：自学版价格不能定得太低太接近 `ai-programming`（$860-1360 那档零基础入门课）——本课定位是给"已经有编程基础、要做作品集找工作"的人，跟零基础入门课不是一个客群，拆档时如果自学版价格压得太低，会跟公司自己的另一门课抢生意。

**承诺红线**（不管拆不拆档都适用）：不写"包就业 / 保 offer / 12 个月内推保证进面"，只承诺过程结果——"做出 3 个能上线的全栈项目 + 完整作品集 + 团队协作经验 + 求职准备度"。这条红线这次有了更具体的理由：新足迹论坛那条帖子里，已经有真实用户在质疑"这些成功案例是不是本来就有底子的人",如果营销物料再往"保证找到工作"这个方向加码承诺，只会让这类怀疑更容易坐实。

## 4. 引流课方案

### 现状缺口是什么

现在潜在用户从看到销售页到掏 $5360-5900（含税实付 $5896-6490），中间没有任何低成本的"先试试"环节——要么直接咨询报名，要么因为价格和周期太高直接流失。16 周 + 近六千澳元这个决策成本，对"还在犹豫要不要重新投入学编程"的人（尤其是预算紧的学生 B、还在权衡"转行值不值"的 C）来说门槛偏高，而现在的漏斗里没有任何东西能接住这批"感兴趣但还没下定决心"的人。

### 引流课在内容上是可行的：真的有现成的课能拆

去核对了大纲（`outline.json` 里 26-28 期的真实 lesson 列表，不是凭空设想）,确认早期课程里确实存在能直接拿来做引流课的内容：

- 26 期出现过 **L115「5 分钟手动部署 Web Application 到 AWS S3 静态网站」**
- 28 期出现过 **L117「GitHub Action + CICD 自动部署上线：让你的 CareerMate 网页全球可见」**
- 每一期最早的 20 节课左右都是 HTML/CSS/JS/Git 基础课（如 L06「HTML & CSS 的奥秘」、L14「JavaScript」、L17「Git Introduction」）

这三类课拼在一起，正好能拼出"从写第一行 HTML 到把它部署成一个能打开的真实网址"这条完整链路，不需要另外生产新内容。**要提醒一点**：这门课自己的 `CLAUDE.md` 已经记录过一个已知问题——`outline.json` 的 `phases[]` 现在装的是"第 26/27/28 期"三期的课程原始快照，不是按教学模块整理过的结构，所以下面不用"Phase 0"这种叫法（那个层级实际不存在），只说"早期基础课 + 部署课"这个内容组合，等真要动手做引流课时，需要按 lesson 标题去匹配当前 production 里最新一期（30 期左右）的真实内容，不能直接照抄 26/27/28 期这几个旧快照里的 lesson code，因为不同期数、不同方向（.NET / Node.js / Java）课程编排本身就不完全一样。

### 具体提案

| 字段 | 内容 | 为什么这么定 |
|------|------|------|
| 主题 | 《3 小时从 0 做出并上线你的第一个网页项目》| 直接对应上面确认过的真实内容（HTML/CSS/JS 基础 + AWS S3 / GitHub Action 部署），不是凭空拟的主题 |

| 定价 | ¥99 / $29 AUD（澳洲本地为主，用 AUD 更贴合真实客群）| 沿用 `course-funnel-architect` skill 里引流课的行业惯例价，不是这门课自己验证过的数字。这里没有跟着项目通用规则强行配一个 CNY 对应数字，是因为 PERSONAS.md 三个买家 persona 全部指向"已经在澳洲本地"的人（新移民 / 澳洲在读留学生 / 澳洲本地转行者），不是还在国内准备远程购课的人，用 AUD 单一定价更符合真实客群，如果未来要单独做面向国内市场的招生（比如给 29 期这样的英文班或潜在的海外远程学员），需要销售团队先确认这批人是不是真的用人民币付款，再补 CNY 价格，不能凭这门课通用规则里"两币种成对出现"的默认惯例硬套 |
| Quick win 交付物 | 一个能打开的真实网址 | 对"没有作品集"的 persona B/C 是直接对症的 hook——他们的核心痛点就是"简历上拿不出真做过的东西" |
| 学完承诺 | "你已经独立做出并部署上线了第一个网页；主课带你做 3 个能写进简历的完整全栈项目（含团队协作经验）" | 把引流课的小成果和主课的大成果连起来，讲清楚"这只是开始，后面还有更多" |
| 转化逻辑 | 引流课让人亲手体验一次"我也能做出上线的东西"，7 天内不推销，靠展示差距自然过渡到"想做更完整、能讲团队协作故事的 3 个项目"这个诉求，也就是主课 | 呼应新足迹论坛的质疑——用户防的是"被架起来的营销承诺"，让人自己动手做出一个东西，比任何广告语都更能建立信任 |

**推荐路径**：`¥99/$29 引流课（从早期基础课 + 部署课拆出）→ 7 天不推销过渡 → 现有单档主课（$5360 早鸟）`。先不同时上引流课和三档拆分——两件事一起改，出了问题分不清是哪个环节的锅，先加一个变量、跑完一期看数据，再决定要不要拆三档。

**转化率假设**（这几个数字全部是同类课程的行业基线猜测，不是这门课的真实数据，第一期引流课跑完必须换成真实数字）：引流课页面到报名 ~30%、引流课报名到加社群 ~60%、社群到主课转化 ~10%（客单价高，转化率天然比低价课低，不能拿低价课的转化率基线套过来）。

## 5. 7 天过渡序列（骨架）

具体文案和执行细节要交给 `/funnel-handoff-design` 子 skill 去做，这里只给结构性骨架，明确每天该干什么、目的是什么。

| Day | 内容 | 目的 |
|-----|------|------|
| D0 | 引流课报名确认 + 交付真实上线 URL + 拉进社群 | 接住报名的人，不要让他报完名就没下文 |
| D1-D3 | 完成引流课正课和 Lab，当晚做出能打开的网址 | 完课体验 + 制造第一个 quick win |
| D4 | 拆解一个真实校友项目案例（带项目 demo 和去向）| 让人看到"完整版"长什么样，触发想象 |
| D5 | 差距分析：你现在做出了一个小页面，简历上还缺的是 3 个完整项目 + 团队协作经历 | 不推销，只是客观展示差距，让用户自己得出"我需要更完整的东西"这个结论 |
| D6 | 分享"自学 vs 跟着直播做 vs 全套求职服务"的选择参考 + 下期开课信息 + 早鸟截止日 | 给决策提供参考框架，不是硬推 |
| D7 | 早鸟截止提醒 | 给一个明确的行动窗口 |

**红线**：不群发课程链接、不假装"个人推荐"、不承诺"保 offer / 12 个月内推保证进面"。这条红线不是泛泛而谈——新足迹论坛那条帖子已经证明了，这个买家群体里存在会主动核实营销话术真假的人，任何一次"话说太满"被抓到，伤害的是整个校友案例体系的可信度，不是一次转化的得失。
