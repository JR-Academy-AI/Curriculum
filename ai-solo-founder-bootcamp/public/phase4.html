🎤 嘉宾现场课 · 180min
[现场课 · 嘉宾] 把生意讲成故事 · Pitch & BP

本周真实动作：把前 13 周的真实数据压成 deck + BP + 一页纸，并当着人讲三遍。Stan 在 W3 拆过你的 idea，W14 回来看你把它讲成什么样——一头一尾的书挡。

🎬 现场 3 小时 · 6 个环节

  1. ①三件套的分工与同源 + Stan：金字塔故事线、traction 前置25min deck 给 5 分钟的场合、BP 给愿意慢读的人、一页纸给邮件和官网。三者受众不同但事实必须完全一致——任何一处数字对不上，专业度立刻归零，所以三份从同一份 source of truth 生成。Stan 讲金字塔结构在 deck 上的落法：第一页给结论、接着三根支柱、每根支柱下面才是证据。并讲为什么一人公司的 deck 要把 traction 往前放——你最稀缺的资产是「真的有人付钱了」，不是市场有多大。
  2. ②自下而上做市场测算 + 现场出 deck v1 与一页纸30min 现场演示自下而上测算：真实客单价 × 你能触达的客户数 × 合理渗透率 = 可实现规模，再往上推三年路径；对比自上而下甩 TAM 为什么会被当场质疑。每人算一遍自己的数，然后把 source of truth 喂给 Canva / Gamma 出 10-12 页 deck 初稿和一页纸，人工调版式和图表。BP 长文档课后补。验收：deck 里每个数字都能追回真实记录，没有一个是编的。
  3. ③三档 pitch 讲法：30 秒 / 5 分钟 / 投资人版30min 三档不是长短剪裁的关系，是三套不同结构：30 秒版的目标是「被转述」，5 分钟版的目标是「被记住一个画面」（通常是你的活产品在跑），投资人版的目标是「经得起追问」。第一轮全员讲 30 秒，同组的人立刻尝试复述，复述不出来当场重写。第二轮抽 5 人上台讲 5 分钟版（含活产品演示），全场用 Demo Day 评分表打分：结构完整 / 演示是活的 / 数据真实可追 / 控时 / ask 明确。第三轮用语音模式让 AI 扮投资人做 8 问压力测试，答不上来的记下来补进 BP。
  4. ④融资入门：该融 / 不该融各 5 个判断点30min 融资换的不是钱，是控制权 + 增长义务。拿了 VC 钱你就从「$10k MRR 的自由」变成「追 $1B 估值的雇主」——要雇人、设 board、按季度汇报、被逼着烧钱抢市场。该融的三个硬条件要同时满足：已有 PMF（留存与复购真实）、市场窗口期短且先发优势值钱、资金能直接换增长速度。不该融的信号：还在找 PMF、靠融资续命、为估值虚荣、不想管人却要拿钱。现场每人对照打勾——设计预期是大多数人勾不满，结论是「继续 OPC」，这是好结果不是失败。
  5. ⑤Term sheet / SAFE / 估值：三个最容易被坑的条款25min SAFE = 先拿钱、估值留到下一轮再定，不立即稀释、不设利息、法律文件薄，是 YC 标准早期工具；priced round 要正式定估值 + 股权交割，耗时耗律师费。现场过 3 份 SAFE term sheet，标出三个坑：valuation cap（决定你被稀释多少）、discount（折扣率）、MFN（最惠条款），演示同一笔钱不同 cap 下你最终丢多少股权。结论：早期估值没有公式，是供需博弈，哪怕只融一次也要先看懂条款再签字。
  6. ⑥投资人 fireside：澳洲一线 VC + 加速器合伙人40min 两段对谈合并一场：本地一线 VC 讲他们看什么、不看什么、华人 founder 在澳洲 raise 的真实经验、被拒最常见的原因；加速器合伙人讲录取标准、申请材料怎么准备、6-12 周到底给什么、以及和这门 bootcamp 的关键差异（accelerator 拿 7-10% equity，bootcamp 不拿股权）。主讲老师主持控节奏挖具体案例，不让它变成宣传。学员每人限 1 个具体问题，禁止「请问您怎么看 AI」这种空问题。当场收集嘉宾联系方式发到班级群——这场最大的价值是 networking。

已确认支持本营的投资人 / 基金：Tick（天使投资人 · 墨尔本）、Sam（天使投资人 · 悉尼）、AirTree / Blackbird 背景投资人（澳洲头部 VC，已投 Canva / SafetyCulture）、极客公园基金 + 国内多支基金的合作资源。另有 Square Peg / AfterWork Ventures / Antler 墨尔本 / Startmate 悉尼 等持续对接中。待确认：当期 fireside 具体出席嘉宾名单在开课前公布。

⭐ DEMO DAY · 180min
[现场课] 登台 · Demo Day · 入会 Founder Club

本周真实动作：三城联合路演真上台讲 5 分钟，并在互为客户日当晚谈成第一笔同学生意。

🎬 现场 6 个环节

  1. ①三城联合路演：每人 5min pitch + 2min Q&A60min 墨尔本主场 10-12 人、悉尼卫星教室 6-8 人、布里斯班卫星教室 3-5 人，直播三城切换。每人 5 分钟必须包含一个活的产品演示（不是截图），2 分钟 Q&A 由评审团追问。评分沿用 W14 那张表：结构完整 / 演示是活的 / 数据真实可追 / 控时 / ask 明确。
  2. ②评审团总结 + 颁发结业证书20min 三位嘉宾各点评 5 个学员，讲具体的：哪个数字最有说服力、哪一页应该删、哪个 ask 提得不对。然后给完成 6 项毕业硬指标（$1+ 真实付费 / ABN 注册 / Grant 提交 / 10+ 内容产出 / 产品 URL Live / Demo Day 出席）的学员颁发结业证书。
  3. ③投资人对接：一页 pitch + 数据包怎么整理20min 把项目整理成投资人 30 秒能看懂的一页 pitch（问题 / 方案 / traction / 团队 / ask）+ 数据包（MRR / 增长 / 用户验证证据）。没有真实 traction 不强推——先有 $1 真实付费 + 增长信号，对接才有意义。
  4. ④匹配投资机构 + 主理人定向提交 / 引荐25min 按项目阶段和赛道匹配通道：本地 VC（Demo Day 评审席会后 intro）、美元 / 人民币基金定向推送、本地 venture club。由主理人代为提交或定向引荐并跟进反馈。说清楚边界：这是资源对接，不保证融资。
  5. ⑤互为客户日机制 + 进场卡片怎么填15min 晚宴前说明玩法：每人胸前贴两张卡片——「我能给的」（产品 / 服务 / 能力 / 客户引荐）和「我要的」（早期客户 / 投资 / 合伙人 / 服务采购）。卡片写具体不写虚的（不是「我会做 marketing」，而是「我能帮你两周内做出小红书内容机器」），这是当晚撮合的索引。
  6. ⑥三城本地圆桌 mingling + 老师 / 嘉宾在场撮合40min 每城 8-15 人小圆桌，同桌是本城同期同学 + 历届校友 + 嘉宾 + 本地 VC / 会计师。老师和嘉宾巡场，看到双方卡片契合主动 intro。5 类商业角色（互为早期客户 / 服务采购 / 合伙人 / 天使 / 引荐源）在这一晚直接落地。收尾每人写下今晚要跟进的 3 个具体动作，当场拉进 JR Solo Founder 校友群，接续毕业后 6 个月 Office Hour。
🍷 互为客户日晚宴 = 邀请制 + 被邀请到的人始终免费（餐饮 / 嘉宾 / VC / 校友 / Networking 全部包含在学费里，永远不另收钱）。
🟢 默认邀请：完成 6 项毕业硬指标的学员自动获邀。
🟡 有条件邀请：完成 4-5 项硬指标的学员，主讲老师在 W14 末 1:1 review 决定。
🔴 不邀请：Phase 1-3 完成度 < 50% / 缺席 ≥ 30% 现场课 / Demo Day 缺席 / 整期 ghost 不互动。
邀请制的目的不是收钱（晚宴一直免费），是保护被邀请的人 + 嘉宾 + VC 的网络质量——混子坐进 8 人圆桌，整桌 networking 价值掉 80%。这个机制把稀缺感从「入门门槛」移到「毕业门槛」，倒逼报名后认真做。

校友 · 持续
[W15·自学] Founder Club 入会：校友网络 · mastermind · 6 个月 Office Hour · 互为客户市场

🎓 毕业不是结束，是开始

毕业后进 JR Solo Founder 校友群（首期 + 后续期合并），会籍包含：校友网络（三城同期 + 历届）、mastermind（小组互查进展）、6 个月持续 Office Hour（每月一次线上，主讲老师 + 1-2 位嘉宾轮流主持，话题学员投票决定）、互为客户市场（平台 matching 工具持续可搜，「我能给的 / 我要的」长期挂着）、老带新（下一期晚宴你作为校友被邀请回来当嘉宾，双向永续）。

这部分的实际价值在于：毕业后 6 个月你做产品遇到具体问题（Grant 被拒了 / 第一次招外包 / 客户要求签 MSA / 考虑融资）时，有一群同样在跑一人生意的人能立刻答。

本周产出Demo Day pitch 录像 + 投资人对接材料 + 当晚 3 个 follow-up + Founder Club 会籍 卧槽点：台下坐着的人，有的当晚就成了你的客户、合伙人或第一张 angel check。
📌 Phase 4 后续还会继续加内容
已列入规划、尚未排进 W14-W15 的三块（待确认：具体排期与讲师）：谈判 / 成交（把 pitch 变成签下来的合同）· 媒体 / PR 曝光（从被搜到到被报道）· 投资人关系（把一次 fireside 变成持续 pipeline）。这三块面向的是已经跑起来、开始接更大单子的学员，会以校友 Office Hour 专场或后续期正式课的形式补上。
