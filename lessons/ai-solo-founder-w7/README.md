## 打开与操作

课件固定 1600×900（16:9）画布，所有窗口仅整体等比缩放，不作响应式重排。

不需要安装依赖或构建；双击 `index.html` 可离线打开，经营地图文件保持在同一目录。官方资料链接联网时使用。

也可从 curriculum 根目录启动：

```bash
python3 -m http.server 18747 --bind 127.0.0.1
```

入口：`http://127.0.0.1:18747/lessons/ai-solo-founder-w7/`

- 左右方向键 / PageUp / PageDown：翻页；Home / End：首尾页。
- F：全屏；N：当前页讲师提示（会显示在当前屏幕，投屏时请按需打开）。
- 目录：跳到指定页；`?page=N` 支持刷新与浏览器前进后退。
- 产品结构图：点击模块查看职责与早期简化方式。
- 第 42–43 页：可点击流程模拟，切换客户、运营和事件视角。
- 经营地图：自动保存至当前浏览器，支持 Markdown 导出与 JSON 备份导入。跨浏览器、跨来源和跨设备不自动同步，需导出备份；导入前提示替换。

## 课前准备与演示边界

T-1 发课件、经营地图与当天目标。学员准备产品入口、自己可操作的测试环境、收费与交付说明；不要收集凭据或客户隐私。

内置 Brief Studio 是课堂合成产品。全部价格、漏斗和成本算例均明确标注；演示不连接 Google Analytics / GSC、Stripe 或 Airwallex，也不会扣费。没有真实 provider 沙箱授权时，使用内置模拟讲清结构，真实接入状态保留 unavailable。不能把内置按钮称为 Stripe / Airwallex 真实测试。

数据工具演示：使用已授权网站的 Analytics / GSC 报告，查看访问来源、页面或搜索表现；不讲事件参数、埋点代码与 DebugView。真实支付演示：使用已授权的 provider 测试环境，对照订单、通知和权益。账户审批或权限受阻时，转需求卡与验收用例，不在全班现场开户或排长时间个案。

A / B / C 为三选一实操，不要求所有学员一节课同时完成 GA4 与支付集成。无工程条件者的需求 / 模拟状态与真实接入状态分开标注。
