# AI 一人创业营：15 周，每周日下午 3 小时，逐周做什么

先把最实际的三件事说完，再展开：

- **时长与节奏**：15 周。每周日 14:00–17:00 一节 3 小时线下现场课，周中自学与实操。整门课 53 个 lesson，15 节现场课，9 个互动 Lab。
- **总时间投入约 94 小时**：现场 45 小时 + 周中自学 42.4 小时 + Lab 6.2 小时。平均每周 6.2 小时，但不是平均分布（下面有逐周表，W4 那周会到 15 小时）。
- **上课形式**：三城线下 hub-and-spoke——墨尔本主场教室，悉尼、布里斯班卫星教室看同步直播 + 本地 Tutor 现场陪练（1:8）。不录播。

这门课的出口不是一张证书，是 6 项毕业硬指标：$1+ 真实付费、ABN 注册、Grant 申请提交、10+ 内容产出、产品 URL 公网可访问、Demo Day 出席。不达标不发结业证。

下面是 15 周逐周安排。每周写清三件事：**现场 3 小时做什么、周中自学做什么、这周结束你手上有什么**。

---

## 每周的固定节奏

15 节现场课的骨架是同一个：

```
开场 15min   → review 你的 AI OS 这一周替你跑出了什么
中段 30min   → 1-2 人上台讲进展 + networking（W2 起，W1 不做）
主体内容     → 本周的真实动作
下课前 5min  → 给 AI OS 派下周的活，定死「下周你要撞的那件真事」
```

这条主线叫 **AI OS**：课上搭好并派活 → 周中它自己跑 → 下节课开场先看它跑出了什么。在职的人时间碎，这条线是把「碎」从劣势变成优势的地方——你睡觉的时候它在跑调研、抓竞品、写周报。

另外两条贯穿全程的线：

- **MVP coding 全部走自学**（材料 + 录播 + Lab 自助完成），不占用周日 3 小时的现场时间。卡住的地方记进卡点日志，带到周日现场问。
- **组队**：开课前填「创业身份采集」分 A/B/C 三类——A 有 idea 草稿、B 有能力资源但方向未定、C 还在决定要不要下场。W2 开场按 A/B/C 混编 3-4 人一组，全程互查交付，到 W15「互为客户日」还在持续消费这个关系。

## W0 · 开课前 Pre-work（约 1.2 小时）

不是课，是不做会拖垮 W1 的准备动作。

**做四件事**：

1. **装机** —— 笔记本 macOS 12+ 或 Win10+ with WSL2，能正常访问 AI 工具。
2. **定 AI 订阅档位** —— 预算有限只买一个：Codex / ChatGPT；想更省：DeepRouter（匠人自研，可接 DeepSeek 等国内模型）；预算充足：Codex + Claude 双开。
3. **LLM API Key 注册 + 充值 $50** —— 15 周课程加上自动化任务，月烧大约 $30-100。
4. **ABN 前置材料 + 填创业身份采集表（A/B/C）**。

ABN 这件事之所以在开课前就提，是因为它跟装个软件不是一回事。W7 要真的收钱、W13 要定公司结构，这些在澳洲走流程是几天到几周的等待，不是当场能解决的。提前把队列排上，等到用的时候才不卡。

# Phase 1 · AI Enable Business（W1–W7）

> 出关物：一个被真实付过一次钱的、AI 化的产品，加一个上线的品牌官网。

## W1 · 搭起你的 CEO AI OS｜Your CEO AI OS

**现场 3 小时**（这周不做 idea 公开分享，全程可对试听开放）：

- **13:45 签到 + pre-work 抢救**（15min）—— 助教逐人核对三句：订阅登录了吗、笔记本能访问吗、身份采集填了吗。没就绪的当场救，不拖到动手环节。
- **① 你要走哪条路**（35min）—— 不讲「心智」这种虚词，讲遇到同一件事三种人怎么选：活干不完，VC startup 招人、传统创业招人、OPC 上 AI 不招人；缺钱，一个融资、一个贷款、一个靠第一笔收入养活自己；怎么算成功，一个看估值、一个看营业额、一个看每月进你口袋多少钱加你有多自由。落到一句话：这门课教第三列，不雇人不融资。**想做独角兽，这门课不适合你——现在说比第 10 周说好。**
  收尾做 **OPC 适配 5 维自评**（当场打分，不收上来）：财务储备 / 时间承诺 / 心智成熟 / 行业积累 / 抗孤独。讲师会点破一句：抗孤独这条最多人低估。
- **② 锁方向：当场写死一页生意 Source of Truth**（45min）—— 这一页是后面 14 周所有东西的源头。7 个字段逐个填，每个字段给好例子对坏例子：「服务谁」写「中小企业」不算，写「澳洲 5-20 人的华人会计师事务所」才算；「他现在怎么解决」写「效率低」不算，写「用 Excel 加手工核对，一个客户报税底稿要 3 小时」才算。第 7 个字段是**「不做什么」，必须写满 3 条**——一人公司死于什么都想做。
  写完同桌互念，对方只问三个问题：你服务的人能说出一个真名吗？这个优势别人为什么抄不走？不做的三件事写了吗？
  定规矩：这一期**只做一个方向**，要改必须带证据走 W3 那一关。每周换想法是这门课最常见的失败方式。
- **④ AI OS 选型**（30min）—— 五个方案横向比：Claude Cowork（桌面 App、GUI、1 小时上手、数据走 Anthropic 云）、OpenClaw（开源 CLI、本地 markdown memory、支持非 Claude 模型）、Hermes（跨平台、手机 IM 里派活、跨设备 memory）、Lindy.ai（零代码 SaaS、月费 $50-300）、自建（Crew AI / LangGraph + pgvector）。比五个维度：能干什么、月成本多少澳币、今天下午能不能跑起来、你的邮件日历喂进去存在哪、适合完全不写代码还是工程师。**讲完当场每人举手定一个**，助教登记分组——犹豫的人今天跑不起来，一周后更跑不起来。
- **⑤ 喂数据**（30min）—— 必接 Gmail（知道你在跟谁往来）+ Calendar（知道你的时间去哪了，这是在职创业者最关键的一块）；有时间再接 Drive / Notion。顺带把 ② 写好的 SoT 存进 OS 记忆库——从这一刻起它知道你要做什么生意。
  这是全课最容易翻车的环节：企业邮箱被公司 IT 锁权限大概率接不上，现场直接换个人 Gmail，不跟 IT 政策较劲。
- **⑥ 现场派 7 个秘书任务**（25min）—— 纪律是每个任务当场看到它真的吐出东西，不允许「回去自己试」，而且**每个任务都基于他自己刚写的 SoT**：读我这周日历告诉我时间花哪了 / 扫收件箱列出欠回复的重要邮件 / 根据 SoT 列 5 个竞品和定价 / 列出最该先接触的 10 类人 / 起草一封给潜在客户的介绍邮件 / 从我的日历里找出下周能挤出的 3 个工作块 / 总结我这周和这门生意有关的所有信息。
- **⑦ 派下周的活**（5min）—— 每人给 OS 设一个本周自动跑的任务。默认那条是：每天早上 8 点，把跟我这门生意相关的行业新闻和竞品动态整理给我。

现场还会放 2 个在职期间做成的真实案例。讲法是固定的五段：他是谁（必须是跟你一样在上班的人）→ **他那一周的日历长什么样**（周二晚 9-11 点干什么、周六早上干什么、通勤路上干什么）→ 前 10 个付费用户逐个从哪来（一个一个点名，不说「通过内容营销获客」）→ 现在每月多少钱、数据从哪来 → 他放弃了什么、死过几次。只讲好的部分，可信度直接归零。

> 案例的具体人选与数字，首期开课前会在课程页公布，不提前编。

**周中（3 小时）**：Lab「CEO AI OS 装机验收」90min，把现场没接完的接上；自学「7 个秘书任务跑满一周」90min——现场时间只够配 2 个任务，剩下 5 个自己配完，而且要真跑满一周。秘书这件事，跑一次是 demo，跑七天才叫上岗。

**本周产出**：一页 7 字段的生意 SoT（含 3 条不做清单）＋ 一个接了 Gmail/Calendar、跑通至少 5 个秘书任务的 AI OS ＋ 一个已经在自动跑的周任务。

## W2 · 你的 AI 员工上岗｜Agents at Work

W1 装的是秘书，这周装的是员工。

**现场 3 小时**：

- **四条 agent 路线现场选型**（30min）—— Hermes 适合想随时随地在手机 IM 里扔任务的人；龙虾（OpenClaw）开源 CLI + 本地 markdown memory，适合数据敏感的律师 / 会计 / 医疗类学员；Codex 跟 ChatGPT 订阅打通、写代码类任务顺手；Claude Code agentic 能力最强，适合要它连续改一个真实项目。按「你要它干什么活」选，不按「哪个最火」选。
- **装上 + 接权限**（30min）—— 现场跟着装，装完立刻接权限，逐项讲边界：**邮箱只给读和起草，不给直接发**；日历给读写；云盘按目录授权，敏感目录排除；代码仓库给分支写权限不给主干；浏览器自动化用独立 profile 不用你的主账号。
- **给 agent 写工作说明书**（30min）—— 五件事写清楚：负责哪几类任务、每类任务输入从哪来、交付物长什么样（格式 + 字数 + 必含字段）、什么情况必须停下来找人、输出送到哪。这一步是大多数人 agent 用不起来的真正原因——不是模型不行，是没人告诉它什么叫做完。
- **Agent Schedule 工作坊**（70min，TA 1:8 陪跑，每人现场配通）—— 五个案例：① 每天 7:00 抓竞品 pricing page，AI 总结变化后邮件告诉你「今天 X 涨了 $5、Y 推了新 plan」② 每周一 9:00 调 GSC API 拉上周数据，找流量掉的 query 和排名突变，出 200 字周报 ③ 每月 1 号 8:00 Stripe + Xero 出 MRR / churn / GST 月报推 Telegram ④ 每周日 18:00 汇总 git log + 邮件 + 日历出周报 ⑤ 每天 22:00 用 git log 和当天关闭的 issue 生成次日晨报。
  同时对照各平台的定时机制到底靠不靠谱：Cowork 的 /schedule（UI 最简单，但要 Mac 醒着且 App 开着）、Claude Code cron skill（wrapper + launchd）、Codex CLI 定时、OpenClaw cron（daemon 常驻，不依赖 Mac）、n8n / Zapier scheduled trigger、系统 cron 或 GitHub Actions 兜底。**先讲清楚再选，别用了一半才发现关机就不跑。**
- **验收 + 失败模式排错**（20min）—— 每人展示 5 条 schedule 的 cron 表达式和第一次跑的输出截图，过一遍 5 个失败模式：Mac 睡眠没跑、API rate limit、输出爆 token、push 出来没人看、AI 答错没人发现。每人挑自己最可能踩的两个，当场加兜底。

这周开场还有 30 分钟的分享 + **A/B/C 现场组队**：每人 60 秒亮牌「我是谁 / 我能给什么 / 我要什么」，同步录进平台 matching 工具。这里有个硬规矩——写「我会做 marketing」搜不到人，写「我能两周内帮你搭起小红书内容机器」才会被搜到。3-4 人混编组，选召集人，写不超过半页的组内契约：每周互查哪一项交付、卡住 24 小时内先找谁、谁做谁的第一个真实用户。

**周中（4 小时）**：让 agent 跑第一批调研 120min（Reddit 目标 subreddit 高赞抱怨贴、X 搜「I wish there was」、小红书评论里中文用户描述问题的原话，用 Perplexity 验市场规模）；Prompt Lab「AI 用户调研模板」30min；**自己去跟 5 个目标用户做 30 分钟访谈** 90min——问法走 Mom Test 那一套：「你过去一个月遇到这个问题几次」「上次遇到时你怎么解决的」「你为这个问题花过多少钱」，不问「你愿意付费吗」（用户嘴上说愿意，掏钱时全跑）。

**本周产出**：至少 1 个持证上岗的 agent ＋ 3 条以上跑过一次的 Agent Schedule ＋ 第一批调研报告 ＋ 5 场访谈记录。

## W3 · 这是不是一门好生意｜Prove the Business　⭐ 嘉宾 Stan（麦肯锡）

**现场 3 小时**：

- **顾问怎么看一门生意**（25min）—— Stan 讲三个基本动作：先把生意拆成可算的部件、再找结构性约束、最后看这个约束你能不能解开。对照 indie hacker 常见的三种自我欺骗：把兴趣当市场、把工具当生意、把忙碌当进展。
- **变现路径全景 + 赚钱算式**（30min）—— 订阅制软件、生产化服务、信息产品 / 课程、社群会员、佣金联盟、企业定制、授权模板，逐条给客单价区间、获客难度、创始人时间占用和天花板。然后把「能赚钱」压成一条算式：**客单价 × 目标单量 − 可变成本 = 月毛利**，再往前推单量靠什么来、每个来源产能上限多少。现场用 $1k MRR 和 $10k MRR 两个量级反推需要多少客户——很多人第一次发现自己的定价撑不到目标。
- **麦肯锡四把尺子**（25min）—— 市场规模自下而上算，不甩 TAM；竞争看「现在这些人的钱正付给谁」，包括 Excel 和实习生这种非软件替代方案；单位经济必须把你自己的时间折成钱算进成本，否则服务型生意永远看起来毛利很高；护城河对一人公司只有三种现实答案：行业积累、分发渠道、数据与流程沉淀。每把尺子当场打分。
- **现场拆 3-4 个学员 idea，Stan 主刀**（40min）—— 抽人上台讲 3 分钟，Stan 按赚钱算式 / 形态 / 结构性风险三层连续追问。台下同步在自己表上打分，看自己会不会被同样的问题问倒。被拆到当场想改方向的，走裁决流程改 SoT 原件，不新建文档。
- **产品形态 + 定价选型**（25min）—— 形态四选一（SaaS / 生产化服务 / 信息产品 / 混合），判断依据是客户买的到底是「工具」还是「结果」。定价五选一（一次性买断 / 订阅 / Freemium / B2B per-seat / 服务加软件混合），用「客户类型 × 使用频次 × 创始人时间占用」三维收口。
- **收口**（35min）—— 每人当场写四样：一条能算的赚钱算式、一个形态结论、一个定价模型加价格 anchor（竞品调研 5 家 + 价值锚 + 早鸟折扣 + 年付折扣）、Top 2 结构性风险及应对。讲师和 AI Tutor 现场挑战明显对不上的组合——选订阅但产品一年用两次，churn 必死。

**周中（2 小时）**：选品决策矩阵 60min（5 维度加权评分，把 W2 挖到的痛点砍到 5 个再砍到 1 个）；一页商业验证报告 60min。

这页报告是给你自己看的裁决书，四段，真的只准一页：① **证据段**——W2 的 5 场访谈里，有几个人「上个月真遇到过 + 真为它花过钱」，数字写实，0 就写 0（写 0 不丢人，写假的才要命）② **算式段** ③ **形态与定价段** ④ **风险段**。

**本周产出**：一页商业验证报告，以及一个「继续 / 转向」的书面结论。

## W4 · 做出能卖的东西｜Make It Real

这周分两条路，看你写不写代码。全课周中负担最重的一周（12 小时）也在这里。

**现场 3 小时**：

- **三种不写代码的交付形态**（30min）—— 生产化服务 / 信息产品 / AI 工作流代建，逐个讲客单价区间、毛利结构、每单要投入多少小时、能不能靠 AI 把边际时间压下去。这一节针对律师、会计、医生、咨询、PM 这类不写代码但专业积累很厚的学员——**他们的最短变现路径通常不是做 SaaS**。
- **交付物清单法**（30min）—— 把「我懂合同 / 我懂税 / 我懂招聘 / 我懂供应链」切成一个个具体交付物，每个写清：交付什么文件、多长时间、客户拿到后能干什么、定价多少。判断标准很硬——**写不出交付物名字的，客户也不知道自己买了什么。**
- **现场写交付 SOP**（35min）—— 讲师带一个真实例子走一遍：客户提交材料清单 → AI 第一步做什么（贴出真实 prompt）→ 中间产物长什么样 → 人工审核检查表 → 最终交付物格式。学员同步写自己的，**写不下去的地方就是产品化的断点**，标出来当作本周要攻的点。
- **用 SoT 生成三件套**（30min）—— 服务说明页 + 报价单 + 交付物模板，价格承接 W3 定的 anchor，当场写死。验收标准：三份文件都能直接发给一个真实潜在客户。
- **会 code 的：MVP 范围界定**（30min）—— 把功能清单分成「没有它产品不成立」和「有了更好」，后者这一周一律不做。逐条过范围膨胀陷阱：先做登录注册、先搭后台管理、先做多租户、先接支付。正确顺序是先让核心那一段价值能被一个真人用一次，**收款可以先手动发 invoice**。每人产出最多 5 条的 must-have 清单和一份明确的 not-now 清单。
- **两条路收口**（25min）—— 会 code 的写到「哪天部署上线」，不会 code 的写到「哪天把三件套发给第一个潜在客户」。写进组内共享 SoT，召集人本周中检查一次。

**周中（12 小时，全课最重）**：工具地图 120min（Cursor 是 IDE、Claude Code 是 agentic CLI、Lovable 是无代码 SaaS 生成器、v0 是 UI 组件生成——四个不是同一个东西）＋ PRD → MVP playbook 120min（AI 时代的 PRD 是写给 Claude / Cursor 看的，要明确技术栈、要给 example、要标 must-have vs nice-to-have）＋ 三个 Vibe Coding Lab（Cursor 入门 30min / Claude Code agentic 工作流 45min / Lovable 30 分钟 ship 一个能登录能部署的小 SaaS 45min）＋ Vibe Coding Hub Phase 2 章节 180min ＋ 部署到 Vercel / Cloudflare / Railway 90min ＋ 域名、SSL、Sentry、流量分析 90min。

**本周产出**：一个公网可访问的 URL（不是 localhost 截图），**或者**一份能直接发给客户的交付三件套。

## W5 · 立起你的品牌门面｜Brand & Website

全班一起做官网。核心不是「做个好看的网站」，是建立一种一劳永逸的做法。

**现场 3 小时**：

- **Source of Truth 模式**（25min）—— 一人公司最大的时间黑洞是反复写产品文案：网站、deck、brochure、公众号每份都从头写，改一处要改十处，最后各处说法互相打架。正解是先写 1 份 markdown source（定位 / USP / pricing / 受众 / FAQ / 5 个 use case / 竞品对比），所有 asset 从它生成，**绝不在某份 asset 里手改**。
- **现场写你产品的 markdown source**（35min）—— pricing 承接 W3 定的模型，target audience 承接 W2 那 5 场访谈的原话。访谈里客户的原话比你自己想的形容词值钱十倍。
- **品牌与 design system**（25min）—— 一人公司不需要 VI 手册，需要一张能让 AI 每次生成同一种感觉的清单：产品名和一句话说明、logo、主色辅色中性色各一组 hex、标题和正文两款字体、语气三个形容词加三个禁用词、图片风格选一种。全部写进 source 的 brand 段。
- **同一份 source 跑 6 个工具出全套**（40min）—— Lovable / v0 出 landing page，Gamma / Pitch 出「投 VC」和「找客户」两版 deck，Canva AI 出 A4 brochure 和一页纸 PDF，Notion AI 出客户 onboarding 文档，再出公众号长文 + 小红书标题 3 套 + X / LinkedIn bio。每次都把 brand 段一起喂进去，看视觉和语气有没有被锁住。
- **官网上线**（30min）—— 真的部署到公网并绑上自己的域名。首屏三件套现场逐句改：一句话说明你为谁解决什么、一个证据（真实客户原话 / 数据 / demo 截图）、一个明确 CTA。**课上禁止出现「赋能」「一站式」「全方位」这类谁都能用的词。**
- **验证一致性**（25min）—— 故意改 source 里的 pricing 一个数字，重新生成全套 asset，确认所有地方同步变了。没同步的那份说明你手改过，找出来改回从 source 生成。

**周中（1.5 小时）**：把剩下的对外资产从同一份 source 补齐——A4 一页纸 PDF、客户 onboarding 文档、公众号首图文、邮件签名、报价单模板。一份都不许手写。

**本周产出**：上线的官网 ＋ 一套写死的 design system ＋ Pitch Deck ＋ 一页纸。

## W6 · 别让项目烂尾｜Keep Shipping　⭐ 嘉宾 Ray（微软）

前五周做出来了东西，这周解决「做到一半停了」这件事。

**现场 3 小时**：

- **大厂项目管理落到一人公司**（25min）—— Ray 讲微软那套流程里对一个人还成立的部分：明确的 Definition of Done、写下来的优先级、固定的 review 节奏、风险提前登记。以及必须扔掉的：站会（没有团队要同步）、估点扑克、跨组对齐会、给 stakeholder 的进度汇报。**一个人硬套 Scrum 全套会死在仪式上。**
- **OPC 简化 agile**（25min）—— 只保留四个动作：周日 plan 选 5 项、每项写 DoD、工作日执行、周日 review。DoD 对一个人的真实价值是——它是你唯一的「可以停手了」信号。没有 DoD 的任务会被你无限打磨，或者永远差一点点不敢说完成。
- **把零散待办倒进 backlog**（35min）—— 现场把 W1-W5 攒在便签、微信收藏、脑子里的待办一次性倒进去，让 AI OS 按主题分类 + 按 RICE 和 Eisenhower 排序。**人工只做一件事：砍掉排在后 50% 的**。砍不下手的当场念出来，让同组的人帮你砍。
- **在职版可持续节奏**（30min）—— Ray 讲在微软高强度工作下怎么保住每周一个 3-4 小时深工作块：怎么排、怎么防止被占用、被打断后怎么快速回到上下文（AI OS 在这里的作用是替你保存上下文）。还有一个更现实的问题：连续两周没进展时，怎么判断是节奏问题还是方向问题。
- **让 AI OS 当 PM**（30min）—— 每天读 git commit / 邮件 / 日历判断哪几项动了，每周日 18:00 拉本周实际发生的事对照计划出 review 草稿，包含做完的、没做完的、以及根据你历史节奏给的下周容量建议。再配一条周三的中期提醒。
- **产出下周 5 项执行计划**（35min）—— 逐项写 DoD，标碎片还是整块，至少 1 项直接推进本 phase 的出关物。最后手动触发一次那条周日 18:00 的 schedule，看输出。

**周中（2 小时）**：在职版一周 sprint 模板 60min——周日 plan 选 5 项、工作日碎片任务池（每项 ≤60min）、周末一个深工作块、周日 review。模板里最有用的是「没做完的真实原因」这一栏：**连着三周同一个原因，说明你要改的是节奏不是意志力**。另 60min 是 AI OS 进阶：想换主线 agent 怎么迁移 memory 和 system prompt、双 agent 怎么配合、自建和团队 Brain 怎么做。

**本周产出**：AI OS 托管的已排序 backlog ＋ 下周 5 项带 DoD 的执行计划 ＋ 每周日自动生成的 review。

## W7 · 收到第一笔钱｜First Dollar

Phase 1 的出关周。这周刻意**不建任何获客系统**——内容、outbound、SEO 全部留到 Phase 2。

**现场 3 小时**：

- **为什么第一单必须靠刷脸**（20min）—— 0→1 验证的是「有没有人愿意付钱」，用熟人一对一验证最快；1→100 才是渠道问题。反面案例：花三个月做 SEO 和内容，第一笔钱还没收到就先耗光了热情和预算。
- **AI 盘点人脉 → 30-50 人排序名单**（30min）—— 导出微信标签 / LinkedIn 一度联系人 / 通讯录 / 行业群成员，让 AI 按「可能是买家 / 可能引荐买家 / 无关」分三桶，再按关系强度 × 需求匹配度排序。人工复核前 50 名，补上 AI 抓不到的（线下认识的、微信没备注的）。
- **一对一 pitch 三句话结构**（30min）—— 现场改学员写的原稿，重点挑两个病：**求人味**（「能不能麻烦您帮我看一下」）和**群发味**（第二句里没有对方的具体事）。第二句必须写一件真实发生过的事，写不出来说明这个人不该在名单前列。再过三种拒绝的标准应对：要免费、让你做好再说、嫌贵，练到不假思索。
- **现场真发 10 条一对一消息**（30min）—— 全场安静 30 分钟，每人真的发出去，发完在群里报数，讲师和 TA 现场帮改临门一脚的措辞。**这是整门课最不舒服的 30 分钟，也是转化率最高的 30 分钟。**
- **Stripe / Lemonsqueezy 澳洲版接入**（35min）—— 先讲差异：Lemonsqueezy 是 MoR（它当卖方，帮你处理全球税务和 GST），Stripe 是你自己承担合规但费率低、控制强；提现速度、退款流程、订阅管理各不相同。然后现场接：API Key → Checkout → Webhook → 退款测试，每人跑通一笔 test mode 交易，AI Tutor 1:1 排错。接入方式对应 W3 定的定价模型。
- **AI 生成 5 份法律文件 + AI 律师角色审**（35min）—— 第一笔付费前必须挂：Privacy Policy（澳洲 APP + GDPR 双合规）、Terms of Service、Refund Policy、Cookie Policy、Disclaimer。雇澳洲律师起草这套通常 $3-8k；课上走两层 AI 流程：第一层按产品类型、收款方式、数据处理位置、用户地区个性化填充；第二层把文件喂回去用「澳洲科技律师」角色 review，检查 ACL 条款、ATO 税务表述、GDPR 跨境数据传输、消费者保障漏洞、SaaS 退款合规，输出高中低三档风险清单。
  > 这是初稿加风险清单，不替代持牌律师的正式意见。

**周中（2 小时）**：从 test mode 切 live mode（Stripe 澳洲账号需要 ABN + 银行账户验证，首次提现有等待期）、GST 处理（营业额到 $75k 才强制注册，但收款前就要想清楚价格含不含 GST、发票怎么开）、Webhook 落库与失败重试、退款与争议流程，以及把 5 份法律文件真的挂上 footer。

**本周产出**：**第一笔真实付款到账**（毕业硬指标 #1）。验收要 Stripe / Lemonsqueezy / PayPal 后台截图，含交易时间、金额、买家——**不接受朋友亲属的友情付费**。

到这里 Phase 1 结束，你手上是：一个被真实付过一次钱的产品 + 一个上线的品牌官网。

## W8 · AI 内容工厂｜Content Factory

**现场 3 小时**：

- **小红书爆款笔记结构 + 私信转化**（40min）—— 先讲小红书、微信、抖音、B 站在用户、流量逻辑、变现路径上的差别，说明为什么澳洲华人 OPC 的第一内容阵地通常是小红书。然后逆向拆 3-5 个澳洲华人 indie 真实账号：标题公式、封面、正文结构、评论区运营、私信转化话术。每人写 3 个标题 + 1 篇完整笔记，AI Tutor 1:1 反馈。
- **视频号 + 公众号 + 私域三阵地闭环**（35min）—— 视频号吃算法推荐拉新、公众号做深度长文沉淀搜索流量、微信群做高频互动逼单，转化一定落在私域。现场用一个卖点一次喂出：视频号 60 秒口播脚本 + 公众号 2000 字长文 + 小红书 3 条钩子标题 + 群里一句话讨论引子。再搭转化链：文末群活码 → 进群欢迎语 + 落地页 → 7 天群内容节奏。会讲澳洲华人私域的合规边界（不能频繁群发、企微和个人号的风控差别）。
- **AI 视频、海报、漫剧：一条产线现场出片**（45min）—— 脚本 → 画面 → ElevenLabs 配音 → 数字人对口型（可选）→ CapCut 自动剪加字幕，一条片同时导出视频号 9:16、X 16:9、小红书 3:4 三个尺寸。同一素材再出静态：小红书竖封面、公众号头图、投流海报、产品 hero 图。漫剧只讲最难那个坎——**角色一致性**（三视图设定锁角色，再喂给动画工具保持跨镜头一致）。
- **X / Build in Public 并现场发出第一条**（35min）—— 逆向 5 个英文 indie hacker 账号，提炼帖型模板（milestone / 教训 / 数据截图 / build log）。每人现场写并真发一条：晒 W1-W7 做的产品、第一笔付费，或者一个教训。TA 过 hook 第一句、配图、CTA。
- **收口**（25min）—— 排出本周 4 平台的内容排期，对照「一次 launch 30 分钟出全套」的清单标出自己产线缺哪一环。

**周中（6.5 小时）**：内容工厂搭建 120min（周一 AI 选题 → 周三写初稿 → 周四出图 → 周五人工 review 加多平台分发）＋ 小红书标题生成器 Lab 30min ＋ AI 视频 / 海报 / 漫剧工具栈与成本产能账 150min ＋ X build in public 30 天内容日历 90min（四种帖型轮着发：milestone 数字要真、教训类互动最高、数据截图、build log 配一张丑但真实的截图）。

**本周产出**：一条能重复跑的内容产线 ＋ 本周至少 5 条已发布内容（含 1 条短视频 + 3 张图）。

## W9 · 主动敲开客户的门｜Outbound

**现场 3 小时**：

- **LinkedIn outreach 三段式**（25min）—— 个人化第一句（提对方近期发帖 / 公司 / 文章）+ 你能给的具体价值（不是索取）+ 低门槛 ask（看 30 秒 demo，不约会议）。重点讲那个最常见的错误：**把「个人化」做成了在模板里插入对方公司名。**
- **Claude 批量生成 100 条个人化 outreach + 人工卡点**（30min）—— 导一批目标 LinkedIn URL → AI 抓对方近期动态 → 按三段式生成开场白 → 人工抽审。必须留的人工卡点是三个：第一句的事实核对、ask 的门槛、发送节奏。
- **ProductHunt 冷启动作战图**（35min）—— 发布日前 24 小时决定 90% 排名：墨尔本时间凌晨 6 点 launch（对应 PT 12:01 AM）、提前一周预热 hunter 和朋友名单、动员 5-10 人首小时 upvote 加评论、首图 / tagline / 首条 maker comment 怎么写。现场每人填自己的日期和动员名单。
- **中英文圈 6 大线下渠道地图**（30min）—— 中文圈：华人 tech meetup（墨 / 悉 / 布）、微信群裂变、华人媒体 PR；英文圈：本地 tech meetup、Podcast pitching、founder feature 类媒体。**澳洲华人 OPC 的非对称优势是既能蹭中文圈又能蹭本地 tech 圈——绝大多数竞争者只在一个圈里。**
- **AI 跑线下营销 6 个动作**（35min）—— 抓 meetup / podcast / 记者列表并排序 → 写个人化 pitch 和演讲提案 → 模拟主持人做 30 分钟 Q&A 训练 → 出海报加朋友圈文案加引流落地页 → 写活动后 follow-up 话术 → 把一次活动反哺成线上内容。现场用一个 meetup lightning talk 拆成 5 篇小红书 + 1 篇公众号 + 5 条 X + 1 篇 LinkedIn 长帖 + 1 篇 SEO 博客。
- **收口**（25min）—— 20 个真实 outreach 目标加 3 条个人化开场白、ProductHunt launch 日期加动员名单、1 个线下渠道的 30 天 task 清单（落到墨 / 悉 / 布的具体活动或媒体）。TA 1:8 审话术是否过线。

**周中（1.5 小时）**：LinkedIn 个人化 outreach 生成器 Lab 30min ＋ Reddit / IndieHackers 社区策略 60min——这两个社区对 self-promotion 极度敏感（一发被删加 ban），但对「我用 X 解决了 Y 问题」这类价值帖欢迎度高，公式是 90% 价值 + 10% 软提产品。

**本周产出**：20 条已发出的个人化 outreach ＋ PH launch 作战表 ＋ 1 个线下渠道的 30 天计划。

## W10 · 让人和 AI 都搜到你｜SEO & GEO

**现场 3 小时**：

- **传统 SEO vs GEO：两套逻辑，两种写法**（30min）—— 课上给的口径是 ChatGPT search / Perplexity / Claude search 已经分走一部分搜索流量，所以要双线跑。传统 SEO 强 long-tail keyword、technical SEO、backlink；GEO 强 cite-worthy 内容、结构化数据、entity authority。**GEO 要的是能被 AI 整段引用的段落**（有明确结论、有可核实的数据、有清晰的实体关系），不是关键词密度。
- **拆真实 GSC 数据找 long-tail 机会**（35min）—— 用 jiangren.com.au 的真实 Search Console 数据现场演示：怎么找机会词、看哪些页有曝光没点击、哪些 query 已经被 AI 搜索引用，以及为什么新站前三个月只该做 long-tail。
- **用 AI 产 long-tail 内容矩阵**（30min）—— 每个词对应一个真实搜索意图，不是关键词变体堆砌。判断一个词你现在能不能排上，**看现有结果的质量和站点权重，不看搜索量**。
- **E-E-A-T 四要素落到产品页**（25min）—— Author 框带 LinkedIn、真实 case study、外部引用与媒体提及、联系方式与公司信息（澳洲的话把 ABN 放上去很加分）。
- **给产品页加 Schema.org JSON-LD**（35min）—— 现场加 FAQPage / SoftwareApplication / Person 三种，用 Cursor 直接写进页面，逐个过必填字段。
- **提交 GSC 验证**（25min）—— 现场提交 Rich Results 测试和 URL 检查，确认 schema 通过。定下 10 个目标词 / 3 篇优先内容 / 1 个 GEO 优化点。

**周中（4 小时）**：走 jiangren.com.au 的 `/learn/seo-master` 学习方向全部章节。SEO 是长期工程，系统过一遍，不只是看直播。

**本周产出**：10 个 long-tail 目标词 ＋ 3 篇优先内容主题 ＋ 产品页 JSON-LD 通过 Rich Results 测试。

## W11 · 用户增长｜Growth Hacking

Phase 2 的出关周。

**现场 3 小时**：

- **AARRR 五环 + 一人公司只能修一个环**（25min）—— 逐环讲常见误用：把访问量当获取成果、把注册当激活、把没退款当留存。「最大漏水环」原则：修转化率最低的那一环，投入产出比通常是修其他环的 3-5 倍。**一人公司同时修多个环等于一个都修不完。**
- **现场拉数据填五环表**（30min）—— 打开自己的 PostHog / Plausible 和 Stripe 后台，把各渠道访问、关键动作完成数、回访数、付费数、老带新数填进表。没埋点的当场补，**数据不足的先记「待测」不要瞎填**。逐环算转化率，跟三类产品的参考区间比，找出偏离最大的那一环，写下结论：本周只修这一环。
- **AI 出 3 个改法，选 1 个成为实验假设**（25min）—— 不要「优化文案」这种废话，要「把首屏的三段介绍换成一句用户原话加一个 30 秒 demo」这种。选一个写成假设：因为观察到 X，我认为做 Y 会让 Z 提升到 N。
- **三种循环 + K 因子**（25min）—— 激励型翻车在给现金和防刷没做；协作型翻车在产品本来就是单人使用还硬加邀请；产出型几乎不翻车但天花板低。最实际的做法是先上产出型（零成本），再看要不要加激励型。现场算一个 K 值例子，讲清为什么 K>1 在小众 B2B 里基本不可能。
- **选一种循环写完整机制**（25min）—— 奖励是什么（非现金）、触发点在哪（**用户刚获得价值的那一刻，不是注册时**）、怎么归因、怎么防刷。最小版本这周就要上线：写代码的加一个带参数的分享链接；不写代码的在交付物页脚、邮件签名、报告封底加一行来源链接。
- **一个 launch 跑通 10 渠道 + 营销 OS 闭环**（50min）—— 回看 W8-W11 学的所有渠道，画出「一个 launch 怎么同时点燃 10 渠道」的总图。选一个学员真实 launch 现场拆出全套 asset：1 篇 SEO 长文 + 10 条多平台短文 + 5 张海报 + 3 条短视频 + 1 套邮件序列 + 100 条个人化私信。最后跑一遍闭环：选题 → 写稿 → 出图 → 排程 → outreach → 数据回收反哺下周选题。

**周中（2.5 小时）**：付费投放最小实验 90min——花 $200 买一个答案（陌生人看到你的落地页会不会付钱）。四条规矩：只投一个渠道（B2B / 英文走 Google Search、C 端 / 视觉驱动走 Meta、中文华人受众走小红书）、预算封顶 $200 AUD 跑 7 天日预算 $30 以内、目的是买信息不是买增长、跑完写结论。另 60min 是增长实验系统：实验卡片五个字段（假设必须写数字、最小实施、看哪个数、结果、留下什么）。**一周一个实验，连着跑半年就是 26 个实验。**

**本周产出**：五环诊断表 ＋ 一个已上线的推荐机制 ＋ launch checklist 与 AI 营销 OS 工作流图。

# Phase 3 · Australia Operations（W12–W13）

> 这两周是这门课在全球范围内最难被复制的部分：AI 一人创业 × 澳洲税务与 Grant。

## W12 · 让生意自己运转｜Autopilot

**现场 3 小时**：

- **四个 database 的边界**（20min）—— 一人公司日常是 5-10 个客户 + 10-20 个任务 + 1 个产品，一个 Notion workspace 就够，**不要上 Salesforce / HubSpot**。CRM 跟人、Revenue 跟钱、Tasks 看板、Docs 放 PRD 和营销素材。重点讲为什么 CRM 和 Revenue 必须拆两张表。
- **现场搭 CRM + Revenue + Tasks 三张表**（35min）—— CRM 字段：客户名 / 公司 / 阶段（Lead→Trial→Paid→Churned）/ 金额 AUD / 来源 / 下次跟进日，用 rollup 加 formula 自动算 pipeline 总额，建「本周要跟进」的 filter 视图。Revenue 表记订单、客户 relation、金额 AUD、是否含 GST、日期。学员当场把 W1-W11 攒的真实客户和第一笔付费填进去，验收标准是 pipeline 公式跑出一个真实 AUD 数字。
- **AI 客服三方案选型**（20min）—— 按隐私 × 技术能力 × 成本三轴：OpenClaw 本地、隐私强、要会终端；n8n self-host 或云都行、灵活、中等门槛；Zapier 纯云、最简单、贵。律师 / 会计 / 医疗这类敏感数据走本地方案。
- **现场搭客服邮件分流 + 接知识库**（35min）—— 新邮件进来 → AI 分三类（技术问题 / 退款 / 销售咨询）→ 技术问题草拟回复进草稿箱、退款转人工标记、销售咨询写进 CRM。光分流不够，**还要让 AI 用你自己的 FAQ、退款政策、定价来回答，否则它会瞎编功能或乱承诺退款**。每人用一封自己真实收到的客户邮件测。
- **经营看板先定口径**（25min）—— MRR 年付按 12 摊还是记当月、退款和 chargeback 怎么处理、澳洲收入含 GST 时要不要剔除、churn 按客户数还是按金额、渠道归因用首触还是末触。填完写进 AI OS 记忆库，之后所有分析引用这一份。**口径不统一的数据看板，看了比不看更糟。**
- **LTV/CAC 分渠道 + churn 归因 + 自动简报**（45min）—— **CAC 要把你自己的时间折价算进去，不然内容渠道会显得免费**。把 PostHog 来源数据和 Stripe 付费数据 join 起来算每渠道的注册 / 付费 / 单客成本，把流失客户名单喂给 AI 做聚类找前三个模式和止血动作。最后固化成一条每月 1 号 8:00 的 schedule 推到手机。验收：简报里每个数字能追回原始数据源。

**周中（1.5 小时）**：AI 客服 prompt 设计 Lab 30min（系统用 50 条真实客户邮件测你的 prompt）＋ Stripe → Xero 自动同步 60min（Xero 在澳洲市占率高，所有澳洲会计师都用；开启集成后每笔交易自动进 Xero 做 bookkeeping，月底直接出 BAS 报告）。

**本周产出**：CRM / Revenue / Tasks 三库跑真实数据 ＋ 一条客服 flow 上线 ＋ 每月 1 号自动经营简报。

## W13 · 把钱从税务局拿回来｜Compliance & RDTI　⭐ 嘉宾 持牌 CPA / Grant consultant

**现场 3 小时**：

- **四种结构决策树**（30min）—— Sole trader / Partnership / Pty Ltd / Trust 在税率、责任隔离、设立与维护成本、Grant 资格、未来引入投资人这五个维度上的差别。一个常见误解：**不是收入一到某个数就该开公司**，还要看你的收入是不是个人劳务型。
- **嘉宾真实案例：5 个临界场景**（30min）—— 年收入 $90k / 年收入 $180k / 准备接受外部投资 / 多人合伙 / 要申请 Grant，各自该选什么结构、为什么。现场 Q&A，学员带自己的具体数字问。每人当场写下自己的实体决策和三条理由。
- **PSI 规则：为什么你的公司结构可能白搭**（25min）—— Personal Services Income：若你 80% 以上收入来自单一客户、且卖的是你个人劳务而非产品，ATO 会把公司收入穿透按个人税率计，Pty Ltd 的低税率白用。四道测试（results test / 80% rule / unrelated clients / employment / business premises）的判断逻辑，以及为什么做技术咨询、设计、法律这类学员最容易踩。
- **真实案例 + CGT 与退出规划**（25min）—— 嘉宾拆一个做技术咨询、90% 收入来自一家公司、以为开了 Pty Ltd 就低税、结果触发 PSI 被穿透补税的案例。规避路径三条：多客户化、产品化（从卖工时转向卖订阅 / SaaS）、做好 80/20 测试记录。再讲 CGT：持有超过 12 个月个人可享 50% 折扣，符合条件时 small business CGT concessions 还能进一步减免。
- **RDTI 研发退税**（30min）—— 本周重头戏。资格四要件：实体类型（**必须是公司，sole trader 不行**，这一条直接反向影响上面的结构决策）、什么活动算 R&D（核心实验活动 vs 支持性活动的界定）、记录要求（同期记录，事后补写风险很高）、申请窗口（财年结束后 10 个月内）。Grant consultant 拆三个真实拿到退税的案例：分别是什么类型的开发、怎么归集支出、审核时被问了什么。
- **申请书结构 + AI 起草 + 1:1 评估**（40min）—— 技术不确定性怎么写、实验过程怎么描述、支出怎么归集（人力 / 合同 / 云服务）。每个学员现场算自己这三个月的 R&D 支出，嘉宾 1:1 评估要不要申请、还缺哪些记录。
  > **具体金额与资格判定以 CPA / Grant consultant 的正式意见为准。课程不承诺任何退税结果。**

**周中（4 小时）**：ABN / TFN / GST / BAS 实操 90min（跟着嘉宾录制的分步演示在 ABR 网站注册 ABN；GST 注册门槛是年收入 $75k，自愿可早注册）＋ 一年期财务规划模板 60min（经澳洲 CPA review 过的表：12 个月收入预测 / GST 预提 / 季度 BAS 准备金 / 个人 vs 公司税对比 / Super 自缴 / 应急储备）＋ 其他 Grant 全景对照 45min（EMDG 出口市场开发补贴、各州 Grant、联邦大额）＋ Grant 申请书 AI 起草 Lab 45min。

**本周产出**：实体决策书 ＋ PSI 自测结论 ＋ R&D 支出清单 ＋ RDTI 申请书初稿（对应毕业硬指标「Grant 申请提交」）。

# Phase 4 · Founder Club（W14–W15）

## W14 · 把生意讲成故事｜Pitch & BP　⭐ 嘉宾 Stan（麦肯锡，书挡回归）＋ 投资人 fireside

W3 那位把你的 idea 拆到只剩骨头的人，这周回来教你怎么把它讲出去。

**现场 3 小时**：

- **三件套同源 + 金字塔故事线**（25min）—— deck 给 5 分钟的场合、BP 给愿意慢读的人、一页纸给邮件和官网。三者受众不同但**事实必须完全一致，任何一处数字对不上专业度立刻归零**，所以三份从同一份 source of truth 生成。Stan 讲金字塔结构在 deck 上的落法，并讲为什么一人公司的 deck 要把 traction 往前放——你最稀缺的资产是「真的有人付钱了」，不是市场有多大。
- **自下而上做市场测算 + 现场出 deck v1**（30min）—— 真实客单价 × 你能触达的客户数 × 合理渗透率 = 可实现规模，再往上推三年路径。对比自上而下甩 TAM 为什么会被当场质疑。把 source of truth 喂给 Canva / Gamma 出 10-12 页 deck 初稿和一页纸，人工调版式和图表。**验收：deck 里每个数字都能追回真实记录，没有一个是编的。**
- **三档 pitch 讲法**（30min）—— 不是长短剪裁的关系，是三套不同结构：30 秒版的目标是「被转述」，5 分钟版的目标是「被记住一个画面」（通常是你的活产品在跑），投资人版的目标是「经得起追问」。第一轮全员讲 30 秒，同组的人立刻尝试复述，**复述不出来当场重写**。第二轮抽 5 人上台讲 5 分钟版（含活产品演示），全场用 Demo Day 评分表打分。第三轮用语音模式让 AI 扮投资人做 8 问压力测试。
- **融资入门：该融 / 不该融**（30min）—— 融资换的不是钱，是控制权加增长义务。该融的三个硬条件要同时满足：已有 PMF、市场窗口期短且先发优势值钱、资金能直接换增长速度。不该融的信号：还在找 PMF、靠融资续命、为估值虚荣、不想管人却要拿钱。**现场每人对照打勾——设计预期是大多数人勾不满，结论是「继续 OPC」，这是好结果不是失败。**
- **Term sheet / SAFE / 估值三个坑**（25min）—— 现场过 3 份 SAFE term sheet，标出 valuation cap、discount、MFN 三个坑，演示同一笔钱不同 cap 下你最终丢多少股权。
- **投资人 fireside**（40min）—— 本地一线 VC 讲他们看什么、不看什么、华人 founder 在澳洲 raise 的真实经验、被拒最常见的原因；加速器合伙人讲录取标准、申请材料怎么准备、6-12 周到底给什么，以及跟这门 bootcamp 的关键差异（**accelerator 拿 7-10% equity，bootcamp 不拿股权**）。学员每人限 1 个具体问题，禁止「请问您怎么看 AI」这种空问题。当场收集嘉宾联系方式发到班级群。
  > VC 与加速器嘉宾人选正在敲定，确认后在课程页公布。

**周中（1 小时）**：business vs VC 路线决策表（10 维度自评）+ 200 字「我接下来 12 个月走哪条」。

**本周产出**：10-12 页 pitch deck ＋ BP ＋ 一页纸 ＋ 三档 pitch 逐字稿 ＋ 融资与否的书面结论。

# 时间投入：在职的人到底要挤出多少

这是这门课被问最多的问题，正面回答。

**总量 93.7 小时**，三部分：

| 类别 | 时长 | 说明 |
|---|---|---|
| 现场课 | 45.0h | 15 周 × 每周日 3h |
| 周中自学 | 42.4h | 材料 + 录播 + 项目实操 |
| 互动 Lab | 6.2h | 9 个 Lab |

**平均每周 6.2 小时** = 周日下午 3 小时 + 周中约 3.2 小时（分摊到五个工作日，一晚约 40 分钟）。

但平均数会骗人。真实分布是这样的：

| 周 | 现场 | 周中 | 合计 | 备注 |
|---|---|---|---|---|
| W0 | — | 1.2h | 1.2h | 开课前准备 |
| W1 | 3h | 3.0h | 6.0h | |
| W2 | 3h | 4.0h | 7.0h | 含 5 场用户访谈 |
| W3 | 3h | 2.0h | 5.0h | |
| **W4** | 3h | **12.0h** | **15.0h** | 🔴 全课最重的一周 |
| W5 | 3h | 1.5h | 4.5h | |
| W6 | 3h | 2.0h | 5.0h | |
| W7 | 3h | 2.0h | 5.0h | 出关周，压力在「发消息」不在时长 |
| **W8** | 3h | **6.5h** | **9.5h** | 内容工厂搭建 |
| W9 | 3h | 1.5h | 4.5h | |
| W10 | 3h | 4.0h | 7.0h | SEO 系统学习 |

| W15 | 3h | — | 3h+ | Demo Day 实际全天 |

**三件要说在前面的事**：

1. **W4 是唯一一个需要你专门腾时间的周**（12 小时周中）。因为 MVP coding 全部下沉到自学，不占现场时间——这是设计取舍：3 小时现场时间用来做「一个人在家做不了的事」（当面被拆、当场组队、现场发消息、嘉宾 Q&A），能自己看视频学的一律不占。**建议提前排一次周末整块时间给 W4，或者在 W3 结束后就开始预热。**
2. **周中的时间不全是「学习」，大部分是在做你自己的项目**。跟 5 个用户聊天、发 10 条私信、写你自己的落地页——这些事你自己创业本来也要做，课程只是把它排进了固定档期，还给了一套模板和一个会催你的 AI OS。
3. **有一件事没法帮你压缩：周日下午 3 小时不录播。** 三城线下的价值在同桌互念、现场组队、被讲师当场逼具体、晚宴撮合，这些没法回放。缺席一次就是缺席一次。

课程官方口径给的区间是每周 8-11 小时（含项目实操的弹性上限）。按 outline 的实际排课算，多数周落在 4-7 小时，W4 和 W8 显著高于平均。

# 课程形式：三城线下 hub-and-spoke

- **墨尔本**：主场教室，嘉宾物理出席。

# 谁适合

按课程大纲写死的画像：

- **35-50 岁、在澳洲、有 5-15 年职业积累的专业人士**——senior 工程师、PM、设计师、咨询、律师、会计、医生、1-5 人小团队创始人。

# 谁不适合（这段比上面那段重要）

- **想做独角兽的**。这门课教的是不雇人、不融资、目标 $1k → $10k MRR 的一人公司。W1 第一个小时就会把这话说清楚，不会等到第 10 周。想走 VC track 的人，W14 有融资入门和 fireside，但主轴不为你设计。
- **想躺赚的**。这门课的毕业硬指标里有一条是「$1+ 真实付费，不接受朋友亲属友情付」。W7 有 30 分钟全场安静、每人真的发出 10 条一对一消息的环节。整门课最难受的部分不是学不会，是**必须去做那些让人不舒服的事**：找人、开价、被拒绝、再找下一个。
- **完全没有职业积累的**。W1 写 SoT 的第 4 个字段是「不公平优势」，W4 的整条不写代码路径建立在「把你的专业切成可标价的交付物」。刚毕业、没有行业纵深的人写不出这两样东西，勉强报名会在 W3 被拆到没话说。
- **不在澳洲、也不打算来的**。W12-W13 占总课时约 13%，对你无关，价格不变。W1-W11 加 W14-W15 全球通用，但 ROI 不如本地学员。
- **每周挤不出 5 小时、周日下午还经常被占的**。这门课的节奏靠「周日交付 → 周中被 AI OS 追 → 下周日被人问进展」这个循环推着走，循环断两次基本就跟不上了。
