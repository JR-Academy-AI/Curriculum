# OPC Idea Validator 学生 Skill 包

这个压缩包包含：

- `opc-founder-os`：读取 Founder Workspace、现有证据和下一道关卡。
- `opc-idea-validator`：准备真人访谈、整理客户证据，并作出继续、调整或停止的判断。

## Codex 安装

1. 解压 ZIP。
2. 把 `opc-founder-os` 与 `opc-idea-validator` 两个文件夹复制到 `~/.codex/skills/`。
3. 重新打开 Codex或新建任务。
4. 输入：`运行 $opc-idea-validator，检查我的访谈问题是否诱导，并等待我带回真实访谈记录。`

## 证据边界

AI 可以检查提问方式、整理你带回的脱敏记录、指出证据冲突和生成下一步测试。AI 不能代替目标用户接受访谈；角色扮演回答、未来购买意愿、称赞和生成截图都不能写进客户证据表。

## 课程过关

1. 完成课程要求的五场真人访谈；不足五场时如实记录数量。
2. `CUSTOMER-EVIDENCE.md` 将原话、解释、过去行为、当前替代、代价和承诺分开。
3. 保存至少一条支持证据和一条反证或冲突。
4. 写出 `continue`、`revise` 或 `stop`，并说明置信度和下一项最便宜的真人测试。
5. 由课程规定 reviewer 检查证据后，才可标为 `verified`。
