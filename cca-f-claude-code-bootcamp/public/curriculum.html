❓ 常见问题
我已经会用 Claude Code 了，还需要这门课吗？
如果你已经熟练，只想拿证，考试直通包（US$399，首期 US$299）更划算。这门冲刺班是给"想真正学会 + 顺带拿证"的人——如果你还没亲手搭过 MCP server、没配过 hooks、没做过多智能体，这门课的实战部分对你有价值。
实战是看录播还是真的动手？
真的动手。11 个 Quest 全部在你自己的终端 / 项目里做，AI 主动带练 + 逐步验证——装 Claude Code、跑第一个任务、写 CLAUDE.md、配 hooks、做 slash command、亲手搭 MCP server、用 subagents、设计上下文方案。学完这些都是你带得走的真实产出。
考试报名和考试费怎么算？
Anthropic Partner Academy 不对个人开放自助注册。匠人已注册加入 Claude Partner Network，通过 CPN 合规通道为你开通 Partner Academy 账号、打通报名准入，并全程陪你走完注册 → 约考 → 考场。考试费按官方标准，在 Partner Academy 结账时由你直接支付，不含在包价里。
你们保证过考吗？
不做"保过"承诺。我们承诺真实环境实战 + 系统对齐 5 大 domain + 2 套全真模拟 + 直播答疑，帮你把握最大化。没过按官方重考规则协助二刷。
