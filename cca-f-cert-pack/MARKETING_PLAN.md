# MARKETING PLAN · Claude 官方架构师认证 · 考试直通包

> 本文是 `cca-f-cert-pack` 的对外宣传策划 SoT。Landing、小红书、公众号、朋友圈、社群、销售私聊都从这里取方向和话术。

## 1. 命名原则

对外先说人能秒懂的名字，不要一上来用简称。

| 场景 | 推荐写法 | 说明 |
|---|---|---|
| 主名称 | Claude 官方架构师认证 | 首屏、封面、标题优先用这个 |
| 完整名称首次出现 | Claude 官方架构师认证 CCA-F（Claude Certified Architect - Foundations） | 先中文解释，再补官方英文名和简称 |
| 后文简称 | Claude 架构师认证 | 大多数渠道正文用这个 |
| 专业补充 | CCA-F | 只放在括号、FAQ、专业说明里 |

避免写法：

- CCA-F 考试直通包
- 成为全球华人首批 CCA-F 持证人
- 用报名限制当封面标题或主钩子

推荐改写：

- Claude 官方架构师认证 · 考试直通包
- 成为全球华人首批 Claude 官方认证架构师
- 匠人 CPN 合规通道 · 官方考试名额 · 系统备考路线

## 2. 产品定位

产品名：Claude 官方架构师认证 · 考试直通包

产品形态：

- 官方考试名额
- 系统化备考资料
- 报名与预约协助
- 场景题拆解
- 全真模拟冲刺
- 备考答疑社群

一句话定位：

> 成为全球华人首批 Claude 官方认证架构师。匠人通过 Claude Partner Network 合规通道，帮你拿到官方考试名额，并提供最短备考路线、场景题拆解和全真模拟。

核心不是卖资料，而是三件事：

1. 报名通道：通过匠人 CPN 合规通道申请官方考试名额。
2. 备考路线：把 Anthropic Academy 散课整理成 5-domain 最短路径。
3. 冲刺确定性：原创考点精析、场景题框架、全真模拟、报名陪跑。

## 4. 目标用户

优先人群：

- 已经在用 Claude / Claude Code / MCP 做项目的开发者。
- AI Engineer / Solution Architect / 技术顾问。
- 想给简历、LinkedIn、客户提案增加 Anthropic 官方认证背书的人。
- 做 AI 外包、Agent 项目、企业 AI 转型咨询的人。
- 已学过 Claude Code 实战班，但缺一张官方认证的人。

不适合人群：

- 完全没用过 Claude / Claude Code 的新手。
- 想从零学 AI 编程的人。
- 期待直播课、长期辅导、项目实战的人。

分流话术：

> 你只是差一张证，选考试直通包。你还没真正上手 Claude Code，建议选 Claude Code 实战冲刺班。

## 5. 核心卖点

### 卖点 1：官方考试名额 + CPN 合规通道

这是可信度支柱，但不要放成封面主口号。封面先讲“成为全球华人首批 Claude 官方认证架构师”。

推荐话术：

> Claude 官方架构师认证是 Anthropic 首个 Claude 官方技术认证。匠人已注册加入 Claude Partner Network，这个包通过 CPN 合规通道帮你申请官方考试名额，并走通 Pearson VUE 预约和考试准备。

### 卖点 2：省下几十小时摸索

推荐话术：

> Anthropic Academy 的官方课是免费的，我们不藏这件事。但官方课是散的，没人告诉你哪门课对应哪个考点、哪些必须看、哪些可以跳过。我们把它整理成 5-domain 备考路线，按考试权重和题型直接冲刺。

### 卖点 3：官方没有的原创冲刺件

推荐话术：

> 官方给你考纲，我们给你考点精析、场景题答题框架、全真模拟、逐题解析和考前清单。

交付物：

- 1 个官方 Claude 架构师认证考试名额。
- 5 大 domain 考点精析。
- 6 类场景题拆解。
- 全真模拟题。
- 逐题详解。
- 报名、预约、OnVUE 环境自检、重考规则答疑。
- 备考社群。
