FAQ
How much of the course is actually live?
21 live sessions (~32.5 hours total) with real engineers, reserved for project reviews, live debugging, and 1:1 coaching. Everything else — concept teaching, tool walkthroughs, and comparisons — is self-paced video and hands-on labs you work through on your own schedule. Same technical depth, instructor time spent where it actually moves the needle.
What programming background do I need?
Basic Python (variables, functions, data structures) and hands-on experience building a RESTful API. If you've built CRUD endpoints with Flask/FastAPI/Express, you're ready. No ML/DL background required — the course builds up from Transformer fundamentals.
What's the difference between Context Engineering and Prompt Engineering?
Context Engineering is the evolution of Prompt Engineering. Prompting is just the text of the instruction; Context Engineering is the whole information architecture — what to retrieve, how to manage memory, how to scaffold information for the model. Gartner's 2026 research found 57% of agent failures are context-design failures, not model failures.
How is this different from other AI courses?
Most AI courses are either pure theory or just API calls in a notebook. This one starts at Context Engineering and goes all the way to GraphRAG, a 3-way Agent SDK comparison, and AI Eval Engineering — all 7 capstone projects are deployable, not notebook demos. The focus is production engineering, not "it worked once in a notebook."
Do I need a GPU?
Phases 1-8 don't need one — API calls are enough. Phase 9 (Model Layer) fine-tuning uses Google Colab's free T4 GPU or an AWS EC2 GPU instance. You'll learn to fine-tune with Unsloth + QLoRA on consumer-grade hardware, using ~60% less VRAM than the traditional approach.
What is the ISA capstone project?
Intelligent Study Assistant — the project thread running through the entire course. You build a basic version during Foundation + Context Engineering, add document retrieval during the RAG phase, add tool use and multi-step reasoning during Agent Core + Multi-Agent, and optimize it with fine-tuning during the Model Layer phase. Your ISA levels up at the end of every phase.
Why learn 3 different Agent SDKs?
OpenAI's Agents SDK is the simplest (handoff-based), Claude's Agent SDK has the deepest tool integration (native MCP), and Google's ADK is the strongest for enterprise (native A2A). Real companies mix and match, and interviews ask about the tradeoffs. You'll build the same task with each one and form your own opinion.
What can I do after finishing?
Independently build RAG + GraphRAG systems, multi-agent applications, and eval pipelines, and deploy them to production. You'll graduate with 7 demoable projects on your resume. Target roles: AI Engineer, AI Agent Developer, AI Eval Engineer, LLM Engineer.
