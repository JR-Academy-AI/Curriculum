**共 35 张课堂页。** W1 让学生建立了 Business SoT 和一个懂业务的工作空间；W2 把它升级成一个**有权限、有工作说明书、有排程的员工**：现场选一条 agent 主线，接上五类权限并划清边界，写出第一份 agent JD，中场交流并首次组队，然后在工作坊里把五条 Agent Schedule 配出来，最后过一遍失败模式、责任边界和本周作业。W1 的闭环不变，只是第二步不再需要人坐在电脑前。

## W2 的三个过关结果

1. **一个接好权限的 agent**：主线只装一条；五类权限按边界给完，敏感目录已排除。
2. **一份 agent JD**：任务范围、输入源、交付物规格、停下来找人的条件、输出落点，五段写全并存进 memory。
3. **5 条 Agent Schedule**：每条有 cron 表达式，至少一条手动跑过并留下真实输出截图。

闭环仍然是同一条，只是 agent 插在第 2 步：

> SoT → Agent JD + Schedule → 自动执行 → 人工检查 → 新证据 → 更新 SoT

**改 SoT 的权力只在最后一步，只属于学生本人。**

## 内容边界

- 四条路线只对照定位与适用场景，**不写价格、订阅档位与系统要求**（repo 内没有可引的定价真相源）。
- 装机页不复制具体命令行；Windows 路径以官方安装文档为准（见 `PRD.md` §5 未决项 2）。
- JD 示范页标注为课堂合成示例，不代表任何真实公司的运营数据或竞品情况。
- 涉及税务、合同、公司结构与持牌事项的段落只提示去咨询澳洲执业律师、会计师或相应持牌人士，不给专业意见。
- 学生可见页面不出现内部 lesson code、文件名或讲师备注。

## 版式

- 1600×900 固定画布，Register B 讲课视觉（3px 黑边 + 6px 硬阴影 + 暖底 `#fff1e7`）。
