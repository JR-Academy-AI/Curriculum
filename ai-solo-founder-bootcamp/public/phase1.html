L02
现场课 · 180min
[现场课] 搭起你的 CEO AI OS · Your CEO AI OS

本周真实动作：锁死一个方向写成一页 SoT，当场把 CEO AI OS 装起来并接上 Gmail / Calendar / Drive / Notion。

🎬 现场 3 小时 · 6 个环节

  1. ①OPC 心智 + 澳洲在职创业者案例 3-5 个35min OPC vs 传统创业 vs VC startup 三条路在团队、融资、营销、财务、心智每一层的差别。然后放两个真实案例：墨尔本 indie hacker（$3k-$10k MRR）和澳洲华人 micro-SaaS founder（$10k-$30k MRR），重点看他们在职期间怎么排时间、第一批用户从哪来。最后做 OPC 适配 5 维自评：财务储备 / 时间承诺 / 心智成熟度 / 行业积累 / 抗孤独能力。
  2. ②锁方向：当场写死一页生意 Source of Truth35min 7 个字段逐个填：服务谁 / 他现在怎么解决 / 我用 AI 做掉哪一段 / 不公平优势 / 收钱形态假设 / 6 周后可验证的证据 / 明确不做什么（不做清单必须写满 3 条）。写完存进当天搭好的 AI OS 记忆库，不是存在本地随手一个文件里。同桌互念，只问三个问题：你服务的人具体到什么程度？这个优势别人为什么抄不走？不做的三件事写了吗？定规矩——这一期只做一个方向，要改必须带证据走 W3 那关。
  3. ③创业身份 A/B/C 复盘 + 现场组队（贯穿 15 周）25min A 类（有 idea 草稿）提供可被拆的靶子；B 类（有能力资源、方向未定）补技术 / 行业 / 渠道缺口；C 类（还在决定下不下场）是全组最诚实的用户样本和挑刺人。每人 60 秒亮牌：我是谁 / 我能给什么 / 我要什么，同步录进平台 matching 工具（写「我会做 marketing」搜不到人，写「我能两周内帮你搭起小红书内容机器」才会被搜到）。3-4 人混编组、选召集人、写不超过半页的组内契约：每周互查哪一项交付、卡住 24 小时内先找谁、谁做谁的第一个真实用户。
  4. ④AI OS 选型：5 个 AI 秘书方案深度对比30min Claude Cowork（桌面 App / GUI / 1 小时上手 / 数据走 Anthropic 云）、OpenClaw（开源 CLI / 本地 markdown memory / 支持非 Claude LLM）、Hermes（跨平台 / 手机 IM 对话 / 跨设备 memory）、Lindy.ai（零代码 SaaS / $50-300 月）、自建（Crew AI / LangGraph + pgvector）。按 W0 选定的 AI 订阅档位分组，逐个讲强项弱项和月成本，当场定主线方案——装机细节留给本周的 Lab。
  5. ⑤超级记忆：把 Gmail / Calendar / Drive / Notion 喂进 agent25min 现场接通四类真实数据源，让 OS 从「聊天玩具」变成「知道你在干什么的秘书」：邮箱（历史邮件 + 联系人）、日历（会议 + 空档）、云盘（合同 / 简历 / 过往项目）、Notion / Slack（笔记与讨论）。逐条讲授权范围怎么给、敏感数据怎么隔离（律师 / 会计 / 医疗类学员走本地路径）、memory 怎么组织成它下周还找得到的结构。验收：问它「我下周三下午有空吗、上一次跟 X 聊到哪了」，它答得对。
  6. ⑥干活：现场派 7 个秘书任务30min 当场把 7 个任务配进 OS：① 每日晨间简报（日程 + 待办 + 昨日进展）② 邮件分诊与草稿 ③ 财务月报（Stripe + Xero → MRR / churn / GST 准备金）④ 会议笔记转决策清单 ⑤ 日程协调 ⑥ 客户跟进队列（7 天没回的自动提醒 + 上次上下文）⑦ 周报生成（git commit + 邮件 + 日历）。现场至少跑通 2 个并留输出截图，剩下的本周内补。合同审查那一类留到 W7 跟 AI 律师课联动。

📋 现场过关

下课前每人必须有：一页 SoT（已存进 OS 记忆库）、一个能读到你真实日历和邮件的 AI OS、一个组、至少 2 个当场跑通并有输出截图的秘书任务。

本周产出一页生意 Source of Truth + 一个跑得动 7 个秘书任务的 AI OS + 一个 A/B/C 混编小组 卧槽点：第一次有一个东西同时知道你的日程、邮件、文档和生意方向，而且它已经开始替你干活。
W2 · WEEK 2 你的 AI 员工上岗AGENTS AT WORK 周日 3h 现场课 · 周中自学 210min + Lab 30min
L05
现场课 · 180min
[现场课] 你的 AI 员工上岗 · Agents at Work

本周真实动作：给 agent 接权限、写工作内容、排定时任务，然后你自己去约 5 个真实用户。

🎬 现场 3 小时 · 6 个环节

  1. ①四条 agent 路线现场选型：Hermes / 龙虾（OpenClaw）/ Codex / Claude Code30min Hermes = 跨设备 + 手机 IM 里派活 + 常驻 daemon，适合想随时随地扔任务的人；龙虾（OpenClaw）= 开源 CLI + 本地 markdown memory + 不依赖单一模型商，适合数据敏感（律师 / 会计 / 医疗）的人；Codex = 跟 ChatGPT 订阅打通、写代码类任务顺手；Claude Code = agentic 能力最强，适合要它连续改一个真实项目。按「你要它干什么活」而不是「哪个最火」来选，现场每人定一条主线。
  2. ②装上 + 接权限：邮箱 / 日历 / 云盘 / 仓库 / 浏览器30min 现场跟着装。装完立刻接权限，逐项讲授权边界：邮箱只给读 + 起草不给直接发；日历给读写；云盘按目录授权，敏感目录排除；代码仓库给分支写权限不给主干；浏览器自动化给独立 profile 不用你的主账号。讲清楚哪些权限一旦给了就要有审计日志。
  3. ③给 agent 写工作内容说明书（它的 JD）30min 一份 agent 的工作说明书要写清五件事：负责哪几类任务、每类任务的输入从哪来、交付物长什么样（格式 + 字数 + 必含字段）、什么情况必须停下来找人、输出送到哪。写完存进 memory。这一步是大多数人 agent 用不起来的真正原因——不是模型不行，是没人告诉它什么叫做完。
  4. ④Agent Schedule 工作坊 案例 ①②③：竞品监控 / SEO 周报 / 财务月报40min ① 每天 7:00 抓竞品 pricing page → AI 总结变化 → 邮件「今天 X 涨了 $5、Y 推了新 plan」。② 每周一 9:00 调 GSC API 拉上周数据 → 找流量掉的 query 和排名突变 → 出 200 字周报。③ 每月 1 号 8:00 Stripe + Xero → MRR / churn / GST 月报 push Telegram + 存 Drive。TA 1:8 陪跑，每人现场配通。
  5. ⑤案例 ④⑤ 周报 / git 日报 + 跨平台机制对照30min ④ 每周日 18:00 git log + 邮件 + 日历 + memory → 周报存档。⑤ 每天 22:00 git log + 当天关闭的 issue → AI 总结 → 次日早上邮件「昨日做了 X/Y/Z」。同时对照各平台的定时机制：Cowork /schedule（UI 最简单但要 Mac 醒着 + App 开着）、Claude Code cron skill（wrapper + launchd）、Codex CLI 定时、OpenClaw cron（daemon 常驻不依赖 Mac）、n8n / Zapier scheduled trigger、系统 cron / GitHub Actions cron 兜底。讲清再选，别用了一半才发现关机就不跑。
  6. ⑥验收 + 失败模式排错20min 每人展示 5 条 schedule 的 cron 表达式 + 第一次跑的输出截图。过一遍 5 个失败模式：Mac 睡眠没跑、API rate limit、输出爆 token、push 出来没人看、AI 答错没人发现。每人挑自己最可能踩的两个，当场加兜底。

[W2·自学] 让 agent 替你跑第一批调研：竞品 / 市场 / 用户痛点

🎯 选品的核心是找到一个真实存在、有人愿意付费、AI 能解决的痛点

不是凭空 brainstorming。这一周你新装的 agent 就干这件事：一小时挖完 200+ 条 Reddit 真实抱怨、用 Perplexity 验证市场规模、从小红书评论里提取中文用户描述问题时的原话。四步：Reddit API + Claude 抓目标 subreddit 高赞抱怨贴 → X 搜「I wish there was」句式 → 小红书评论聚类 → 输出「痛点 × 频次 × 付费意愿」三维矩阵。这是选品最关键的输入数据，而且现在它可以定时自己跑。

L08
SELF · 90min
[W2·自学] 跟 5 个目标用户做 30min interview

不要问「你愿意付费吗？」——这是 indie hacker 最容易踩的坑（用户嘴上说愿意，掏钱时全跑）。用 Mom Test 那一套：「你过去一个月遇到这个问题几次？」「上次遇到时你怎么解决的？」「你为这个问题花过多少钱？」先用 AI 模拟面试一遍，再去真实用户那聊 5 个。这 5 场访谈的原话是 W3 商业验证和 W5 官网文案的原料，不能省。

W3 · WEEK 3 这是不是一门好生意PROVE THE BUSINESS ⭐ 嘉宾 Stan · 麦肯锡 周日 3h 现场课 · 周中自学 120min
L09
现场课 · 180min
[现场课 · 嘉宾] 这是不是一门好生意 · Prove the Business

本周真实动作：把 idea 过一遍麦肯锡式判断——市场规模、竞争、单位经济、护城河、产品形态、定价，全部定死。

🎬 现场 3 小时 · 6 个环节

  1. ①顾问怎么看一门生意：从情怀到结构25min Stan 讲咨询视角的三个基本动作：先把生意拆成可算的部件、再找结构性约束、最后看这个约束能不能被你解开。对照 indie hacker 常见的三种自我欺骗：把兴趣当市场、把工具当生意、把忙碌当进展。
  2. ②一人公司变现路径全景 + 赚钱算式30min 先铺全景：订阅制软件、生产化服务、信息产品 / 课程、社群会员、佣金与联盟、企业定制、授权与模板，逐条给客单价区间、获客难度、创始人时间占用和天花板。然后把「能赚钱」压成一条算式：客单价 × 目标单量 − 可变成本 = 月毛利，再往前推单量靠什么来（内容 / outreach / 引荐 / 搜索）、每个来源的产能上限。现场用 $1k MRR 和 $10k MRR 两个量级反推需要多少客户，很多人第一次发现自己的定价撑不到目标。
  3. ③麦肯锡四把尺子：市场规模 / 竞争 / 单位经济 / 护城河25min 市场规模自下而上算，不甩 TAM；竞争看的是「现在这些人的钱正付给谁」，包括 Excel 和实习生这种非软件替代方案；单位经济要把你自己的时间折成钱算进成本，否则服务型生意永远看起来毛利很高；护城河对一人公司只有三种现实答案——行业积累、分发渠道、数据与流程沉淀。每把尺子当场给自己打分。
  4. ④现场拆 3-4 个学员 idea（Stan 主刀）40min 抽 3-4 个学员上台讲 3 分钟 idea，Stan 按赚钱算式 / 形态 / 结构性风险三层连续追问。台下同步在自己的表上打分，看自己会不会被同样的问题问倒。被拆到当场想改方向的，走 W3 的裁决流程改 SoT 原件，不新建文档。
  5. ⑤产品形态决策 + 5 大定价模型选型25min 形态四选一：SaaS / 生产化服务 / 信息产品 / 混合，判断依据是客户买的到底是「工具」还是「结果」。定价五选一：一次性买断、订阅、Freemium（转化率 1-5%）、B2B per-seat、服务 + 软件混合。用三维决策框架收口——客户类型（C 端 / B 端）× 使用频次（每天 / 一次性）× 创始人时间占用，例如低频 + B 端 + 高创始人投入，大概率走混合模型而不是订阅。
  6. ⑥产出赚钱算式 + 形态结论 + 价格 anchor + Top 2 风险35min 所有人按同一套框架自查，当场写下四样东西：一条能算的赚钱算式、一个形态结论、一个定价模型 + 价格 anchor（竞品调研 5 家 + 价值锚 + case study 早鸟 30-50% off + 年付折扣）、Top 2 结构性风险及应对。讲师和 AI Tutor 现场挑战明显对不上的组合（选订阅但产品一年用两次，churn 必死）。最后明确这个定价模型对应 W7 哪种接入方式：一次性 = Stripe Checkout / 订阅 = Subscriptions / B2B = Custom invoicing / 混合 = 多产品组合。

什么时候必须找真人律师：投资协议 / SAFE notes / 股权分配、首位员工劳动合同（澳洲 Fair Work 极复杂）、单笔 $20k+ 的 B2B 客户合同、跨境出海（美国 Delaware C-corp / 中国数据出境）、被人 sue 或威胁 sue。课上发澳洲华人科技律师 fixed-fee 推荐名单。
