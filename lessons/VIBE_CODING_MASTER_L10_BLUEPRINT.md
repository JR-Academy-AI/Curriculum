# Vibe Coding 大师课 · 第十节蓝图

> 状态：DRAFT 1.0（2026-08-21 · 系列首次转向理论层）
> 主题：**四象限 AI 协作协议：信息在谁那里，决定谁该说什么**
> 课型：**90 分钟框架课**（不是讲座。前 32 分钟学员在写、在卡住、在看老师翻车，老师不许连续讲）
> 课堂硬产物：**一段学员自己的「开场四问」，可复用、可做成 Skill。**
> 本文只定义课程。Deck、`RUNSHEET.md` 与 `HANDOUT.md` 必须以本文为唯一事实源生成。

---

## 0. 立项决定

### 0.1 为什么第十节转向理论

L1 到 L9 全部是机制层：SoT、交付链路、Skills、诊断、Subagent、Team、老项目。九节课给了学员几十条规则，而**规则只在教过的场景里有效**。

第十节换的不是话题，是层次：

> 前九节给你动作，第十节给你一张能自己推出动作的图。

这个转向有一个必须承认的代价，写在这里防止后面自我欺骗：

**这节课不会让学员多一项能力。** 四个象限里有三个，学员已经会做对应的动作了（落盘、先让它说、派只读调查）。给动作起名字不等于给能力。这节课的价值只有一个：**让学员在没教过的第十种情况下做对。**

所以本节的成败判据只有一句，deck、讲稿、评分表全部围绕它：

> **一个学完的人，回去做下一个真实任务时，动作和没学的人不一样吗？**

如果学员离场时的状态是「思路更清楚了」，这节课失败了。它必须是「我以后每次开工前会先过一遍那四问」。

### 0.2 为什么 90 分钟够（关键：四条搬运动作，不是四个格子）

四个格子是一页纸的东西，讲完加举例 30 到 35 分钟就到底了，剩下的时间一定注水。

真正撑起 90 分钟的是**格子之间的搬运动作**。「协议」这个词的重量全在这里：

| 搬运 | 动作 | 前九节里是什么 |
|---|---|---|
| 隐藏 → 开放 | 落盘 | L1 到 L3 全部 SoT |
| 盲区 → 开放 | 先让它说，你别先下结论 | L6 诊断、L9 Discovery 前九步不改文件 |
| 未知 → 盲区 / 隐藏 | 设计实验（不是设计 prompt） | L7 三路只读调查 |
| **开放 → 隐藏（退化）** | **你没更新，它读到的是过期那份** | L9 知识债，但方向是反的 |

第四条是本节最值钱的一页，也是学员基本想不到的：**开放区不是稳定状态，是需要维护的状态。** 有了它，四象限从一张静态分类图变成一个有方向、有衰减的系统，才够一节课。

### 0.3 最重要的教学决定：图必须在第 32 分钟才出现

理论课只有一种死法：图在第 8 分钟上屏，之后 80 分钟都在解释一张已经在屏幕上的图。学员的姿态从「我在想」变成「我在听」，就再也回不来了。

本节的顺序是反的：

```text
0–20 分钟    学员回答四个问题（不给任何框架）
20–32 分钟   老师用自己的项目现场暴露一次盲区
32 分钟      图第一次出现，台词是「你们刚才填的东西有名字」
```

**这一条是全课唯一不可协商的节奏铁律。** 提前放图，这节课就降级成一场讲座。

### 0.4 本节在 L10 到 L14 里的位置

第十到十四节是理论线，尺度递增再收回：

```text
L10  四象限协作协议     信息：谁知道什么       一次对话
L11  抽象阶梯           层级：你在哪一层说话   你个人
L12  委托与可验证性     交付：怎么交，怎么验   一次任务
L13  系统思维与杠杆点   演变：长期会怎么样     组织与时间
L14  不可委托的东西     责任：什么不交出去     收回到你
```

**L11 到 L14 的排布和剂量尚未锁定**，本蓝图不替它们做决定。已知的判断是：五个框架里只有四象限、委托、杠杆点三个能产出「回去真会做的动作」，抽象阶梯和不可委托更像洞察而不是协议，可能应该并进别的节。所以 L10 的收口**只埋点、不承诺**：粒度问题埋给 L11，可验证性埋给 L12，退化循环埋给 L13。deck 上不要出现「下节课我们讲 X」这种硬承诺。

### 0.5 一处必须由讲师确认的定义

**四象限 AI 协作协议是讲师的原创框架，本蓝图是按它的「用法」反推出来的骨架。** 已知的用法是：把一次协作或 review 拆成开放 / 盲区 / 未知 / 隐藏四格，并且**在结尾单独留一格「只有你能回答的问题」**（那就是隐藏区）。

以下几件事本蓝图无法代填，必须讲师在做 deck 之前定下来（见 §16 附录 A）：

1. 四格的**中文定名**（本蓝图暂用开放区 / 盲区 / 隐藏区 / 未知区，讲师若有自己的叫法以讲师为准，全套材料统一）。
2. 每格的**判定标准**：一条信息该归哪一格，判据是什么。
3. 讲师自己**最常掉进哪一格**。这是开场第一句话的素材，别人替不了。

## 1. 课程定位

### 1.1 承接前九节

```text
L1–L3  SoT 三层          把你知道它不知道的东西写下来
L4     交付链路          让一条链走完
L5     Skills            把重复的话固化成能力
L6     诊断              它没有记忆，只有 context
L7     Subagent          给 context 分家
L8     Agent Team        让成员的发现改变别人的下一步
L9     Legacy            三种债，知识债最贵
────────────────────────────────────────────────────
L10    四象限            前九节全是这张图的推论
```

一句话承接：

> **L9 的知识债，就是这张图的隐藏区。** AI 能读出 `status == 7` 会导致 `skip_validation`，读不出**为什么是 7**。那句话在 L9 里是一个例子，在 L10 里是一整个象限。

### 1.2 全节立论

**开场立论（不在第一页说，在第 32 分钟图出现时说）：**

> **协作失败几乎从不是能力问题，是信息分布问题。**

**收口立论：**

> **开放区不是你达成的状态，是你维护的状态。**

中间全部内容都在回答两件事：信息现在在谁那里（四格），以及怎么把它搬到该去的地方（四条搬运动作 + 一条退化）。

### 1.3 核心框架

```text
                       它知道                     它不知道
                 ┌──────────────────────┬──────────────────────┐
                 │                      │                      │
     你知道      │       开放区         │       隐藏区         │
                 │   直接交，别废话     │   你不说它就编       │
                 │                      │   （最贵，会归零）   │
                 ├──────────────────────┼──────────────────────┤
                 │                      │                      │
    你不知道     │       盲区           │       未知区         │
                 │   先让它说           │   设计实验           │
                 │   你别先下结论       │   不是设计 prompt    │
                 │                      │                      │
                 └──────────────────────┴──────────────────────┘
```

搬运动作（协议的实体，比格子重要）：

```text
        隐藏区   ──── 落盘 ─────────────────▶  开放区
        盲区     ──── 先让它说 ─────────────▶  开放区
        未知区   ──── 设计实验 ─────────────▶  盲区 / 隐藏区
        开放区   ──── 你没更新，它读的是旧的 ─▶  隐藏区
                          （退化 · 唯一一条流出开放区的）
```

### 1.4 老师必须抓住的九个要点

1. **图不许提前出现。** 第 32 分钟，一秒都不许早。
2. **第三问（盲区）学员会卡住，卡住就是教学内容**，不许救场。
3. **老师必须现场承认一次自己的无知。** 这一句比任何定义都有效。
4. **隐藏区不要教「要落盘」，要教「你以为你落盘了」。** 学员学过 SoT，会觉得这格已懂。
5. **退化那一条不许提前讲。** 它是反转，提前讲就没有了。
6. **格子的边界不重要，搬运动作才重要。** 所有边界争议一句话止住。
7. **讲评只问「你这条属于哪一格」，不判对错。** 一判对错，框架当场退化成考试题。
8. **出处放最后说。** 开场说「这是 1955 年的 Johari 窗格」，注意力当场掉一半。
9. **收口必须是一个动作，不是一句总结。** 开场四问要能贴墙上，或者一句话调用。

### 1.5 最容易出错的五类地方

| 类型 | 容易错在哪里 | 当场纠正 |
|---|---|---|
| 节奏 | 图提前上屏，后面全在解释图 | 见 §10.1 铁律第 1 条，deck 里 P08 之前没有任何四格图形 |
| 深度 | 把课上成分类练习（这条算哪一格） | 「分不清就当隐藏区处理，也就是你多说一句，代价最小」 |
| 密度 | 老师讲成 90 分钟单向输出 | 硬指标：前 32 分钟连续说话不超过 3 分钟一段 |
| 敷衍 | 隐藏区被学员当成「SoT 我懂」跳过 | 让他们打开自己的 `CLAUDE.md`，数过期条目 |
| 落地 | 收口是感想不是动作 | 硬产物是一段可复用的开场四问，Exit ticket 收它 |

## 2. 学员起点与课堂门槛

### 2.1 学员应已具备

- 完成 L1 到 L9，尤其 L6（它没有记忆，只有 context）和 L9（三种债）。
- 手上有自己写过的 `CLAUDE.md` 或等价规则文件。**P13 要当场打开它。**
- **不需要能跑代码的环境。** 本节一行代码都不改。

### 2.2 课前必须带来的东西（入场券）

> **一个你这周真的要做、但还没做的任务**，来自你自己的项目。

三条硬要求：

1. **必须是真任务，不是假想任务。** 假想任务填不出隐藏区，因为你没有真的在乎过它。
2. 你能在课堂上打开对应的项目，**且不含敏感信息**。
3. 任务大小控制在「你原本打算今天下午交给 AI 做」的量级。太大填不完四格，太小填不出未知区。

课前 72 小时通知稿：

> 下节课请带**一个你这周真的要做但还没做的任务**（你自己的项目，能在课堂上打开，不含敏感信息），以及**你现在正在用的那份 `CLAUDE.md`**。不需要装环境，不需要能跑代码，这节课不改任何代码。也不需要预习任何东西。

### 2.3 没有合格任务的学员怎么办

三条兜底，按优先级：

1. **回溯法**：拿他上周已经做完的一件事，倒回去填四格，然后对照实际发生的事，看当时哪一格填错了。**这条其实教学效果最好**，因为有真实结局可以对照，缺点是没有真实的紧张感。
2. **借 L9 的老项目**：如果他上节课带了老项目，拿「给这个项目补第二份文档」当任务。
3. **公开仓库兜底**：助教发一个公开仓库地址，任务定为「给它加一个小功能」。这条最弱，因为隐藏区几乎是空的，要提前告诉他这一点，并让他在讲评时说出「我这一格为什么填不满」。

## 3. 学习目标

课程结束后，学员能够：

1. 说清「协作失败几乎从不是能力问题，是信息分布问题」，并用它解释一次自己真实失败过的协作。
2. 对一个真实任务填满四格，**四格都有具体内容，不许留空**。
3. 说出四条搬运动作，每条对应一个具体动作，而不是一句原则。
4. 承认并写出自己项目里的一个盲区（AI 能看出、他原先不知道的事）。
5. 区分「不落盘它就编」和「落到哪一层」是两个不同问题。
6. 说出开放区退化的机制，并在自己的 `CLAUDE.md` 里找出至少一条已过期的条目。
7. 区分「设计实验」和「设计 prompt」。
8. 说出哪些隐藏区**不能搬**（数据边界），并给出替代做法。
9. 产出一段自己的开场四问，并按 L5 的判断线决定要不要做成 Skill。
10. 说出这个框架借自哪里，以及它比原型多出来的是哪一条。

### 3.1 过关证据（全部落在产物形态，不落在标准答案）

学员离场前必须交出（针对自己那个真实任务）：

1. **一张填满四格的图**，四格都有具体内容。
2. **四条性质不同的指令**：直接交 / 先问 / 先落盘 / 先做实验，各一条。
3. **一条盲区记录**：AI 告诉他的、他原先不知道的一件事，写下来。
4. **一条过期条目**：从自己 `CLAUDE.md` 里挑出来的，附改后的版本。
5. **一段开场四问**：可复用、可粘贴、可做成 Skill。
6. **一条数据边界声明**：哪些隐藏区在他的环境里不能搬，以及替代做法。

**第 5 项是本节的硬产物。** 前四项都是课堂练习的痕迹，第 5 项是他回去真的会用的东西。没有第 5 项，这节课等于只上了一场讲座。

## 4. 非目标

本节明确不做：

- 不讲 Johari Window 的心理学背景和人际关系应用。**这不是一节沟通课。**
- 不做任何人格测评、性格分类、团队角色测试。
- 不重讲 SoT / Skills / Subagent / Team 的机制。只**重新解释**它们。
- 不教任何具体工具的操作和配置。
- 不给「正确的四格答案」。每人任务不同，本节不存在标准答案。
- 不把课上成分类练习。边界不重要，搬运才重要。
- 不展开 L11 到 L14 的框架，只埋点。
- 不改任何代码，不跑任何构建。
- 不比较 AI 工具优劣，只讲能力维度差异（§8.2）。

## 5. 第一幕 · 四个问题（0 到 20 分钟）

**这一幕的原则：老师只问，不讲。** 每个问题投出来之后，老师闭嘴，学员写。

**唯一例外是 0 到 3 分钟的开场**（P00 到 P01，说清今天的完成标准）。从 P02 投出「拿出那个任务」开始，到第 32 分钟图上屏之前，老师只问、只演示，不讲解。流程表（§10）里 0 到 3 分钟标的「讲」指的就是这三分钟，不构成例外之外的例外。

### 5.1 四个问题的定稿措辞

顺序不可调，措辞不要改（每一句都在避免提示框架）：

1. **这个任务里，有什么是你和它都清楚的？**
2. **有什么是你清楚、但你没写下来、你默认它已经知道的？**
3. **这个项目里，有什么是它能看出来、而你其实不知道的？**
4. **有什么是你们俩都不知道，必须真的试一次才知道的？**

四问投屏时**不许分组、不许加标题、不许编号成 2×2**。它们必须看起来像四个平行的问题。

### 5.2 第三问会卡住，不要救场

第三问是全课的支点。学员写不出来，因为**人不相信自己有盲区**。

老师的处理：

- 至少给 **90 秒沉默**。不要补充说明，不要举例，不要换个说法再问一遍。举例等于把答案给了。
- 90 秒后只问一句：「写不出来的举手。」举手会很多。
- 然后说：「记住这个感觉。这是今天最重要的一格。」
- **然后立刻切到 P07 老师演示，不解释。**

如果老师在这里心软给了例子，第二幕的现场证明就没有杀伤力了，因为学员已经有了一个「哦原来是这种东西」的答案。

### 5.3 第二问和第四问的常见塌陷

- **第二问会被写成技术细节**（用什么框架、代码在哪个目录）。这些其实是开放区的东西（它自己能看）。真正的隐藏区是**理由和约束**：为什么当初这么选、哪个客户不能碰、上次为什么回滚。老师**先不纠正**，留到 P12 讲落盘时用他们自己写的东西当反例。
- **第四问会被写成「我不确定 AI 能不能做到」**。那不是未知区，那是对工具能力的猜测。未知区是**关于这个系统本身**的未知：改了这里会不会有别的地方炸、这个模块到底还有没有人在用。同样留到 P18 再纠。

## 6. 第二幕 · 老师的盲区（20 到 32 分钟）

### 6.1 这一段的形式

**投屏。老师自己的项目。就是 L9 用的那个没有文档的老项目。**

老师让 AI 读一段自己写的代码或模块，要求它说出「三件这段代码的作者可能没意识到的事」。然后老师念其中一条，说那句话：

> **「这是我写的。它刚才告诉了我一件我不知道的事。」**

### 6.2 为什么必须是这个形式

L9 已经用过一次同类动作（「这是我写的，我现在不记得为什么了」），效果被验证过。这次更重：

| | L9 | L10 |
|---|---|---|
| 老师承认的 | 遗忘 | **无知** |
| 学员的反应 | 原来他也会忘 | 原来我也可以不知道自己不知道 |
| 教的那一格 | 知识债（隐藏区） | **盲区** |

**这一段不能排练。** 排练过的「惊讶」是假的，学员看得出来。所以老师课前只能做两件事：选定项目和范围、确认投屏不含敏感信息。**至于它会说出什么，老师不许提前跑。**

### 6.3 兜底（万一它说的三条老师全都知道）

有这个概率，必须准备好。老师的台词：

> 「三条我都知道。那说明这块我掌握得还行。**注意我刚才在干什么：我在用它校准我自己的盲区大小。** 这个动作本身才是今天要学的，不是它一定能吓到我。」

然后换一个更久没碰的模块再试一次。**如果第二次还全中，就承认「今天没抓到」并往下走**，不许硬演。诚实比效果重要，而且「他没演出来还照样承认」本身也在教东西。

### 6.4 兜底二 · 断网、工具挂掉、权限被拒、超时无响应

§6.2 的「不许提前跑」和「必须准备兜底」不是同一件事，前面几节的规格（L7 离线兜底、L8 环境降级矩阵、L9 预录输出）在这里同样适用。**排练禁令只针对当天要用的那个模块，不豁免运维兜底。**

三级降级，按顺序用：

| 级别 | 触发 | 做法 |
|---|---|---|
| **一级** | 当天那个模块调用失败 / 超时 | 换 §6.3 的备用模块，重跑一次。这仍然是现场的 |
| **二级** | 网络或工具整体不可用 | 投**课前在第三个模块上跑过的预录输出**，投的时候必须明说：「这是我课前在另一个模块上跑的，因为现在连不上。」**不许假装是现场的** |
| **三级** | 连预录也放不出来（投屏挂了 / 断电） | 口述那次真实发现，并当场说明：「今天这一格我只能讲，不能演。」然后**把 P05 第三问填不出来的举手数当替代证据**，那个数字本身就证明了盲区存在 |

二级用的预录**必须是第三个模块**，不能是当天要用的那个，否则排练禁令就形同虚设。这一条要写进 §15.1 课前清单。

**三级的代价要讲师提前知道**：P07 是本节唯一不许砍的演示（§10.1），降到三级时这一段的说服力会掉一半，但课程结构不会断，因为第三幕的揭示只依赖学员在 P05 卡住过，不依赖老师这次演示成功。

## 7. 第三幕 · 图第一次出现（32 到 44 分钟）

### 7.1 揭示（32 到 38 分钟）

图上屏。第一句话固定：

> **「你们刚才填的东西有名字。」**

然后把四问和四格对上，一格一句，不展开。接着给立论：

> **协作失败几乎从不是能力问题，是信息分布问题。**

**这里不许停下来讨论。** 学员这时候会想聊「所以我那次失败是因为……」，老师收一句「记住它，一会儿讲评时说」，往下走。

### 7.2 回收前九节（38 到 44 分钟）

一张映射表，说明**前九节全是这张图的推论**：

| 象限 | 前九节里对应什么 | 学员当时学的是 |
|---|---|---|
| 隐藏区 | L1 个人 AI OS、L2 PRD、L3 设计宪法、L9 知识债 | 一堆要写的文件 |
| 盲区 | L6 诊断三问、L9 Discovery 前九步不改文件 | 一套流程纪律 |
| 未知区 | L7 三路只读调查、L8 成员互改下一步 | 两种结构 |
| 开放区 | L4 交付链路 | 一条流水线 |

这张表的作用不是复习，是**换解释**：

> 你们学过的那几十条规则，不是几十件事。是四件事，加四个搬运动作。

这一页会引出一个必然的质疑：**这框架是不是事后套上去的。**

**挡法不许是动机声明。** 「这不是我事后编的」这类话是本节的禁句，理由有两条：

1. **动机是学员唯一无法验证的东西。** 你越强调自己没有事后编，越像在辩解，反而把这个念头钉牢了。
2. 它把命题从「这个框架站不站得住」偷换成了「这个老师诚不诚实」。**后者不该由学员来评估，也评估不了。**

正确的挡法是**交出一个可证伪的判据，然后让位给证据**：

> **一个事后归纳的框架，只能解释已经教过的东西。能推出没教过的东西的，才不是。**
>
> 待会儿有一条你们九节课里没见过的，它是从这张图推出来的。到时候你自己判断。

这个判据的兑现点是 **P19 的退化那一条**（Johari 原型里没有、前九节也没教过，纯从图里推出来的）。所以 P10 只下判据、不给保证，P19 负责兑现。**deck 和讲稿都不许出现「相信我」性质的表述。**

## 8. 第四幕 · 四条搬运动作（44 到 74 分钟）

### 8.1 搬运一 · 隐藏 → 开放：落盘（44 到 55 分钟）

**不要讲「要落盘」，学员已经学过三节课了。要讲「你以为你落盘了」。**

三步：

**第一步（2 分钟，含 P11 过场）· 用他们自己第二问的答案当反例。**
> P11「协议不是四个格子，是四条搬运动作」是本节唯一的过场页，约 1 分钟，时间从这一步里出。
> 它只列前三条搬运，**第四条留到 §8.5 当反转，不许在 P11 提前说**。
问：你第二问写的那几条，有几条其实是它自己能看出来的（代码在哪、用什么框架）？
结论：**真正的隐藏区是理由和约束，不是事实。** 事实它能读，理由只在你脑子里。这句话直接接 L9 的 `status == 7`：它能读出结果，读不出为什么是 7。

**第二步（6 分钟）· 打开你自己的 `CLAUDE.md`。**
现场动作，全班一起：打开文件，逐条标记。**上限：最多标 15 条**，文件更长的只标「你印象里最常被它违反的那 15 条」。6 分钟是按这个上限定的，不加上限这一步会吃掉整个 §8.1。然后老师问：

> **这里面有几条是三个月前写的，现在已经不成立了？**

举手会很多。**这就是 P19 退化那一页的引信，先埋不点。** 老师这里只说一句：「先记着，一会儿回来算这笔账。」

**第三步（3 分钟）· 粒度问题。**
落盘不是落越多越好。同一件事可以落在四个高度上：

```text
意图     我要一个能让用户找回密码的东西
规格     邮件链接，15 分钟过期，一次性
判据     过期链接必须返回 410，且不许发第二封
实现     用这个库、这张表、这个字段名
```

落太高它会自由发挥，落太低你等于自己在写代码。**这是本节唯一给 L11 埋的点**，一句话带过：「落在哪一层，是下一个话题，今天只要知道它是个问题。」不许展开。

### 8.2 国内环境与企业环境：哪些隐藏区不能搬（55 到 59 分钟）

这一段必须在落盘之后立刻讲，因为学员刚被鼓励「多写下来」，而他们回去要写的多半是公司的东西。

**先分级，再决定搬什么：**

| 信息类型 | 能不能搬进开放区 | 怎么搬 |
|---|---|---|
| 技术约束、架构决定、命名规范 | 可以 | 直接写 |
| 业务规则的**逻辑** | 一般可以 | 写规则，**去掉真实客户名和数据** |
| 客户身份、真实数据、密钥、合同条款 | 不可以 | **只写结构描述**：「有一类客户走特殊结算路径，标记在 X 字段」 |
| 受合规约束的代码本体 | 看密级 | 按公司规定，本课不替任何人做合规判断 |

**核心做法一句话：** 隐藏区搬不过去的时候，搬**它的形状**，不搬它的内容。AI 需要知道「这里有一条例外规则」，不需要知道「这条例外是给某某公司开的」。

国内工具环境只讲能力维度，不排名、不给具体产品的版本能力：**四问里没有任何一问依赖特定工具**。第一问到第四问在任何能读代码的助手上都能做。差距出现在盲区那一格（对陌生代码库能看出多深）和未知区（能不能自己设计并跑实验）。这两项差距真实存在，但**它不改变协议本身**，只改变每一格的搬运效率。

### 8.3 搬运二 · 盲区 → 开放：先让它说（59 到 64 分钟）

动作只有一句：**先让它说，你别先下结论。**

反例对照页（这一页比正例重要）：

```text
坏：  「这个 bug 是缓存没清导致的，你去把缓存逻辑改一下」
      → 你把答案说了，它只会顺着你找证据
      → 你的盲区被你自己焊死了

好：  「这个现象有哪几种可能的原因？各自需要什么证据？
       不确定的地方明确说不知道」
      → 它可能给你一条你没想到的
```

这就是 L6 的「它是在查还是在猜」和 L9 的「Discovery 前九步不改任何文件」的同一件事：**你先说结论，就把盲区关掉了。**

补一句 L7 的结论回收：**不给「不知道」一个出口，它就编。** 所以要盲区，就必须在指令里给它「我不确定」的位置。

### 8.4 搬运三 · 未知 → 盲区 / 隐藏：设计实验（64 到 67 分钟）

短，因为 L7 已经教过。要说清的只有一句区别：

> **未知区不能靠改 prompt 解决。** 你们俩都不知道的事，再怎么组词也问不出来。只能设计一个实验去把它变成已知。

三种最常用的形态（对着 L7 的能力，不重讲）：

1. **只读调查**：派出去翻，回来只给结论和证据位置。
2. **最小实验**：改一个最小的东西，看会不会炸。这就是 L9 的 One Change → One Goal → One Verification。
3. **观测**：加日志，等一周，用数据决定。这条唯一不能在课堂上做完，但必须提，因为很多未知区只有时间能回答。

### 8.5 搬运四 · 开放 → 隐藏：退化（67 到 72 分钟，反转页）

**全课第二个高光。** 前面三条都在教「怎么搬进开放区」，学员这时候形成了一个错觉：搬进去就结束了。

翻页：

> **开放区会漏回隐藏区。**

回来算 8.1 埋的那笔账：他们刚才在自己的 `CLAUDE.md` 里找到的过期条目，就是漏掉的部分。

```text
   你写了 CLAUDE.md（隐藏 → 开放）
            ↓
   项目变了 / 决定变了 / 人换了
            ↓
   你没更新（开放区悄悄过期，但看起来没变）
            ↓
   它每一轮照旧读那份过期的
            ↓
   「它又不守规范了」「它怎么又忘了」   ← 你以为是它的问题
            ↓
   你补一句 prompt 打补丁（改症状，不改源）
            ↓
   开放区继续烂，补丁越来越多
```

三句收口：

1. **开放区不是你达成的状态，是你维护的状态。**
2. 它退化的时候**没有报错**。这是它比另外三格危险的原因。
3. 你打的每一个 prompt 补丁，都是在替一条过期的开放区条目付利息。这句直接接 L3 的「修宪法 > 改页面」，也是给 L13 杠杆点埋的点（**一句带过，不展开**）。

### 8.6 止争页（72 到 74 分钟）

一定会有人问「那如果只有一半算哪一格」。这个讨论能吃掉 20 分钟。提前挡住：

> **格子的边界不重要，搬运动作才重要。**
>
> **分不清算哪一格的时候，当隐藏区处理。** 代价是你多说一句话，这是四种代价里最小的一种。

后半句既止争，又是个真判断：错当开放区的代价是它编（你不知道它编了）；错当盲区的代价是白问一轮；错当未知区的代价是白做一个实验；**错当隐藏区的代价只是啰嗦。**

## 9. 第五幕 · 落地（74 到 90 分钟）

### 9.1 动手：写你自己的开场四问（74 到 84 分钟）

**这是本节唯一的正式动手，产物是硬产物。**

要求：

1. 写成一段**你回去真的会用的话**，不是四个抽象问题的复读。
2. 必须包含四格各一条动作，**且四条的性质不同**（一条直接交、一条先问、一条先落盘、一条先做实验）。
3. 必须包含**给「不知道」的出口**（承接 L7）。
4. 长度控制：能一次粘贴，不超过屏幕一屏。

deck 上只给结构骨架，**不给范文**。给了范文所有人都会抄，四格就变成填空题。骨架：

```text
[任务]

已经确定的（直接做，不要重新讨论）：
  ...

我知道但可能没写在文件里的（照这个走，有冲突以这里为准）：
  ...

我不确定、想听你的判断的（先说结论和依据，不要直接改）：
  ...

我们都不知道、需要验证的（提一个最小实验，先别做）：
  ...

任何一条你不确定的，明确说「不知道」，不要猜。
```

原理页（「为什么这么组词」，本节必须有的一页）：

| 组词 | 为什么 |
|---|---|
| 四段**分开写**，不揉成一段 | 四格的信息要求不同的动作，揉在一起它会用同一种态度对待全部 |
| 「不要重新讨论」 | 开放区的东西被重开会浪费一整轮 |
| 「有冲突以这里为准」 | 隐藏区落盘之后要有优先级，否则它会拿代码现状压你的规则 |
| 「先说结论和依据，不要直接改」 | 盲区要的是它的判断，不是它的行动。**一动手就没法比较你和它谁对了** |
| 「提一个最小实验，先别做」 | 未知区最容易变成 scope creep（L9 危险一） |
| 「明确说不知道，不要猜」 | 不给出口它就编（L7） |

### 9.2 讲评（84 到 87 分钟）

**规则（写进 deck，念给学员听）：**

> 我只问一句：**你这一条属于哪一格，依据是什么。**
> 我不判对错。

理由要说出来：一判对错，学员就转向猜老师想要的答案，框架当场退化成考试题。**这条规则本身也是四象限的应用**：学员的任务在他的隐藏区里，老师根本没有判对错的信息。

抽三到四份，每份只问一句。**优先抽那些第三问填不出来的人**，让他们说「我为什么填不出来」，这比听一份填得好的更有价值。

### 9.3 出处（87 到 88 分钟）

**现在才说，一分钟。**

- 原型是 **Johari Window**（Joseph Luft & Harrington Ingham, 1955），用于人际关系里的自我认知。
- **四象限用于人机协作是本课的应用，不是 Johari 的原意。** 这一点要明说。
- **退化方向（开放 → 隐藏）是本课的扩展，Johari 原型里没有这一条。** 人际关系里信息不会自己过期，代码库里会。

为什么放最后：开场说「这是 1955 年的一个模型」，学员立刻把它归档成「学过的旧东西」，注意力当场掉一半。**先用完，再标出处。**

### 9.4 收口与作业（88 到 90 分钟）

收口一句（接 L5）：

> 这四问是你**每次开工都要说一遍的话**。第五节课我们定过一条线：**同一段话说到第三次，它就该是个 Skill。** 所以今天的作业不是复习这张图，是把这段话变成你敲一个词就能调出来的东西。

1. **退化那一段从 2 分钟扩到 5 分钟，止争页单独拿到 2 分钟。** 原来 2 分钟要装揭示、退化循环图、三句收口、止争页和四种代价对比，还要在同一格里放 P19 到 P21 三页，装不下。退化是全课第二个高光，被挤掉等于这节课白上。

3. **补时来源**：映射表 7→6、搬运一 13→11（粒度 5→3）、讲评 4→3、出处 2→1。**没有动前 32 分钟的任何一格**，因为第一幕是这节课的地基。

### 10.1 节奏铁律

1. **32 分钟前，四格图不许以任何形式出现在屏幕上。** 全课唯一不可协商的一条。包括：不许在封面画 2×2、不许在议程页写「四象限」、不许把四问排成方阵。
2. **前 32 分钟老师连续说话不超过 3 分钟一段。** 这一幕是学员在写、在卡住、在看老师翻车。
3. **第三问卡住时给足 90 秒沉默，不救场、不举例。**
4. **退化那一条不许提前讲。** 只在 8.1 埋引信（「先记着」），70 分钟才点。
5. **出处放到 86 分钟之后。**
6. **不安排中场休息。** 90 分钟课不需要，而且休息一旦放在 32 分钟之前，揭示的势能全放掉。真的需要就放在 44 分钟（映射表讲完），不许更早。**这一条是本系列的例外**：L5 到 L9 每节都排了 5 分钟休息，L6 同样是 90 分钟也排了。例外的理由只有一个，就是保护第 32 分钟那次揭示，讲师若不认这个取舍，改法是把休息放在 44 分钟并从动手段借 5 分钟，**不许放在 44 分钟之前**。
7. 时间不足时，砍的顺序是：粒度那一段（§8.1 第三步）→ 未知区三种形态缩成一句 → 映射表缩成一句话带过。**不许砍：四个问题的动手、老师的盲区演示、退化反转页、写四问的 10 分钟。**
8. **P07 的三级降级（§6.4）不占用预算。** 一级换模块吃的是 20 到 32 那 12 分钟里的余量，二级投预录反而更快，三级只讲不演最快。**降级是为了不超时，不是超时的原因。**

## 11. Slide 蓝图（28 页）

### 11.1 Deck 性质

- 每页只承担一个教学任务。
- **P00 到 P07 之间不许出现任何四格图形、2×2 布局、或「象限」二字。**
- **这条约束覆盖封面标题本身。** deck 的 P00 标题是「你以为它知道」，副标题「Vibe Coding 大师课 · 第十节」。真名「四象限 AI 协作协议」第一次出现在 **P08**，和图同时上屏。
- 浏览器标签页 `<title>`、`lessons.html` 卡片、文件名可以用真名（投屏时看不见），但**讲师若不全屏演示，课前要确认标签页标题没有暴露在投屏区域**。
- 四问全文、指令骨架、检查清单放 `HANDOUT.md`，deck 只显示当前那一问。
- 讲授页可以完整呈现结论；动作页只显示「现在做什么、完成判据、**限时多久**」。
- 🔴 **deck 上不许出现绝对分钟数。** 「硬停 52 min」「46–52 min」这类刻度是从上课那一刻起算的，属于讲师的东西。三条理由：
  1. **它把讲师架上被公开计时的位置。** 屏幕写 52、实际讲到 58，全场都知道你落后 6 分钟 —— 压力转移到讲师身上，学员的注意力从内容转到进度。
  2. **上课晚开始 5 分钟，全 deck 当场失效。** 绝对刻度只要有一个环节移位就全错。
  3. **P05 尤其不能有。** 那一页整个设计是 90 秒沉默，屏幕上挂个钟只会让人盯钟，不动脑。

  时间表**只存在于 `RUNSHEET.md`**（讲师的文档）。**动作页给时长**（「限时 10 分钟」），因为**学员需要知道「我有多久」，不需要知道「现在是第几分钟」**。
  **阶段徽章（讲 / 做 / 演 / 写）保留** —— 它告诉学员「现在该听还是该动手」，是有用信号，不是进度条。
- 禁止按时间自动出现答案；需要分步时用讲师控制的拆页。
- 1600×900 画布：主正文 ≥ 26px，示例与代码 ≥ 22px，脚注 ≥ 16px。
- 四象限图和搬运图、退化循环图按本文形状保留，用等宽字体呈现。**退化循环的纵向落差本身就是表达，不要改写成横向图。**
- 四格建议固定配色贯穿全场（沿用 L9 三种债固定配色的做法），学员靠颜色认格；但**配色只能在 P08 之后出现**。

## 12. 高频失败模式

| 症状 | 根因 | 处方 |
|---|---|---|
| 学员觉得「这就是 SoT 的另一种说法」 | 隐藏区讲成了「要落盘」 | 用他们自己第二问的答案当反例（事实 vs 理由），再打开 CLAUDE.md 数过期条目 |
| 课堂陷入「这条算哪一格」的争论 | 止争页出现太晚 | P21 提前，或者第一次有人问时直接念那句话 |
| 学员填不出盲区就放弃了 | 老师救了场 | 90 秒沉默，然后立刻切老师演示。**填不出来本身就是那一页的教学成果** |
| 老师演示没抓到盲区，场面尴尬 | 概率事件，正常 | §6.3 的兜底台词，换模块再试一次，还不行就承认「今天没抓到」往下走 |
| **P07 断网 / 工具挂掉 / 权限被拒 / 超时无响应** | 现场调用天然不可靠，而 P07 不许砍 | **§6.4 三级降级**：换备用模块 → 投第三个模块的预录（明说是预录）→ 只讲不演，用 P05 的举手数当替代证据 |
| 学员交了四格和四问，但没有数据边界声明 | 评分表原来没有这一维，学员按规则也能过关 | **§13.1 已补「边界」维度**，过关线随之改为 10/12。讲评时至少抽一份问「你哪一类信息决定不搬」 |
| 学员写的四问是四个抽象问题的复读 | 骨架给成了范文，或者没强调「回去真会用」 | 讲评时只问一句：「这段话你明天真会粘贴吗？」 |
| 收口变成感想大会 | 硬产物没收 | Exit ticket 第 7 题直接收那段四问 |
| 学员回去就忘了 | 没做成 Skill | 作业第 2 项是硬性的：做成 Skill，跑一次，迭代一次 |

## 13. 评分与 Exit ticket

### 13.1 课堂评分（12 分）

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **填格** | 只填了开放区和隐藏区 | 四格都有，但盲区或未知区是空话 | 四格都有具体内容，指得到具体文件或具体决定 |
| **盲区** | 没有记录 | 有记录，但是它自己就能读到的事实 | 一条他原先真的不知道的事，且他说得出为什么原先不知道 |
| **搬运** | 说不出四条动作 | 说得出，但四条指令性质雷同 | 四条指令性质真的不同，且盲区那条没有先给结论 |
| **退化** | 没做审计 | 找到过期条目，没改 | 找到过期条目 + 改后的版本 + 说得出它是怎么悄悄过期的 |
| **边界** | 没有声明 | 有声明，但只是「公司代码不能外传」这种笼统话 | 指名了哪一类信息不搬 + 给出「搬形状不搬内容」的具体替代写法 |
| **收口** | 只有感想 | 有四问，但是抽象问题的复读 | **一段能直接粘贴、回去真会用的四问** |

过关线：**10/12，且「盲区」和「收口」不得为 0。**

「边界」这一维对应 §3 学习目标第 8 条和 §3.1 过关证据第 6 项。**v0 的评分表和 Exit ticket 都没有查它，导致学员可以完全按规则过关却没做这件被写成必做的事。**

### 13.2 Exit ticket

1. 协作失败的第一归因是什么？（不许答「模型不行」或「prompt 没写好」）
2. 四个象限分别是什么？在你的任务里各举一个例子。
3. 第三问为什么最难填？
4. 「不落盘它就编」和「落到哪一层」是不是同一个问题？为什么？
5. 开放区为什么会退化？举一个你自己的例子。退化的时候有报错吗？
6. 「设计实验」和「设计 prompt」的区别是什么？
7. **交出你那段开场四问。**
8. 你的任务里，哪一类信息你决定**不搬**进开放区？不搬的话你改成怎么写？

八题至少六题正确；**第 1、5、7、8 题必须正确，第 7 题必须有实物。**

**收取方式（v0 的 88 到 90 两分钟装不下这份卷子，这里改口径）：**

- **课堂上只收第 7 题**，也就是那段开场四问。它是硬产物，必须当场落袋，不许带回家再补。
- **其余七题课后 24 小时内线上提交**，判卷在课后。
- 第 8 题是配合 §13.1 新增的「边界」维度加的，覆盖 §3.1 过关证据第 6 项。

## 14. 作业

### 必做

1. **这周三个真实任务，各填一次四格**，交回来。每份附一行：事后发现哪一格填错了。
2. **把开场四问做成一个 Skill**（承接 L5），真调用一次，迭代一次。交 `SKILL.md` 和一次调用记录。
3. **给自己的 `CLAUDE.md` 做一次退化审计**：逐条标「仍成立 / 已过期 / 不确定」，改掉过期的，删掉不成立的。交改动前后对照。
4. **写一份「我不知道」清单**（承接 L9 作业第 5 项），这次多加一列：**这一条属于盲区还是未知区**。两者的处方完全不同，一个是去问，一个是去试。

代码不能外传的学员，四项照做，交的时候把内容替换成结构描述即可（这本身就是 §8.2 教的那个动作）。

### 选做扩展

- **盲区校准**：让 AI 读你一个模块，专门要「三件作者可能没意识到的事」，看它命中几件。每月做一次，记录命中率的变化。
- **失败复盘**：找一次你和 AI 协作失败的真实记录，事后归因到某一格。**这是这个框架最有说服力的用法。**
- **团队版**：让两个同事对同一个任务各填一次四格，对比两人的隐藏区。**两份隐藏区的差集，就是你们团队知识债的地图**（接 L9）。
- 把退化审计做成定期动作，写进你的日历或者 Skill 里。
- 把四问接到 L7 的六格 brief 上：看看四格分别对应 brief 的哪几格。

## 19. 事实与数据纪律

### 19.1 概念出处

- **Johari Window**：Joseph Luft & Harrington Ingham, 1955。原用于人际关系中的自我认知。
- **四象限用于人机协作**：本课的应用，**不是 Johari 原意**，deck 和讲义都要写明。
- **退化方向（开放 → 隐藏）**：本课的扩展，**Johari 原型里没有这一条**，要写明是扩展。
- 「不给『不知道』一个出口，它就编」：本系列 L7 的结论，标明来源，不要当本节发明。
- 「它没有记忆，只有 context」：L6 的立论。
- 三种债、`status == 7`：L9 的框架，本节只借用作隐藏区的锚点。

### 19.2 课堂数据纪律

- deck 不出现具体模型名、价格、上下文长度数字。
- 国内工具只讲**能力维度**，不排名、不写具体产品的版本能力。合规部分只讲「要确认哪两条条款」，不替学员做合规判断。
- **不用本课程仓库自己的文件、Skill、目录当教学例子。** 老师用自己的老项目，学员用自己的项目。
- **本节没有标准答案。** 每位学员的任务不同，deck、讲义、评分表里都不许出现「正确答案应该是」。
- 老师演示的任何代码或文档，投屏前确认不含敏感信息。
- 学员自己的 `CLAUDE.md` 属于他自己的材料，**不许要求投屏或上交内容**，只上交「过期几条」这个数字和改动对照。

### 19.3 需要课前核对

- 演示所用编码工具当天「只读分析」的实际行为（会不会顺手改文件）。
- 「说不知道」这类指令当天的实际遵从情况，课前跑一次别的模块确认。
- 官方文档以 <https://code.claude.com/docs> 当天版本为准，课前核对，不凭记忆写进讲义。
