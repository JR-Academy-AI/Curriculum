## 3. 主课要不要分档（新定位）

**结论：线下小班分档空间小，不建议现在拆；先跑通"线上体验课 → 线下小班"单主课漏斗。**

**为什么线下小班分档空间小**：线下小班的成本几乎是固定的（场地 + 老师时间 + 小班人数上限），不像线上课能靠"自学版/直播版"边际零成本地分档。硬拆档只会摊薄小班本就有限的名额。真要给预算敏感的人一个更低入口，答案更可能是**"线上自学版（用录播自学库）"**作为独立的低价产品，而不是把线下小班本身拆档——但这需要新定位第一期数据支撑，现在不做。

**如果未来分档，参考逻辑（占位，未验证）**：不按内容多少，按**"有没有老师线下带练"**分：
- 线上自学版（约 $X，低）：只给录播自学库 + 社群答疑，自己跟着做，没有线下带练
- 线下小班版（=主课，高）：四城线下 + Claude Code 带练 + 老师盯屏

**承诺红线**：不写"包就业/保 offer/保证赚钱/保证做出能变现的产品"。只承诺过程结果（做出一个上线产品 + 掌握用 AI 做产品的能力）。新足迹论坛的旧证据（§9）说明匠人系用户里有人会主动核实营销真假，话别说满。

## 4. 引流 / 体验课方案（新定位）

### 为什么新定位下体验课更重要
线下小班门槛更高（要到场、周期长、价格待定但不会低），远端看到的人很难一步走进四城教室。需要一个**低成本、线上就能做、当场出成果**的体验课，让人先亲手用 AI 做出一个小东西，建立"我也能做出产品"的信心，再导流到线下小班。

### 内容上可行——现成录播能拆出体验课（旧版已核实，仍成立）
旧版核实过 `outline.json` 里存在能拼成"从写代码到部署上线一个真实网址"完整链路的现成课（HTML/CSS/JS 基础 + AWS S3 部署 + GitHub Action CI/CD 部署，都是真实 lesson）。这条**在新定位下更贴题**——把它包装成"**一晚用 AI 做出并上线你的第一个小产品**"，正好是新课"用 AI 做产品"的浓缩预告。

### 具体提案（新定位版）
| 字段 | 内容 | 为什么 |
|------|------|------|
| 主题 | 《一晚用 AI（Claude Code）做出并上线你的第一个小产品》| 直接是主课"用 AI 做产品"的迷你版，不是泛泛的编程入门 |
| 形式 | 线上直播/录播 3 小时 + 现场跟着用 AI 做出一个能打开的真实网址 | 抓"当晚就能看到成果"的 quick win |
| 定价 | 低价体验价（$X AUD，待定）| 参照体验课惯例，新定位无真实数据 |
| Quick win | 一个用 AI 做出来、能打开的真实网址 | 对"有 idea 但怕自己做不出来"的 Persona A 直接对症 |
| 学完承诺 | "你已经用 AI 做出并上线了第一个小东西；线下小班带你把一个真正的产品从零做到上线，还教你 AI 写错了怎么救、怎么部署、怎么迭代" | 把体验课的小成果和主课的大成果连起来 |
| 转化逻辑 | 让人亲手体验一次"我也能用 AI 做出上线的东西"→ 自然想"做个更完整的、真正属于我自己方向的产品"→ 线下小班 | 体验 > 广告语，尤其对"怕做不出来"的人群 |

**推荐路径**：`线上体验课（用 AI 做出第一个上线小东西）→ 短过渡 → 四城线下小班`。

**转化率假设**：🚫 新定位无任何真实数据，第一期跑完必须换真实数字。旧版给过求职定位的行业基线（页面→报名 ~30%、报名→社群 ~60%、社群→主课 ~10%），但那是低价线上主课的基线，**线下小班的转化漏斗（还要加"到场试听"这一环）跟它不一样，不能直接套**。
