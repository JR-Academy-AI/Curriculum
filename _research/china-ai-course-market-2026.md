## 一、结论摘要（先看这 8 条）

1. **市场没有"一个 AI 课程市场"，而是 6 个几乎不重叠的市场**，各自的客户、价格带、交付方式完全不同：大厂认证 / 开发者付费平台 / 线下转行培训 / 职能岗转岗课 / 泛人群知识付费 / 商学院高管班。拿它们互相比价没有意义。
2. **价格带跨 3 个数量级**：免费（Datawhale 开源）→ 49 元引流课 → 1,599–4,680 元线上训练营 → 20,980–27,980 元线下脱产就业班 → 6,900 元起的 3 天高管班 → 数十万的商学院年度项目。
3. **最贵的是"包就业"叙事，不是最好的内容**。黑马程序员 AI 大模型开发高手班一线城市 **27,980 元** ✅，而同样教 RAG/微调的知乎知学堂线上课 **4,680 元** ⚠️。差价买的是脱产场地、班主任、就业推荐，不是知识密度。
4. **最赚钱的是"低价引流 + 私域高客单"**。影视飓风 49 元 AI 实战课卖出 13 万+ 单、637 万+ 元，单日近 500 万 ⚠️；李一舟 49 元引流课 → 1,980 元年课 → 2,980 元商业实践课的套娃结构，三年累计营收被报道为 1.75 亿 ⚠️。
5. **内容同质化极严重**：绝大多数课程的技术骨架是同一套（Prompt → RAG → Agent → 微调 → 部署）。真正的差异化在**场景垂直度**（做机器人 / 做产品岗 / 做办公）和**交付形态**（陪跑 / 作品集 / 认证）。
6. **师资是最大的信任洼地**。头部机构靠"前大厂技术总监"背书，个人 IP 赛道则已被央媒点名讲师人设造假（新浪财经 / 中新网 2025-03 系列报道）⚠️。凡宣称"三天学会月入过万"的，基本是焦虑营销。
7. **免费开源是价格锚的地板**：Datawhale 的 happy-llm / self-llm / llm-universe / diy-llm 全部免费开源、覆盖 2000+ 学校 ⚠️。任何 4,000 元以下的纯录播技术课，都要回答"凭什么不去看 Datawhale"。
8. **官方认证正在成为新的付费理由**：华为 HCIA-AI、阿里云大模型 ACA/ACP、工信部教考中心 AIGC 应用工程师 —— 卖的不是课，是"可写进简历的凭证"，对**在职、要交差、要涨薪**的人群转化率最高。

#### B. 一个反常识的结论：**"大厂在职工程师授课"基本是营销话术**

把上表的履历拉直看，头部付费课的主讲人**几乎没有一个是"大厂在职员工"**，真实构成是三类：

1. **前大厂技术负责人 → 现创业者**（徐文浩：MediaV 技术总监/拼多多 → 自己开公司；李文哲：Amazon/高盛 → 开贪心科技）
2. **高校教师 / 研究所博士**（孙志岗：原哈工大副教授；赵松：中科院自动化所博士）
3. **社区技术大 V**（July：算法博客 + 开源项目起家）

原因很直接：**在职的大厂 P7/P8 不敢也不方便公开系统性授课**（竞业、保密、公司规定、时间不够）。所以宣传页上出现"来自阿里/腾讯/字节的在职专家"时，通常对应的是以下三种情况之一：

- 他其实是**前**员工（宣传时抹掉"前"字）
- 他只来做**一次嘉宾直播 / 一节公开课**，主体课程由教研团队和助教交付
- 他是**外包讲师**，同时给三四家机构讲同一套课

**能验证的大厂名字，在这个市场里主要出现在两个位置**：
- **讲师的过往雇主**（阿里业务中台、拼多多、MediaV、Amazon、Goldman Sachs、妈妈网、360、网易）
- **课程技术栈的绑定方**（阿里云通义千问/通义灵码、华为昇腾、百度飞桨、字节火山引擎）—— 这是官方认证课的师资来源，讲的是自家产品栈

## 六、竞争格局的 5 个判断

1. **"技术课"正在通缩，"服务"正在通胀。** 内容本身被开源和大模型自己摧毁了定价权；还能维持高价的只有脱产陪跑、1v1、就业交付、官方凭证。
2. **分层定价（三档）已成标准打法。** 起点课堂 2,999 / 4,699 / 12,999 是教科书级案例 —— 内容基本相同，差在带教密度。任何单一价格的课程都在浪费高付费意愿客户。
3. **低价引流课是获客基础设施，不是产品。** 黑马 598 元试学班、影视飓风 49 元课、知乎免费公开课，本质都是筛选器。没有引流课的机构获客成本会显著更高。
4. **垂直化是唯一的护城河。** 通用"大模型全栈"已是红海且在打价格战；深蓝押具身智能、黑马押嵌入式+机器人、起点押产品岗，都是在躲开正面战场。
5. **信任是最稀缺的资源。** 2025 年央媒对 AI 卖课的集中报道，已让"AI 课"在部分人群里带上负面预设。**可验证的师资、可退款的协议、可查证的学员产出**，正在从加分项变成入场券。

## 七、对匠人学院（JR Academy）的可迁移启示

> 以下是基于上述国内竞品格局的推论，**未做澳洲本地市场验证**，仅作产品/定价讨论的输入。

1. **护城河不在"教大模型"，在"本地就业场景"**。国内已经卷到 4,680 元含直播 + 项目带教 —— 单纯比内容既赢不了也不该比。
2. **可以直接借鉴的结构**：低价试学（对标 598 元入门班）→ 主课分三档（技能 / 项目 / 1v1 陪跑）→ 结课凭证。我们目前多数课是单一价格，损失了高意愿客户。
3. **必须避开的坑**：不用"包就业 / 月入过万"口径 —— 既触我们自己的红线，也正是国内这轮舆情的引爆点。
4. **凭证是被低估的付费理由**：国内工信部/华为/阿里认证课卖得动，靠的就是"可写进简历"。结课证书 + 作品集应该当成产品卖点，而不是附赠品。
5. **垂直场景优先**：对标深蓝（具身智能）、起点（产品岗）的做法，我们已有的 AI 会计、AI 漫剧、AI 全栈产品班这类**职业 × AI 交叉方向**，正是国内红海里的空白位，应继续加码而不是回到通用大模型课。
