# OPC W8 Content Engine

## Set the system

Read `BRAND-SOT.md`, `OFFER.md`, and customer evidence. Create `CONTENT-SYSTEM.md` with three evidence-backed pillars, audience question, source material, channel role, format, CTA, owner, cadence, and reuse map.

Do not translate one post unchanged across platforms. Adapt the hook, proof, length, visual need, CTA, and cultural context for each channel.

## Produce and publish

Generate one source asset and a Chinese and English derivative set. Remove template openings, unsupported claims, fake stories, fake engagement, and fake customer quotes. Require human review before publishing.

Append public URL, channel, language, CTA, date, and available metrics to `CONTENT-LOG.md`. Write `unavailable` when platform metrics are not yet available.

## Exit

Mark W8 `executed` when content is publicly accessible. Mark `verified` only when five Chinese and five English public links required by the course are recorded. End with which channel should feed W9 acquisition.
