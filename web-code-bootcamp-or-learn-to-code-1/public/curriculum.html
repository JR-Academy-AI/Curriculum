怎么上：翻转课堂 + 线下带练

① 课前 · 看录播自学

每周 2–4 小时，把概念、语法、工具视频看掉（下方就是完整录播库），自定节奏。

② 线下 · 小班带练

每周 1 次 2.5–3 小时，老师开 Claude Code 带全班一起把产品一块块做出来。

③ 结课 · 交付上线产品

带走一个部署上线的全栈产品 + 用 AI 独立做产品的能力。

本期项目：全班做同一个真实项目（公司项目池选定其一，开班时公布）。项目是载体，能力是收获。
