### 0.1 字数上限是硬的，不是建议

海报字太小 = 手机刷到那一眼看不清 = 白做。1242×1660 竖版下的可用上限：

| 位置 | 上限 | 为什么 |
|---|---|---|
| 主标题 | **≤ 10** | 超了就得缩字号，缩了就没有冲击力 |
| 副标题 | **≤ 18** | 一行放得下，不折行 |
| 要点（3 条） | **每条 ≤ 14** | 三条等长才好排版 |
| 底栏 / 钩子 | **≤ 22** | 最小字号 24px，再长就压到 20px 以下了 |
| 周图「这周干什么」 | **≤ 20** | — |
| 周图「你会做出 / 那个瞬间」 | **≤ 24** | — |
| L3 单句 | **≤ 16** | 长图一行放得下 |

> 🚨 **上限的单位是「全角当量」，不是字符数。** 一个汉字算 1，一个英文字母 / 数字 / 半角标点算 **0.5**——因为海报上真正的约束是**视觉宽度**，不是字符个数。
> 例：`Vibe Coding：Cursor 入门` 有 21 个字符，但只有 **12 当量**，是合规的。按字符数去卡会把一堆本来没问题的英文标题误判成超长。
>
> ⚠️ **写校验脚本的人注意**：本文件里既有卡片用的 ``` 块，也有这条 bash 命令的 ```bash 块。用 `` ```\n(.*?)\n``` `` 去配对会**错位到全部漏检**（我第一版就是这么误报「0 超限」的）。正则要写成 ``` ^```(\w*)\n(.*?)^``` ``` 并跳过 `bash` 块。
>
> 自检一行命令（在本目录跑）：
> ```bash
> python3 -c "import unicodedata as u,sys;t=sys.argv[1];print(sum(1 if u.east_asian_width(c) in 'WF' else .5 for c in t))" "你要检查的那句话"
> ```

**下面所有文案都已按此规则逐条验过：101 个受限字段 + 55 条 L3 单句 + 总图 A 的 15 行两列，0 处超限。** 你自己改的时候别超。

### 0.2 🚨 三句话不许直接上海报

从大纲里裁下来的原句，有三处**不能原样印上去**，我标出来了：

| 原句 | 问题 | 上海报要怎么改 |
|---|---|---|
| 「算完 43.5% 退税，发现这门课的学费可能是被税务局报销的」 | **这是税务主张，而且很可能不成立。** RDTI 退的是符合条件的 R&D 支出，不是课程学费。印上去等于给学员一个错误的税务预期 | 改成「把 R&D 支出算清楚，该退的一分不少拿」，或干脆只写「澳洲 RDTI 实操」 |
| 「麦肯锡顾问当场把你的 idea 拆到只剩骨头」 | **借第三方公司背书**。Stan 的真实 title 和能不能公开挂「麦肯锡」还没确认过 | 确认前一律写「资深战略顾问」；确认并拿到本人同意后才可写公司名 |
| 「有人真的付钱了」这类 | 单独用没问题（这是**学员要做的动作**），但**不许延伸成收入承诺** | ❌ 月入 / 躺赚 / 副业收入 / 第一桶金<br>✅ 收到第一笔真实付费 |

另外通用红线：**不许出现「最」「第一」「100%」「保证」「稳赚」**——广告法 + 平台限流双重踩雷。

## 4. 出图时的注意事项

1. **一张图只讲一件事。** 周图别把 55 节全塞进去，长图别想同时讲卖点。
2. **数字比形容词有效。** 「15 节现场课」「20 条 outreach」「43.5%」比「系统全面」强。
3. **「那个瞬间」那一栏是全图的钩子**，字号要比其他栏大一档。
4. **视觉风格**：官网是精致软风（奶油底、圆角、柔阴影、珊瑚主色），**不是黑边硬阴影那套**。给外部设计或 AI 出图时要写明，否则容易出成 deck 风格。
5. **生成图里不要带文字。** AI 出的中文字经常缺笔画。图只做背景/氛围，**文字用设计软件叠上去**。
6. **不确定的数字先去核** —— 价格、席位数、开班日期这类会变的，用之前对一遍 `FUNNEL_PLAN.md`，别照抄旧海报。
