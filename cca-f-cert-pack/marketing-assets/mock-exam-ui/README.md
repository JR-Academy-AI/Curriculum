## 营销叙事锚点（写文案时用）

- 真考在 Pearson VUE 考场进行，界面全英文——很多学员题会做，但第一次见考试驱动（Flag for Review、Exam Review、End Review 双确认）会慌
- 我们的模考 1:1 复刻了 Pearson VUE 官方 CBT tutorial 的界面：进考场前你已经"考过"了
- 60 题 / 120 分钟 / 5 个 domain 按真实权重抽题，倒计时到点自动交卷
- ⚠️ 文案红线：不承诺"包过 / 保证通过"；不使用 Pearson VUE logo（只做界面风格模拟，文字表述用「模拟 Pearson VUE 考试界面」）
