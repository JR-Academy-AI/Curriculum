## 1. 课程定位摘要（新）

**一句话卖点**：11 周四城线下小班，老师用 AI（Claude Code）带你从零做出一个能上线的真实产品，学完你有能力自己做想做的东西。

**三个差异化钩子**（推广主打）：
1. **不是教你手写代码，是教你用 AI 把产品做出来**——现在真实的做法
2. **线下小班面授**，老师盯着你屏幕当场救，不是几百人线上直播里的一个头像
3. **四城可上课**（布/墨/悉/阿），家门口就能上

**目标人群**（详见 PERSONAS.md，全部为待验证假设）：A 有 idea 的准创业者 / B 想转做产品的在职者 / C 想做副业的人。**不是目标**：纯冲求职拿 offer 的人（旧定位，导流求职向课/服务）、想深挖 LLM 工程的人（导流 ai-engineer-bootcamp）。

**承诺红线**：不写"包就业/保 offer/保证赚钱/保证做出能变现的产品"，只承诺过程结果——"做出一个能上线的产品 + 掌握用 AI 独立做产品的能力"。（§9 存档的新足迹论坛证据说明匠人系用户里有人会主动核实营销真假，案例要如实标注、话别说满。）
