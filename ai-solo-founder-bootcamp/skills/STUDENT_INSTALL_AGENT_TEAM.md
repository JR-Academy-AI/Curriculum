# OPC Agent Team 学生 Skill 包

这个压缩包包含两个 Skill：

- `opc-founder-os`：读取你的 Founder Workspace、证据状态和下一道关卡。
- `opc-agent-team`：设计最小权限的 AI 员工，并跑通第一个可检查的定时任务。

## Codex 安装

1. 解压 ZIP。
2. 把 `opc-founder-os` 与 `opc-agent-team` 两个完整文件夹复制到 `~/.codex/skills/`。
3. 重新打开 Codex或新建一个任务。
4. 输入：`运行 $opc-agent-team，帮我设计一个最小权限 AI 员工，并先手动跑通一项安全任务。`

## 不要一开始授权全部账号

先用合成或脱敏数据手动运行。确实需要连接器时，只授权一个专用文件夹、测试日历或最低权限账号。以下动作必须由本人最终批准：发送消息、公开发布、付款、删除、修改主分支、签署合同，以及法律、税务、医疗等专业结论。

## 课堂过关

1. `AGENT-TEAM.md` 写清任务、输入、输出、权限、停止条件和人工负责人。
2. 至少一个低风险任务被真实运行，而不只是写好配置。
3. 你指出并修正至少一处输出或边界问题。
4. 你知道任务在电脑睡眠时是否继续，能找到运行日志，也能停用排程和撤销权限。
5. `AUTOMATION-LOG.md` 留下本次运行的输入、输出、纠错和状态。

生成配置是 `drafted`；任务真实运行并复核后是 `executed`；证据可检查且经课程规定 reviewer 接受后才是 `verified`。
