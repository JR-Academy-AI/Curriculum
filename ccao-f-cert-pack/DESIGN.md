## 🔑 三根价值支柱

### 支柱 1 · 报名准入：这道门个人打不开
见 `CLAUDE_CERT_FAMILY.md` 第三节。CCAO-F 与其余三门共用同一条链路。

### 支柱 2 · 我们替你把 blueprint 的重心翻译出来
官方七域权重摆在一起，重心**极其反直觉**：

- **Output Evaluation and Validation 21%**（权重最高）
- Governance, Risk, and Responsible Use 15%
- 而 **Prompting and Task Execution 只有 14%**

**评估 + 治理 = 36%，是 Prompting 的两倍半。**

话术：**"市面上所有的中文 AI 通识课都在教你怎么写 prompt。可这门官方认证里，prompt 只占 14%，而『怎么判断 Claude 在胡说』占 21%。方向搞反了，刷再多题也没用。"**

这是本产品最锋利的一句话，数字来自官方 blueprint，可放心引用。

### 支柱 3 · 原创冲刺件，官方没有
- 七域考点精析，逐条对齐官方 blueprint
- **输出评估 checklist**（幻觉 / 事实 / 偏见 / 完整性四关）——直接对应权重最高的 Domain 2
- **Claude Projects 实操**（指令 + 知识源 + 连接器）——对应 Domain 5 + Domain 4 共 28%
- 2 套全真模拟（60 题 / 120 分钟）+ 逐题详解 + 七域得分分布
- 报名 / 预约 / OnVUE 环境自检 / 重考规则全程手把手

## 🆚 和另外三门的分流

**"你不写代码 → CCAO-F；你写代码交付应用 → CCDV-F；你做架构决策 → CCAR-F；你带团队做端到端交付、要跟法务高管过会 → CCAR-P。"**

🚨 **四门互不设前置。** 官方明确写着没有强制前置或必修课。**禁止**宣传"必须先考 Associate 才能考 Developer/Architect"。

CCAO-F 是四门里唯一官方明说 **"不需要任何软件开发或 API 经验"** 的一门，也是考试费最低的一门。它和匠人中文站「全球华人学习 AI 第一站」的定位最贴，TAM 也最大。
