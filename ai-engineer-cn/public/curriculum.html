JR ACADEMY · 国内 AI 应用开发岗 · 第一期招生中

AI 应用开发工程师训练营

对着国内 AI 应用开发岗的真实 JD 学，12 周从零做出「匠答 AI」电商智能客服工单系统，毕业带着扛得住面试追问的真项目，冲 25-40K 应用开发岗。
12 周技术 + 职业孵化
24节直播 (每节 ≤3h)
18个互动 Lab
6个项目里程碑
61节课
适合谁学 / 不适合谁

✅ 适合

›后端 / 全栈工程师（2-5 年），想转 AI 应用开发
›应届 CS / 计算机相关，想拼 AI 校招、要能聊的真项目
›传统算法 / 数据岗，想补 LLM 工程化能力
›创业者 / 独立开发，想做能上线的 AI 产品

❌ 不适合

✕零编程基础（建议先学 Python）
✕只想拿证书 / 速成不动手
✕想做大模型预训练算法（那是硕博算法岗）
先修要求：会 Python、用过命令行、懂 Git 基本操作。这不是从零教 Python 的课。
为什么和别的训练营不一样
真项目

做一套「匠答 AI」

12 周做出一整套电商智能客服工单系统——用户问「我的订单到哪了」「这件能不能七天无理由退」，它自己查订单、翻退换货政策、判断该不该转人工。不是教程级 demo，每周学完新技能当周就接进项目。

押新技能

RAG 评测 · MCP · 私有化部署

押注 2025-26 国内 JD 新高频词：Function Calling + MCP、RAG 工程化与评测、vLLM 私有化部署——老课程更新慢、覆盖薄的地方。

全国产栈

Qwen / DeepSeek / GLM + 国内云

国产大模型 + 阿里云百炼/华为云 + Coze/Dify。私有化部署是国内合规刚需，连国际课程都缺这一块。

诚实定位

对齐真实 JD，不卖幻觉

逐节对齐 BOSS 直聘真实 JD，瞄准招得最多、转型能拿到的 AI 应用开发岗。不卖需要硕博背景的算法岗幻觉，也不抄培训机构那套「1-3 年就 45-65K」的虚高数字。

课程亮点
  • 12 周做出一整套「匠答 AI」电商智能客服工单系统，不是教程级 demo
  • 全国产技术栈：Qwen/DeepSeek/GLM + 阿里云百炼/华为云 + Coze/Dify
  • 押注 2025-26 新高频技能：Function Calling + MCP、RAG 评测、vLLM 私有化部署
  • 诚实对齐国内真实 JD：主流 25-40K/月，大厂 AI 应用岗年包 40-90 万
  • 每周 2 节直播陪跑（≤3h）+ 浏览器 Lab + Quest 真实环境实战
  • 防简历同质化：全班同架构，毕业人人加专属扩展，面试各有的讲

12 周主线：学一节，就在匠答 AI 上做一节
周学什么当周在匠答 AI 上做什么
W1Python 工程化 / Docker / Git本地 Docker Compose 一键跑通匠答 AI，读懂架构
W2国产大模型 API / Prompt / Function Calling把 AI 服务接上 Qwen/DeepSeek，写第一个「按订单号查物流」Function Call
W3Embedding / 向量库选型把退换货政策、商品资料、历史工单灌进向量库，建检索
W4RAG Pipeline / 混合检索 / 重写压缩给应答接 RAG：这个问题该怎么答、按哪条政策、要不要转人工
W5RAG 评测（RAGAS/Langfuse）给 RAG 加评测面板，跑出召回/忠实度指标 ★里程碑
W6Agent 原理 / ReAct / 设计模式把 AI 大脑重写成 ReAct 分诊 Agent
W7MCP 协议 / MCP Server用 MCP 接匠答后端（查订单 / 查物流 / 发起退款 / 转人工）
W8Multi-Agent / 工作流编排升级成分诊 + 订单查询 + 售后处理多智能体协作 ★里程碑
W9微调 LoRA/QLoRA / Llama Factory微调一个工单意图分诊小模型（退货/物流/商品咨询/投诉）
W10vLLM/SGLang 私有化部署 / 量化 / 合规把微调模型私有化部署进 AI 服务 + 压测（客户数据不出内网）★里程碑
W11AI Eval / 防注入 / 护栏 / 可观测评测客服应答质量 + 防 AI 编造退款政策 + 加监控
W12个性化 + Demo + 面试叙事每人换一个垂直行业客服场景 + 独创功能，端到端 Demo ★毕业作品
防简历同质化：W1–W11 全班在同一套匠答 AI 上做同样架构（好教好批），W12 强制每人换一个垂直行业（美妆 / 3C / 母婴 / 医美 / 教育）+ 加专属扩展，简历各不相同、抗追问。每周 2 节直播（每节 ≤3 小时），其余录播 / Lab / Quest 自主节奏。
