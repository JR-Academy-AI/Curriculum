# OPC W10 SEO and GEO

## Choose the question

Use customer evidence, search data when available, sales objections, and support questions. Select one narrow query connected to the offer. Do not invent volume, difficulty, ranking, or AI visibility metrics.

## Build the asset

Create `SEARCH-GROWTH.md` with query, intent, audience, unique evidence, first-party experience, official or primary sources, content outline, schema choice, internal links, CTA, publication URL, and verification log.

Write the page with the direct answer first, concrete examples, explicit limitations, dated sources, and a useful next action. Avoid generic AI prose and unsupported superlatives.

## Verify

Check the live URL, canonical, robots access, structured data where used, mobile rendering, source links, and indexing submission or observation. Treat submission as submitted, not indexed. Treat an AI answer as a lead, not proof of durable citation.

## Exit

Mark `executed` when the page is live. Mark `verified` only when the technical checks pass and the observation date is recorded.
