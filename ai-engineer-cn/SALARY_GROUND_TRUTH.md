## 三、明确不采信的数据（培训机构宣传口径）

以下数字在搜索中反复出现，**一律不得进入任何对外文案**：

| 说法 | 出处类型 | 为什么不采信 |
|---|---|---|
| 「1-3 年 Agent 岗稳定月薪 45-65K」 | CSDN / 火山引擎 ADG 社区卖课号 | 与 V2EX 真实招聘帖（3-5 年 25-30K）直接矛盾，虚高约一倍 |
| 「华为字节核心 Agent 人才月薪 90-130K，年薪超 150 万」 | 同上 | 极端个例包装成普遍水平 |
| 「岗位需求暴增 15 倍 / 同比激增 310%」 | AtomGit / CSDN 培训号 | 无原始数据源，纯营销话术 |
| 「人才缺口超 500 万，供需比 1:8」 | 同上 | 典型培训行业造词，无统计口径 |
| 「大模型算法工程师平均月薪 68,051 元」 | CSDN 博客 | 精确到个位数却无样本量和采集方法，可疑 |
| 「大模型应用工程师平均年薪 45.8 万，较传统 IT 高 52%」 | 知乎专栏 | 同上，无口径 |

> 这些号本身在卖大模型培训课，抬高薪资预期是其转化手段。我们抄它们的数字 = 帮它们的营销背书，且第一个来质疑的学员就能问倒销售。

## 三点五、岗位要求 Ground Truth（2026-08-02 采集）

给「中国就业前景」栏目用。来源：BOSS 直聘 / 智联招聘 / V2EX 上公开的真实 JD。

### 常见岗位标题（对口本课）
- AI 应用开发工程师 / 高级 AI 应用开发工程师
- 大模型应用开发工程师
- AI 大模型应用及 Agent 开发工程师

### 高频岗位职责（多份 JD 的交集）
1. 用 LangChain 一类框架搭 AI 应用架构，完成模型加载、配置与优化
2. **主导 RAG 系统开发** —— 数据预处理、检索与生成模块、算法与策略调优
3. 大模型部署、微调、推理加速；设计并实现 RAG 架构与 Agent 系统
4. **把 AI 应用集成进客户既有业务系统**，保证数据交互与功能协同

> 第 4 条值得注意：国内相当一部分岗位是 **to B 交付**，不只是做自家产品。课程里「把 AI 接进真实后端（MCP）」正好对应这类要求。

### 高频任职要求
- 熟练 Python，掌握 PyTorch / TensorFlow
- **有 RAG 检索增强、Agent 开发经验**，用过 Qwen 等开源大模型
- 计算机 / 软件工程相关本科及以上
- **3-5 年 AI 应用 / 后端开发经验，且有完整端到端 Agent/LLM 项目交付经验**

> 最后一条是本课最直接的对标：JD 要的不是「学过」，是**交付过一个完整项目**。这正是「匠答 AI」12 周做一整套系统的理由。

### ⚠️ 明确不对口的岗位
算法研究员 / 预训练 / 多模态基础模型研究 —— 普遍要求硕博 + 论文，本课不覆盖，销售时不要往这边靠。
