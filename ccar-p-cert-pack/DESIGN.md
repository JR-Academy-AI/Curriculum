## 🔑 三根价值支柱

### 支柱 1 · 报名准入：这道门个人打不开
见 `CLAUDE_CERT_FAMILY.md` 第三节。

### 支柱 2 · 我们把 F 和 P 的 blueprint 逐条对齐给你看
最贵、最难、也最容易被误解的一门。绝大多数人以为它是 Foundations 的进阶版，于是照着 F 的方法复习——**必然翻车**。

逐词核对官方两份考纲的结果：

| | CCAR-F | CCAR-P |
|---|---|---|
| 主轴 | 怎么**造** | 怎么**决策与交付** |
| Claude Code | 20%（一整个域） | 7% |
| Prompt | 20%（一整个域） | 13%（与模型选型、上下文工程合并） |
| **RAG / 检索** | **全篇 0 次出现**，且 "vector database implementation details" 明确列进 out-of-scope | Domain 3 核心（19%，权重最高） |
| **GDPR / HIPAA / FedRAMP** | **全篇 0 次出现** | Domain 5 明确列出 |
| **干系人沟通（stakeholder）** | **全篇 0 次出现** | Domain 6 整域，14% |
| **A/B 测试** | 不考 | Domain 4（16%） |

话术：**"我们把两份官方考纲逐词比对过。RAG、stakeholder、GDPR 这些词，在 Foundations 的考纲里出现 0 次。你按 F 的方法复习 P，等于把 40% 的考点当空气。"**

### 支柱 3 · 原创冲刺件，官方没有
- 七域考点精析，逐条对齐官方 blueprint
- **RAG 流水线设计实战**——Foundations 完全不考，中文材料几乎空白
- **架构决策沟通训练**（写 ADR + 五分钟讲清取舍与 SLA）——对应 Domain 6 的 14%，是纯软技能，华人技术考生最容易丢分、也最缺练习材料的一块
- 2 套全真模拟（**63 题** / 120 分钟）+ 逐题详解 + 七域得分分布
- 报名 / 预约 / OnVUE 环境自检 / 重考规则全程手把手

## 🧱 产品结构（16 节 / 4 Phase / 约 15h 自学）

| Phase | 干什么 | 确定性成果 |
|---|---|---|
| P0 认证全景 & 打通报名 | 搞懂 P 和 F 差在哪 + 开通账号 + 自行注册与预约 | 一个能进 Partner Academy 的账号，和一场已约好的考试 |
| P1 七域备考路径 | 权重地图 + 逐域精析（Integration 19% 最重） | 一条明确标出"从 F 过来要重学什么"的备考路线 |
| P2 软硬两手实战 | RAG 流水线设计 + 架构决策沟通 | 会设计 RAG，也能把取舍讲给非技术干系人 |
| P3 全真模拟 & 冲刺 | 2 套模拟 + 考前清单 | 两套模拟稳定 720+ 再进考场 |

## 🆚 和另外三门的分流

**"你不写代码 → CCAO-F；你写代码交付应用 → CCDV-F；你做架构决策 → CCAR-F；你带团队做端到端交付、要跟安全法务高管过会 → CCAR-P。"**

🚨🚨 **官方明确写着：CCAR-P 没有强制前置或必修课，不要求先持有 CCAR-F。**

**禁止**在任何对外内容里暗示"必须先考 Foundations 才能考 Professional"。真实的分流依据是**经验与岗位**：3+ 年系统架构或平台工程经验、交付过端到端系统、日常要跟干系人过会 → 直接考 P。

（但可以诚实地说：如果你从没在生产环境跑过 Claude，两门都别急。）

## 📌 定价口径（内部）

- 对外宣传页、海报、小红书、公众号不露出价格。
- **包价待定**（Lightman 未拍板）。定价参考：官方考试费是四门里最高的一档，受众也是付费能力最强、最可能由公司报销的一批人。
- 官方考试费**不含在包价内**，对外必须交代这笔钱存在且需另付，但**不写金额**。
- 商业价值：这批人往往是团队技术决策者，转介绍与 B 端合作价值高于单笔客单价。
